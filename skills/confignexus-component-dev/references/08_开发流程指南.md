# 08 开发流程指南

> 本文档提供了创建新组件的端到端分步指南。

---

## 🚀 步骤 1：创建组件目录

在 `app/` 目录下创建一个新文件夹，使用下划线命名法。

```powershell
cd path/to/app
mkdir new_demo_component
```

---

## 📄 步骤 2：初始化文件

从现有组件（如 `dialogue_component`）复制基础文件，或手动创建。

需要创建的核心文件：
1. `package.json`
2. `vite.config.ts`
3. `metadata.json`
4. `index.html`
5. `index.tsx`
6. `index.css`
7. `tsconfig.json`
8. `tailwind.config.js`
9. `postcss.config.js`

**修改 metadata.json：**
```json
{
    "name": "new_demo_component",
    "toolType": "demo_tool",
    "devPort": 5176,  // 确保端口不冲突
    // ...其他字段
}
```

---

## 🛠️ 步骤 3：配置构建环境

确保 `vite.config.ts` 正确指向 `app/node_modules`（默认即可）。

测试启动：
```powershell
# 在 app 目录下
cd new_demo_component
# 确保没有本地 node_modules
npm run dev
```

---

## 💻 步骤 4：开发组件功能

1. **定义数据结构**：确定组件需要展示和编辑的数据。
2. **定义字段映射**：参考 [05_字段映射规范](./05_字段映射规范.md) 创建映射配置。
3. **实现 UI**：使用 React + TailwindCSS 开发界面。
4. **接入 IPC**：参考 [04_IPC通信API规范](./04_IPC通信API规范.md) 实现数据同步。

```tsx
// index.tsx 核心逻辑
useEffect(() => {
    // 监听同步数据
    const handleSync = (e: any) => {
        const payload = e.detail || e;
        // 更新状态
    };
    window.addEventListener('tool:receive-sync', handleSync);
    return () => window.removeEventListener('tool:receive-sync', handleSync);
}, []);
```

---

## 🔌 步骤 5：注册到主程序

需要修改 `src/main.js` 来注册新组件。

1. **打开 `src/main.js`**
2. **找到 `toolWindowRegistry`**
3. **添加新条目**：

```javascript
/* src/main.js */
const toolWindowRegistry = {
    // ...现有工具
    demo_tool: {
        getWindow: () => toolTypeToWindow.get('demo_tool'),
        syncChannel: 'tool:receive-sync'
    }
};
```

---

## 🔗 步骤 6：添加菜单入口（可选）

如果需要从菜单栏打开组件，修改 `src/renderer/menubar.js`。

```javascript
/* src/renderer/menubar.js */
const toolsMenu = {
    label: '工具',
    submenu: [
        // ...
        {
            label: '打开演示组件',
            click: () => {
                ipcRenderer.send('window:open-component', {
                    toolType: 'demo_tool',
                    path: 'app/new_demo_component/dist/index.html',
                    title: '演示组件'
                });
            }
        }
    ]
};
```

---

## 🧪 步骤 7：测试与构建

1. **本地调试**：运行 `npm run dev` 并在浏览器测试 UI。
2. **构建发布**：运行 `npm run build` 生成 `dist/` 目录。
3. **集成测试**：在 Electron 应用中打开组件，测试数据同步功能。
    - 打开 ConfigNexus 表格
    - 点击“打开演示组件”
    - 配置映射
    - 点击“同步数据”
    - 验证组件是否收到数据

---

## ✅ 发布检查清单

- [ ] `dist/` 目录已生成且包含 `index.html`
- [ ] `metadata.json` 配置正确无误
- [ ] 主程序已注册 `toolType`
- [ ] 数据同步功能正常
- [ ] UI 在暗色/亮色模式下均正常
- [ ] 无冗余的 `node_modules` 目录
