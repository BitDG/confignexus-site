## 🔗 编辑器类组件：跟随软件主题「点缀色」（强约束）

> 适用对象：`metadata.json` 里 `componentType: "editor"` 的组件（如 `map_app` 地图编辑、`talent_app` 坐标编辑）。
> 游戏预览类（`componentType: "preview"`，抽卡/邮件/背包/任务/对话）刻意保留各自的游戏皮肤，**不**受本节约束。

### 背景：宿主已经把主题色喂进来了

编辑器组件运行在弹出窗口里：外层是主软件的 `src/renderer/window-frame.html`（已接好主窗口 preload + 主题令牌），组件本体在它内部的 `<iframe>` 里加载。宿主帧会在加载完成后、以及用户在「设置→外观→主题预设」换色时，把主窗口的 4 个主题色变量**直接写进 iframe 文档的 `documentElement`（即组件自己的 `<html>`）**：

| CSS 变量 | 含义 |
|---|---|
| `--cnx-primary` | **点缀色 / 强调色**（主要操作按钮、选中态、焦点框的颜色） |
| `--cnx-header-bg` | 头部背景色 |
| `--cnx-tab-bg` | 页签背景色 |
| `--cnx-tab-active-bg` | 选中页签背景色 |

也就是说：**组件不需要任何 IPC、不需要引主 preload，只要在 CSS 里 `var(--cnx-primary)` 就能拿到当前点缀色，且换主题时自动实时刷新。** 组件没做任何接入时，这些变量虽然被写进来了，但组件用的是自己硬编码的颜色（如 Tailwind 的 `blue-500`），所以**不会跟随**——这正是"坐标编辑器按钮不跟点缀色"的根因。

### 做法 A（推荐｜Tailwind v4 项目）：整体重定义调色板，零改 tsx

若组件的强调色是通过 Tailwind 工具类（`bg-blue-500`、`text-blue-600`、`border-blue-400`、`indigo-*` 等）满页书写的，**不要逐处去改 className**。在 `index.css` 顶部用 `@theme` 把这套调色板整体重定义为「以 `--cnx-primary` 为基准、由 `color-mix` 派生明暗梯度」，于是页面里所有相关工具类无需改动即自动跟随点缀色：

```css
@import "tailwindcss";

@theme {
  /* 把"强调蓝"整条调色板挂到点缀色上；fallback #3b82f6 保证独立运行时外观不变 */
  --color-blue-100: color-mix(in srgb, var(--cnx-primary, #3b82f6), white 85%);
  --color-blue-400: color-mix(in srgb, var(--cnx-primary, #3b82f6), white 22%);
  --color-blue-500: var(--cnx-primary, #3b82f6);
  --color-blue-600: color-mix(in srgb, var(--cnx-primary, #3b82f6), black 15%);
  --color-blue-700: color-mix(in srgb, var(--cnx-primary, #3b82f6), black 30%);
  --color-blue-900: color-mix(in srgb, var(--cnx-primary, #3b82f6), black 55%);
  /* indigo 同理（如它也仅作强调用）；完整 50–900 梯度见 app/talent_app/index.css */
}
```

> `color-mix` 在 Electron 内置的 Chromium（≥111）原生支持；`@supports` fallback 由 Tailwind 自动生成，老环境退回基准色。

### 做法 B（其它框架 / 强调色是裸 hex）

直接在样式里引用变量，并自带 fallback：

```css
.primary-btn        { background: var(--cnx-primary, #3b82f6); }
.primary-btn:hover  { background: color-mix(in srgb, var(--cnx-primary, #3b82f6), black 15%); }
.selected, :focus-visible { outline-color: var(--cnx-primary, #3b82f6); }
```

### 三条铁律

1. **只让"强调/交互"语义的颜色跟随点缀色**：主要操作按钮、选中态、激活态、焦点框、强调文字/边框。
   语义色（成功绿 `#52C41A` / 警告 `#FAAD14` / 错误 `#FF4D4F`）、**用户内容色 / 数据可视化色 / Canvas 绘制色**（如节点配色数组、图表系列色）**保持原样，不要挂到点缀色上**。
2. **永远带 fallback**：`var(--cnx-primary, <原色>)`。组件可能被独立打开（`npm run dev`）或被宿主以外的方式加载，缺变量时要退回合理的默认色，不能变透明/变黑。
3. **改完必须重新构建**：Vite 组件的样式编译进 `dist/`，窗口加载的是打包产物。只改源码不跑 `npm run build`（或 `build.bat`）看不到任何变化。

### 验收

打开组件窗口 → 目视主要按钮/选中态为当前点缀色（非写死的蓝）→ 到「设置→外观→主题预设」换一个主题色 → 组件强调色**实时跟着变**，无需重启。

## � 多语言切换规范 (Language Switcher)

### 设计规范

用于支持多语言的组件，提供语言按钮和选择弹窗。

#### 核心参数

| 属性 | 值 |
|------|-----|
| **语言按钮** | 与顶部栏按钮统一样式 (40x40px, 切角) |
| **按钮图标** | `Globe` 图标 (lucide-react) |
| **弹窗背景** | `bg-black/80` + `backdrop-blur-sm` |
| **列表项** | 悬停高亮，当前语言红色背景标记 |

### 类型定义

```tsx
// 多语言表字段映射
interface LanguageFieldMapping {
  sheetName: string;      // 多语言工作表名称
  startRow: number;       // 数据起始行（1-indexed）
  idColumn: string;       // ID 列 (第1列)
  langColumns: string[];  // 语言列 (第3列起)
}

// 多语言数据存储 Map: ID -> { langName: text }
type LanguageData = Map<string, { [lang: string]: string }>;
```

### 完整代码模板

```tsx
import React, { useState } from 'react';
import { Globe, X } from 'lucide-react';

interface LanguageSwitcherProps {
  availableLanguages: string[];
  currentLanguage: string;
  onLanguageChange: (lang: string) => void;
}

export const LanguageSwitcher: React.FC<LanguageSwitcherProps> = ({
  availableLanguages,
  currentLanguage,
  onLanguageChange,
}) => {
  const [isOpen, setIsOpen] = useState(false);

  const chamferClip = {
    clipPath: 'polygon(8px 0, 100% 0, 100% calc(100% - 8px), calc(100% - 8px) 100%, 0 100%, 0 8px)'
  };

  if (availableLanguages.length <= 1) return null;

  return (
    <>
      {/* 语言按钮 */}
      <button 
        onClick={() => setIsOpen(true)}
        className="w-10 h-10 flex items-center justify-center bg-[#050505] border border-[#222] text-gray-300 hover:text-white hover:border-white/50 transition-colors"
        style={chamferClip}
        title="切换语言"
      >
        <Globe size={18} />
      </button>

      {/* 语言选择弹窗 */}
      {isOpen && (
        <div 
          className="fixed inset-0 z-[100] flex items-center justify-center bg-black/80 backdrop-blur-sm"
          onClick={() => setIsOpen(false)}
        >
          <div 
            className="bg-[#0e0e0e] border border-white/10 w-[300px] max-h-[60vh] overflow-hidden"
            onClick={(e) => e.stopPropagation()}
          >
            {/* 头部 */}
            <div className="h-12 flex items-center justify-between px-4 border-b border-white/10 bg-[#121212]">
              <div className="flex items-center gap-2">
                <Globe size={16} className="text-[#ff2a2a]" />
                <span className="text-white font-bold tracking-wider">选择语言</span>
              </div>
              <button onClick={() => setIsOpen(false)} className="text-gray-500 hover:text-white">
                <X size={18} />
              </button>
            </div>

            {/* 语言列表 */}
            <div className="p-2 overflow-y-auto max-h-[50vh]">
              {availableLanguages.map((lang) => (
                <button
                  key={lang}
                  onClick={() => {
                    onLanguageChange(lang);
                    setIsOpen(false);
                  }}
                  className={`
                    w-full text-left px-4 py-3 transition-colors
                    ${currentLanguage === lang 
                      ? 'bg-[#ff2a2a] text-black font-bold' 
                      : 'text-gray-300 hover:bg-white/10 hover:text-white'
                    }
                  `}
                >
                  {lang}
                </button>
              ))}
            </div>
          </div>
        </div>
      )}
    </>
  );
};

// 从多语言数据中获取文本的工具函数
export function getText(
  id: string | undefined, 
  langData: LanguageData, 
  currentLang: string
): string {
  if (!id) return '';
  const entry = langData.get(id);
  if (!entry) return id;
  return entry[currentLang] || entry['简中'] || Object.values(entry)[0] || id;
}
```

## �🃏 Item 卡片规范 (ItemCard)

### 设计规范

```
┌─────────────────────────────┐
│ ITEM_01                   ◤▌│  顶部：ID (#3B3B3B) + 品质三角(16px)
│                              │
│          [图标 36px]         │  中央：图标 (默认 #3B3B3B, hover scale-110)
│                              │
├──────────────────────────────┤
│ 名称              x99        │  底部栏 (28px)：名称 + 数量
└──────────────────────────────┘
```

#### 核心参数

| 属性 | 值 |
|------|-----|
| **尺寸** | 100 x 100 px (固定) |
| **背景** | `#0a0a0a` |
| **边框** | `1px solid #333` |
| **品质角标** | 16px border 三角形 (右上角，透明度 35%) |
| **图标尺寸** | 36px (固定) |
| **图标偏移** | 向下 5px (`pt-[5px]`) |
| **默认颜色** | `#3B3B3B` (图标和文本) |
| **底部信息栏** | 28px 高度，`bg-black` 背景 |
| **Hover效果** | 图标 `scale-110`，边框 `border-white/20` |

#### 品质颜色

```css
/* 稀有度颜色映射 */
COMMON    →  #16a34a  /* 绿色 */
RARE      →  #60a5fa  /* 蓝色 */
EPIC      →  #a855f7  /* 紫色 */
LEGENDARY →  #fbbf24  /* 金色 */
```

### 完整代码模板

```tsx
import React from 'react';
import { Box } from 'lucide-react';

interface ItemCardProps {
  id: string;
  name: string;
  rarity: 'COMMON' | 'RARE' | 'EPIC' | 'LEGENDARY';
  quantity?: number;
  claimed?: boolean;
}

// 根据稀有度获取颜色
const getRarityColor = (rarity: string) => {
  switch (rarity) {
    case 'LEGENDARY': return '#fbbf24';
    case 'EPIC': return '#a855f7';
    case 'RARE': return '#60a5fa';
    default: return '#16a34a';
  }
};

export const ItemCard: React.FC<ItemCardProps> = ({
  id,
  name,
  rarity,
  quantity = 0,
  claimed = false,
}) => {
  const rarityColor = getRarityColor(rarity);

  return (
    <div className="relative w-[100px] h-[100px] bg-[#0a0a0a] border border-[#333] flex flex-col group overflow-hidden select-none shrink-0 shadow-lg">
      
      {/* 顶部 ID 标签 */}
      <div className="absolute top-1 left-2 text-[10px] font-mono text-[#333] z-10 tracking-wider font-bold">
        ITEM_{id.toUpperCase().substring(0, 2)}
      </div>

      {/* 品质三角角标 (16px, 透明度 35%) */}
      <div 
        className="absolute top-[2px] right-[2px] w-0 h-0 border-l-[16px] border-l-transparent border-t-[16px] z-20 opacity-35"
        style={{ borderTopColor: rarityColor }}
      />

      {/* 中央图标 (36px, 默认颜色 #3B3B3B, 向下偏移5px) */}
      <div className="flex-1 flex items-center justify-center relative z-10 pt-[5px]">
        <Box 
          className="text-[#3B3B3B] group-hover:scale-110 transition-transform duration-200" 
          size={36} 
          strokeWidth={1.5}
        />
      </div>

      {/* 底部信息栏 (28px, 默认颜色 #3B3B3B) */}
      <div className="h-[28px] bg-black w-full flex items-center px-1.5 justify-between border-t border-[#222] relative z-20">
        <span className="text-[#3B3B3B] font-bold text-sm font-sans truncate flex-1">{name}</span>
        <span className="text-[#3B3B3B] font-mono text-sm tracking-tighter ml-1 opacity-90">x{quantity}</span>
      </div>

      {/* 已领取覆盖层 (可选) */}
      {claimed && (
```

```tsx
import React from 'react';

interface CyberButtonProps {
  variant?: 'primary' | 'secondary' | 'danger' | 'ghost';
  children: React.ReactNode;
  onClick?: () => void;
  disabled?: boolean;
  className?: string;
}

export const CyberButton: React.FC<CyberButtonProps> = ({
  variant = 'primary',
  children,
  onClick,
  disabled = false,
  className = '',
}) => {
  const chamferClip = {
    clipPath: 'polygon(8px 0, 100% 0, 100% calc(100% - 8px), calc(100% - 8px) 100%, 0 100%, 0 8px)'
  };

  const variants = {
    primary: 'bg-[#ff2a2a] hover:bg-[#ff4444] text-black font-bold shadow-[0_0_10px_rgba(255,0,60,0.4)]',
    secondary: 'bg-[#0a0a0a] border border-[#333] text-white hover:bg-[#151515] hover:border-white/50',
    danger: 'bg-red-600 hover:bg-red-700 text-white font-bold',
    ghost: 'bg-transparent border border-white/10 text-gray-400 hover:text-white hover:bg-white/5',
  };

  return (
    <button
      onClick={onClick}
      disabled={disabled}
      style={chamferClip}
      className={`
        px-6 py-3 tracking-wider transition-all flex items-center justify-center gap-2
        disabled:opacity-50 disabled:cursor-not-allowed
        ${variants[variant]}
        ${className}
      `}
    >
      {children}
    </button>
  );
};
```

## � 材料获得弹窗规范 (RewardModal)

### 设计规范

用于展示任务奖励、抽奖结果、邮件附件领取等场景的全屏弹窗。

```
┌─────────────────────────────────────────────────────────────────────────┐
│                                   ○ ○ ○                                 │  背景：旋转装饰圆环
│                         < ─────────────── >                             │
│                                                                         │
│                           「 获得奖励 」                                 │  标题：带装饰括号
│                                                                         │
│                        ┌─────┐  ┌─────┐  ┌─────┐                        │
│                        │Item1│  │Item2│  │Item3│                        │  物品网格：居中排列
│                        └─────┘  └─────┘  └─────┘                        │
│                                                                         │
│                          - 点击空白处关闭 -                              │  底部提示
└─────────────────────────────────────────────────────────────────────────┘
```

#### 核心参数

| 属性 | 值 |
|------|-----|
| **背景** | `bg-black/80` + `backdrop-blur-sm` |
| **装饰圆环** | 800px、600px、900px 三层，慢旋转动画 |
| **标题样式** | 4xl 字体，`tracking-[0.2em]`，红光阴影 |
| **物品间距** | `gap-8` (32px) |
| **入场动画** | 标题从上滑入，物品依次缩放淡入 |
| **关闭方式** | 点击空白处关闭 |

### 完整代码模板

```tsx
import React, { useEffect, useState } from 'react';
import { ChevronRight, ChevronLeft } from 'lucide-react';

interface RewardItem {
  id: string;
  name: string;
  quantity: number;
  rarity: string;
}

interface RewardModalProps {
  isOpen: boolean;
  items: RewardItem[];
  onClose: () => void;
}

export const RewardModal: React.FC<RewardModalProps> = ({ isOpen, items, onClose }) => {
  const [showContent, setShowContent] = useState(false);

  useEffect(() => {
    if (isOpen) {
      const timer = setTimeout(() => setShowContent(true), 100);
      return () => clearTimeout(timer);
    } else {
      setShowContent(false);
    }
  }, [isOpen]);

  if (!isOpen) return null;

  return (
    <div 
      className="fixed inset-0 z-[100] flex items-center justify-center bg-black/80 backdrop-blur-sm transition-opacity duration-300"
      onClick={onClose}
    >
      {/* 背景装饰圆环 */}
      <div className={`absolute inset-0 overflow-hidden pointer-events-none transition-all duration-700 ${showContent ? 'opacity-100 scale-100' : 'opacity-0 scale-90'}`}>
        <div className="absolute top-1/2 left-1/2 -translate-x-1/2 -translate-y-1/2 w-[800px] h-[800px] border border-white/5 rounded-full" />
        <div className="absolute top-1/2 left-1/2 -translate-x-1/2 -translate-y-1/2 w-[600px] h-[600px] border border-white/10 rounded-full border-dashed animate-[spin_60s_linear_infinite]" />
        <div className="absolute top-1/2 left-1/2 -translate-x-1/2 -translate-y-1/2 w-[900px] h-[900px] border border-[#ff2a2a]/5 rounded-full" />
      </div>

      <div 
        className={`relative flex flex-col items-center max-w-5xl w-full p-10 transition-all duration-500 transform ${showContent ? 'translate-y-0 opacity-100' : 'translate-y-10 opacity-0'}`}
        onClick={(e) => e.stopPropagation()}
      >
        
        {/* 标题区域：带装饰括号 */}
        <div className="flex items-center gap-6 mb-16">
          <div className="flex items-center text-[#ff2a2a] opacity-80">
            <span className="w-12 h-[1px] bg-gradient-to-r from-transparent to-[#ff2a2a]" />
            <ChevronLeft size={24} />
          </div>
          
          <h2 className="text-4xl font-bold text-white tracking-[0.2em] drop-shadow-[0_0_15px_rgba(255,0,60,0.6)]">
            获得奖励
          </h2>
          
          <div className="flex items-center text-[#ff2a2a] opacity-80">
            <ChevronRight size={24} />
            <span className="w-12 h-[1px] bg-gradient-to-l from-transparent to-[#ff2a2a]" />
          </div>
        </div>

        {/* 中央发光效果 */}
        <div className="absolute top-1/2 left-1/2 -translate-x-1/2 -translate-y-1/2 w-64 h-64 bg-[#ff2a2a] blur-[100px] opacity-10 pointer-events-none" />

        {/* 物品网格 */}
        <div className="flex flex-wrap justify-center gap-8 z-10">
          {items.map((item, index) => (
            <div 
              key={index} 
              className="transition-all duration-500 hover:scale-105"
              style={{ 
                opacity: showContent ? 1 : 0, 
                transform: showContent ? 'scale(1)' : 'scale(0.5)',
                transitionDelay: `${index * 150 + 200}ms` 
              }}
            >
              {/* 使用 ItemCard 组件 */}
              <ItemCard item={item} />
            </div>
          ))}
        </div>

        {/* 底部关闭提示 */}
        <div 
          className={`mt-16 text-gray-500 font-mono text-xs tracking-[0.5em] animate-pulse transition-all duration-1000 ${showContent ? 'opacity-100' : 'opacity-0'}`}
          style={{ transitionDelay: '800ms' }}
        >
          - 点击空白处关闭 -
        </div>
      </div>
    </div>
  );
};
```
