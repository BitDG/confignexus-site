# 05 字段映射规范

> **版本**: 2.0  
> **更新日期**: 2024-12  
> **参考应用**: `task_app`、`bag_app`、`mail_app`

本文档定义了组件如何通过字段映射弹窗对接 ConfigNexus 表格数据，包含完整的实现模板。

## 🎯 字段映射概述

字段映射是组件与 ConfigNexus 表格数据对接的核心机制，允许用户动态配置数据列与组件字段的对应关系。

### 映射流程

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│   用户打开映射   │────▶│   选择工作表    │────▶│   配置列映射    │
│     弹窗        │     │   选择起始行    │     │   保存配置      │
└─────────────────┘     └─────────────────┘     └─────────────────┘
                                                         │
                                                         ▼
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│   组件解析数据   │◀────│   接收同步数据   │◀────│   通知主窗口    │
│   更新状态      │     │                 │     │   显示同步按钮  │
└─────────────────┘     └─────────────────┘     └─────────────────┘
```

## 🔧 工具函数

### 列号转换

```typescript
// types.ts - 所有应用都需要此函数
export const colToIndex = (col: string): number => {
    if (!col) return -1;
    col = col.toUpperCase();
    let idx = 0;
    for (let i = 0; i < col.length; i++) {
        idx = idx * 26 + (col.charCodeAt(i) - 64);
    }
    return idx - 1;  // 返回 0-indexed
};

// 使用示例
// colToIndex('A') => 0
// colToIndex('B') => 1
// colToIndex('Z') => 25
// colToIndex('AA') => 26
```

## 🖥️ 映射弹窗完整模板

### DataMappingModal.tsx

```tsx
import React, { useState, useEffect, useCallback } from 'react';
import { X, RefreshCw, Check } from 'lucide-react';

// 泛型映射接口
interface FieldMappingBase {
    sheetName: string;
    startRow: number;
    columns: { [key: string]: string };
}

// 工作表信息
interface SheetInfo {
    name: string;
    columns: { letter: string; name: string }[];
}

// 字段配置
interface FieldConfig {
    key: string;
    label: string;
    code: string;
    required?: boolean;
}

interface DataMappingModalProps<T extends FieldMappingBase> {
    isOpen: boolean;
    onClose: () => void;
    onConfirm: (mapping: T) => void;
    currentMapping: T;
    defaultMapping: T;
    storageKey: string;
    toolType: string;            // 用于通知主窗口
    fieldConfigs: FieldConfig[]; // 字段配置列表
    title?: string;
}

// 声明 electronAPI 类型
declare global {
    interface Window {
        electronAPI?: {
            invoke: (channel: string, ...args: any[]) => Promise<any>;
            getSheetsList: () => Promise<{ 
                success: boolean; 
                sheets: SheetInfo[]; 
                currentSheetName?: string;
            }>;
            notifyMappingConfigured: (toolType: string, configured: boolean) => Promise<void>;
        };
    }
}

export function DataMappingModal<T extends FieldMappingBase>({
    isOpen,
    onClose,
    onConfirm,
    currentMapping,
    defaultMapping,
    storageKey,
    toolType,
    fieldConfigs,
    title = '数据映射配置',
}: DataMappingModalProps<T>) {
    
    const [mapping, setMapping] = useState<T>(currentMapping);
    const [availableSheets, setAvailableSheets] = useState<SheetInfo[]>([]);
    const [selectedColumns, setSelectedColumns] = useState<{ letter: string; name: string }[]>([]);
    const [isLoading, setIsLoading] = useState(false);
    const [isSaving, setIsSaving] = useState(false);

    // 获取工作表列表
    const fetchSheetsList = useCallback(async () => {
        setIsLoading(true);
        try {
            if (window.electronAPI?.getSheetsList) {
                const result = await window.electronAPI.getSheetsList();
                if (result.success && result.sheets) {
                    setAvailableSheets(result.sheets);
                    
                    // 如果当前没有选择工作表，自动选择第一个
                    if (!mapping.sheetName && result.sheets.length > 0) {
                        const firstSheet = result.sheets[0];
                        setMapping(prev => ({ ...prev, sheetName: firstSheet.name }));
                        setSelectedColumns(firstSheet.columns);
                    } else if (mapping.sheetName) {
                        // 如果已有选择，更新列信息
                        const sheet = result.sheets.find(s => s.name === mapping.sheetName);
                        if (sheet) {
                            setSelectedColumns(sheet.columns);
                        }
                    }
                }
            } else {
                // 开发环境模拟数据
                console.log('[DataMappingModal] electronAPI not available, using mock data');
                const mockSheets: SheetInfo[] = [
                    {
                        name: 'Sheet1',
                        columns: [
                            { letter: 'A', name: 'ID' },
                            { letter: 'B', name: '名称' },
                            { letter: 'C', name: '描述' },
                            { letter: 'D', name: '类型' },
                            { letter: 'E', name: '数量' },
                            { letter: 'F', name: '备注' },
                        ]
                    }
                ];
                setAvailableSheets(mockSheets);
                if (!mapping.sheetName) {
                    setMapping(prev => ({ ...prev, sheetName: mockSheets[0].name }));
                    setSelectedColumns(mockSheets[0].columns);
                }
            }
        } catch (error) {
            console.error('[DataMappingModal] Failed to fetch sheets:', error);
        } finally {
            setIsLoading(false);
        }
    }, [mapping.sheetName]);

    // 初始化时获取工作表列表
    useEffect(() => {
        if (isOpen) {
            fetchSheetsList();
        }
    }, [isOpen, fetchSheetsList]);

    // 工作表切换
    const handleSheetChange = (sheetName: string) => {
        const sheet = availableSheets.find(s => s.name === sheetName);
        if (sheet) {
            setMapping(prev => ({ ...prev, sheetName }));
            setSelectedColumns(sheet.columns);
        }
    };

    // 更新列映射
    const updateColumnMapping = (field: string, value: string) => {
        setMapping(prev => ({
            ...prev,
            columns: { ...prev.columns, [field]: value.toUpperCase() }
        }));
    };

    // 保存配置
    const handleSave = async () => {
        setIsSaving(true);
        try {
            // 持久化到 localStorage
            localStorage.setItem(storageKey, JSON.stringify(mapping));

            // 通知主窗口映射已配置
            if (window.electronAPI?.notifyMappingConfigured) {
                await window.electronAPI.notifyMappingConfigured(toolType, true);
            }

            // 回调通知父组件
            onConfirm(mapping);
            onClose();
        } catch (error) {
            console.error('[DataMappingModal] Failed to save mapping:', error);
        } finally {
            setIsSaving(false);
        }
    };

    // 重置为默认值
    const handleReset = () => {
        setMapping(defaultMapping);
    };

    if (!isOpen) return null;

    // 将字段分成两列显示
    const halfIndex = Math.ceil(fieldConfigs.length / 2);
    const leftFields = fieldConfigs.slice(0, halfIndex);
    const rightFields = fieldConfigs.slice(halfIndex);

    return (
        <div className="fixed inset-0 z-[100] flex items-center justify-center bg-black/80 backdrop-blur-sm">
            <div className="w-[850px] bg-[#0e0e0e] border border-white/10 flex flex-col relative shadow-2xl shadow-black/80 max-h-[90vh]">

                {/* 头部 */}
                <div className="h-14 flex items-center justify-between px-6 border-b border-white/10 bg-[#121212] shrink-0">
                    <div className="flex items-center gap-3">
                        <div className="w-1 h-5 bg-[#ff2a2a]" />
                        <h2 className="text-xl font-bold text-white tracking-wider">{title}</h2>
                        <span className="text-[10px] text-gray-500 font-mono tracking-widest">FIELD_MAPPING_PROTOCOL</span>
                    </div>
                    <button onClick={onClose} className="text-gray-500 hover:text-white transition-colors">
                        <X size={24} />
                    </button>
                </div>

                {/* 内容 */}
                <div className="p-8 space-y-8 overflow-y-auto flex-1">

                    {/* 目标工作表 */}
                    <div className="bg-[#151515] border border-white/5 p-6 rounded-sm">
                        <div className="flex items-center justify-between mb-4">
                            <label className="block text-[#ff2a2a] text-sm font-bold tracking-wide">目标工作表</label>
                            <button
                                onClick={fetchSheetsList}
                                disabled={isLoading}
                                className="flex items-center gap-2 text-xs text-gray-500 hover:text-[#ff2a2a] transition-colors disabled:opacity-50"
                            >
                                <RefreshCw size={14} className={isLoading ? 'animate-spin' : ''} />
                                刷新列表
                            </button>
                        </div>

                        <div className="relative">
                            <select
                                value={mapping.sheetName}
                                onChange={(e) => handleSheetChange(e.target.value)}
                                className="w-full h-12 bg-black border border-white/10 px-4 text-white appearance-none focus:border-[#ff2a2a] outline-none"
                            >
                                <option value="">请选择工作表...</option>
                                {availableSheets.map(sheet => (
                                    <option key={sheet.name} value={sheet.name}>{sheet.name}</option>
                                ))}
                            </select>
                            <div className="absolute right-4 top-1/2 -translate-y-1/2 w-0 h-0 border-l-[6px] border-l-transparent border-r-[6px] border-r-transparent border-t-[6px] border-t-gray-500 pointer-events-none" />
                        </div>

                        <div className="mt-4">
                            <label className="block text-gray-400 text-sm mb-2">数据起始行</label>
                            <div className="flex items-center gap-4">
                                <input
                                    type="number"
                                    value={mapping.startRow}
                                    onChange={(e) => setMapping(prev => ({ ...prev, startRow: parseInt(e.target.value) || 4 }))}
                                    min={1}
                                    className="w-32 h-10 bg-black border border-white/10 px-4 text-white focus:border-[#ff2a2a] outline-none font-mono"
                                />
                                <span className="text-xs text-gray-600">* 通常第一行为表头，第二行为类型，第三行为说明，数据从第4行开始</span>
                            </div>
                        </div>
                    </div>

                    {/* 字段映射 */}
                    <div>
                        <div className="flex items-center justify-between mb-6">
                            <h3 className="text-lg font-bold text-white flex items-center gap-3">
                                字段映射
                                <span className="text-xs text-gray-500 font-normal">(选择对应的列)</span>
                            </h3>
                            <button
                                onClick={handleReset}
                                className="text-xs text-gray-500 hover:text-[#ff2a2a] transition-colors"
                            >
                                重置为默认
                            </button>
                        </div>

                        <div className="grid grid-cols-2 gap-x-12 gap-y-6">
                            {/* 左列 */}
                            <div className="space-y-6">
                                {leftFields.map(({ key, label, code, required }) => (
                                    <div key={key} className="w-full">
                                        <div className="flex justify-between mb-2">
                                            <label className="text-gray-500 text-sm font-medium">
                                                {label}
                                                {required && <span className="text-[#ff2a2a] ml-1">*</span>}
                                            </label>
                                            <span className="text-[#ff2a2a] text-[10px] font-mono tracking-wider opacity-60">{code}</span>
                                        </div>
                                        <div className="flex bg-black border border-white/10 h-12 focus-within:border-[#ff2a2a] transition-colors">
                                            <div className="w-12 border-r border-white/10 flex items-center justify-center text-gray-600 font-mono text-xs bg-[#111]">
                                                col
                                            </div>
                                            <select
                                                value={mapping.columns[key] || ''}
                                                onChange={(e) => updateColumnMapping(key, e.target.value)}
                                                className="flex-1 bg-transparent px-4 text-white outline-none font-bold font-mono appearance-none cursor-pointer"
                                            >
                                                <option value="">选择列...</option>
                                                {selectedColumns.map(col => (
                                                    <option key={col.letter} value={col.letter}>
                                                        {col.letter} - {col.name}
                                                    </option>
                                                ))}
                                            </select>
                                        </div>
                                    </div>
                                ))}
                            </div>

                            {/* 右列 */}
                            <div className="space-y-6">
                                {rightFields.map(({ key, label, code, required }) => (
                                    <div key={key} className="w-full">
                                        <div className="flex justify-between mb-2">
                                            <label className="text-gray-500 text-sm font-medium">
                                                {label}
                                                {required && <span className="text-[#ff2a2a] ml-1">*</span>}
                                            </label>
                                            <span className="text-[#ff2a2a] text-[10px] font-mono tracking-wider opacity-60">{code}</span>
                                        </div>
                                        <div className="flex bg-black border border-white/10 h-12 focus-within:border-[#ff2a2a] transition-colors">
                                            <div className="w-12 border-r border-white/10 flex items-center justify-center text-gray-600 font-mono text-xs bg-[#111]">
                                                col
                                            </div>
                                            <select
                                                value={mapping.columns[key] || ''}
                                                onChange={(e) => updateColumnMapping(key, e.target.value)}
                                                className="flex-1 bg-transparent px-4 text-white outline-none font-bold font-mono appearance-none cursor-pointer"
                                            >
                                                <option value="">选择列...</option>
                                                {selectedColumns.map(col => (
                                                    <option key={col.letter} value={col.letter}>
                                                        {col.letter} - {col.name}
                                                    </option>
                                                ))}
                                            </select>
                                        </div>
                                    </div>
                                ))}
                            </div>
                        </div>
                    </div>

                </div>

                {/* 底部 */}
                <div className="h-20 border-t border-white/10 flex items-center justify-end px-8 gap-4 bg-[#121212] shrink-0">
                    <button
                        onClick={onClose}
                        className="px-8 py-3 border border-white/10 text-gray-400 hover:text-white hover:bg-white/5 transition-colors tracking-widest"
                    >
                        取消
                    </button>
                    <button
                        onClick={handleSave}
                        disabled={!mapping.sheetName || isSaving}
                        className="px-8 py-3 bg-[#ff2a2a] hover:bg-[#ff4444] text-black font-bold tracking-widest transition-colors flex items-center gap-2 disabled:opacity-50 disabled:cursor-not-allowed"
                    >
                        <Check size={18} />
                        {isSaving ? '保存中...' : '保存配置'}
                    </button>
                </div>
            </div>
        </div>
    );
}
```

```typescript
// 在 App.tsx 中使用
import { TaskFieldMapping, DEFAULT_TASK_MAPPING, STORAGE_KEY_MAPPING } from './types';

// 从 localStorage 加载
const [fieldMapping, setFieldMapping] = useState<TaskFieldMapping>(() => {

        return DEFAULT_TASK_MAPPING;

// 检查映射是否已配置
const [isMappingConfigured, setIsMappingConfigured] = useState(false);

useEffect(() => {
    const configured = !!fieldMapping.sheetName && 
                       !!fieldMapping.columns.id && 
                       !!fieldMapping.columns.title;
    setIsMappingConfigured(configured);
}, [fieldMapping]);

// 处理映射确认
const handleMappingConfirmed = useCallback((mapping: TaskFieldMapping) => {
    setFieldMapping(mapping);
```

## 📊 数据解析示例

### 完整的数据解析流程

```typescript
// App.tsx
import { colToIndex, TaskFieldMapping } from './types';

// 解析表格数据
const parseAndLoadData = useCallback((sheetData: any[][]) => {
    if (!sheetData || sheetData.length === 0) {
        console.warn('[App] 收到空数据');
        return;
    }

    const { startRow, columns } = fieldMapping;
    const parsedItems: Mission[] = [];

    // 从 startRow 开始遍历 (注意: startRow 是 1-indexed)
    for (let i = startRow - 1; i < sheetData.length; i++) {
        const row = sheetData[i];
        if (!row) continue;

        // 获取 ID (必填字段)
        const idIdx = colToIndex(columns.id);
        const id = row[idIdx];
        if (!id) continue; // 跳过空行

        // 解析其他字段
        const item: Mission = {
            id: String(id),
            title: row[colToIndex(columns.title)] || '未命名',
            description: row[colToIndex(columns.description)] || '',
            type: row[colToIndex(columns.type)]?.toString().toUpperCase() === 'WEEKLY' 
                  ? MissionType.WEEKLY 
                  : MissionType.DAILY,
            status: MissionStatus.IN_PROGRESS,
            currentProgress: 0,
            maxProgress: parseInt(row[colToIndex(columns.maxProgress)]) || 1,
            category: row[colToIndex(columns.category)] || 'System',
            rewards: [{
                type: row[colToIndex(columns.rewardType)] || '经验',
                amount: parseInt(row[colToIndex(columns.rewardAmount)]) || 100,
                icon: row[colToIndex(columns.rewardIcon)] || '🎁'
            }]
        };

        parsedItems.push(item);
    }

    if (parsedItems.length > 0) {
        setMissions(parsedItems);
        showToast(`成功加载 ${parsedItems.length} 个任务`);
    }
}, [fieldMapping]);
```

## 🆕 按"表格结构配置"动态创建表格

ConfigNexus 的表头结构（多少行表头、每行什么角色、什么标签）由用户在 **设置 → 编辑器 → 表格结构配置** 里决定，预设有「精简(3行) / 标准(5行) / 前后端分离(5行) / 完整(7行) / 含批注(5行)」，也支持单表覆盖。

**组件创建表格时不能再写死"前 3 行是字段名 / 类型 / 中文名"了**，否则用户调成"完整"7 行预设后，组件创建出的表只有 3 行表头，跟用户其他配置表对不上，导入导出都会乱。

### 推荐写法：声明式 `cnx.createTable`

只声明"列定义"，让 SDK 自动按当前 schema 铺表头：

```typescript
import { cnx } from '../_shared/sdk/confignexus-sdk';

const handleCreateTable = async () => {
  const columns = [
    { fieldName: 'id',      fieldNameCN: '物品ID',   dataType: 'int',    description: '物品唯一 ID' },
    { fieldName: 'name',    fieldNameCN: '名称key',  dataType: 'string', description: '名称多语言 key' },
    { fieldName: 'quality', fieldNameCN: '品质',     dataType: 'int',    description: '品质等级' },
    { fieldName: 'price',   fieldNameCN: '售价',     dataType: 'int',    description: '出售价格' },
  ];

  const rows = items.map(item => [item.id, item.name, item.quality, item.price]);

  await cnx.createTable({
    toolType: 'bag',
    tableName: 'ItemData',
    columns,   // 关键：声明列，不再手动 push celldata
    rows,      // 数据二维数组（顺序与 columns 一致）
  });
};
```

SDK 内部会：

1. 调 `cnx.getTableSchema()` 拉当前用户配置
2. 按 `schema.rows[]` 顺序铺表头 —— `fieldName` 行填 `column.fieldName`、`dataType` 行填 `column.dataType`、`description` 行填 `column.description` …
3. 数据从 `schema.dataStartRow` 起塞
4. 调老的 `tool:create-table` 通道送给主窗口

用户切到「精简(3行)」就只有 3 行表头，切到「完整(7行)」就 7 行——同一份组件代码不变。

### `ColumnDef` 字段对应表

| ColumnDef 字段 | 对应 schema 角色 | 必备 | 说明 |
|---|---|---|---|
| `fieldName` | `fieldName` | ✅ | 英文字段名/导出 key |
| `dataType` | `dataType` | ✅ | int / string / list&lt;int&gt; / json ... |
| `fieldNameCN` | `fieldNameCN` | 推荐 | 中文字段名 |
| `description` | `description` | 推荐 | 描述/备注 |
| `validation` | `validation` | 可选 | 数据验证 DSL |
| `defaultValue` | `defaultValue` | 可选 | 单元格为空时的默认值 |
| `exportTarget` | `exportTarget` | 可选 | `s` / `c` / `sc`，默认 `sc` |
| `comment` | `comment` | 可选 | 策划注释行 |

只填 `fieldName + dataType` 也能跑，对应没声明的行会留空——下次用户编辑表格时再补即可。

### 兼容老签名

老写法（直接传完整 `data.sheets`）**仍然支持**，但**不推荐**——表头是写死的，跟随不上用户配置：

```typescript
// ⚠️ 不推荐：表头硬编码 3 行，用户切到 7 行预设就会"两套表头"对不齐
await cnx.createTable({
  toolType, tableName,
  data: { sheets: [{ name, celldata: [...手动 push...], row, column, config: {} }] }
});
```

新组件一律用声明式 `columns + rows`。老组件迁移参考 `app/talent_app/index.tsx` 的 `handleCreateTable` 和 `app/bag_app/components/SettingsModal.tsx` 的 `handleCreateTable` 改造前后对比（git history）。

### 高级：直接读 schema 自定义渲染

如果组件需要在创建表前展示一份预览，或者要按 schema 单独画 UI，可以直接调 `cnx.getTableSchema()`：

```typescript
const { success, schema } = await cnx.getTableSchema();
if (success && schema) {
  // schema.default.rows[] 是当前默认表头行的角色顺序
  // schema.overrides[tableName] 是单表覆盖（如果用户配置过）
  // schema.default.dataStartRow 是数据起始行（0-indexed）
}
```

还可以直接调 helper 自己拼 sheet 对象：

```typescript
import { cnx } from '../_shared/sdk/confignexus-sdk';

const { schema } = await cnx.getTableSchema();
const sheet = cnx.buildSheetFromSchema(schema, {
  tableName: 'ItemData',
  columns,
  rows,
});
// sheet 是合法的 Luckysheet sheet 对象，可以直接塞到 cnx.createTable 的 data.sheets 里
```

### 检查清单（新组件创建表格）

- [ ] 用 `columns + rows` 声明式签名，不手动构造 `celldata`
- [ ] 每个 column 至少填 `fieldName + dataType`，推荐补 `fieldNameCN + description`
- [ ] 不假设表头有几行（不在数据行下标里写死 `r + 3`）
- [ ] 数据二维数组的列顺序与 `columns` 完全一致
- [ ] 如果该组件有"独立 schema 偏好"（很少见），传 `schemaOverrideKey` 指定 override

## 🔁 写回数据：`cnx.updateTable` 也跟随动态配置

跟 `createTable` 同一套思路。组件改了节点位置 / 数据后要写回到主窗口表格时，**不要假设数据从第 4 行起**，把决定权交给"表格结构配置"。

### 推荐写法：声明式 `cnx.updateTable`

```typescript
import { cnx } from '../_shared/sdk/confignexus-sdk';

const handleSyncToTable = async () => {
  const columns = [
    { fieldName: 'id',      fieldNameCN: 'ID',       dataType: 'int' },
    { fieldName: 'shape',   fieldNameCN: '形状',     dataType: 'int' },
    { fieldName: 'groupId', fieldNameCN: '天赋组',   dataType: 'string' },
    { fieldName: 'pre',     fieldNameCN: '前置节点', dataType: 'list<int>' },
    { fieldName: 'next',    fieldNameCN: '后置节点', dataType: 'list<int>' },
    { fieldName: 'pos',     fieldNameCN: '位置',     dataType: 'list<int>' },
  ];

  const rows = tableData.map(t => [t.id, t.shape, t.groupId, t.pre, t.next, [t.x, t.y]]);

  await cnx.updateTable({
    toolType: 'talent',
    tableName: 'Talent',
    columns,   // 跟 createTable 完全对齐
    rows,      // 二维数组，顺序与 columns 一致
  });
};
```

SDK 内部会：
1. 调 `cnx.getTableSchema()` 拉当前 schema
2. 按 `tableName` 找 override 或走 default，取 `dataStartRow`（如果用户切到「完整(7 行)」就是从第 8 行起，「精简(3 行)」就是从第 4 行起）
3. 按 `columns` 顺序赋列字母（A/B/C…）
4. 把 `rows` 通过 `tool:update-table` 写回主窗口

**用户随便切表头预设，写回位置自动跟随，组件代码不动。**

### 单元格值的自动转换

| 字段类型 | 单元格里的形态 |
|---|---|
| `number` / `string` | 原样 |
| `Array`（如 `[1,2,3]`） | 写成 `[1,2,3]` 字符串 |
| `Object` | 写成 JSON 字符串 |
| `null` / `undefined` | 空 |

所以 `pos: [x, y]` 这种数组字段直接传，SDK 和主进程会自动转 `"[1,2]"`，与 `createTable` 表头中声明的 `list<int>` 一致。

### 兼容老签名

如果组件保留了 MappingModal 让用户手填 `sheetName / startRow / columns map`，**老签名仍然支持**：

```typescript
await cnx.updateTable('talent', { sheetName, startRow, columns: { id: 'A', shape: 'B' } }, dataArray);
```

但**不推荐新组件用**——startRow 写死的话，用户改了表格结构配置后会写错位（数据写到表头上）。

### main 进程已经做的兜底

即便用了老签名但 `startRow` 缺失（= 0 或 undefined），主进程的 `tool:update-table` 监听器会**自动按当前 sheet 的 schema 算出 `dataStartRow + 1` 作为 startRow**。所以"忘了配 startRow" 也不会写表头。

### 检查清单（写回数据）

- [ ] 用声明式签名 `{ toolType, tableName, columns, rows }`
- [ ] 不在组件代码里假设 `startRow = 4`
- [ ] `columns` 和 `createTable` 保持一致（同一张表）
- [ ] 数组/对象字段直接传，让 SDK 处理序列化
