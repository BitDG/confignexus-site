## 🎯 方案目标

本方案基于 `task_app`、`bag_app`、`mail_app` 三个生产应用的实际实现，提取了共同的设计模式和最佳实践。

1. **统一技术栈**：所有组件均使用 `React + Vite + TailwindCSS` 技术栈
2. **共享依赖**：统一使用 `app/node_modules` 避免重复安装
3. **规范接口**：使用统一的 IPC API 实现窗口管理和数据同步
4. **标准映射**：提供字段映射弹窗模板，快速对接 ConfigNexus 数据
5. **一致体验**：确保所有组件具有 **Cyberpunk 风格** 的 UI/UX 风格

## 🔑 关键概念

### 1. 工具类型 (toolType)

每个组件都有唯一的工具类型标识，在 `metadata.json` 中配置：

| toolType | 组件 | 说明 |
|----------|------|------|
| `task` | task_app | 任务系统 |
| `bag` | bag_app | 背包系统 |
| `mail` | mail_app | 邮件系统 |
| `dialogue` | dialogue_app | 对话组件 |
| `talent` | talent_app | 天赋编辑器 |

### 2. 字段映射 (FieldMapping)

每个组件定义自己的字段映射结构，用于从 ConfigNexus 表格提取数据：

```typescript
interface FieldMapping {
    sheetName: string;      // 目标工作表名称
    startRow: number;       // 数据起始行（1-indexed）
    columns: {              // 列映射
        [fieldName: string]: string;  // 字段名 -> 列字母
    };
}
```

### 3. 同步数据格式 (SyncPayload)

组件接收的同步数据统一格式：

```typescript
interface SyncPayload {
    sheetData: {
        [sheetName: string]: any[][];  // 工作表名 -> 二维数组（原始数据）
    };
    timestamp: number;
}
```

### 4. UI 设计系统 (Cyberpunk Style)

所有组件遵循统一的 Cyberpunk 风格设计系统：

| 元素 | 规范值 |
|------|--------|
| 主色调 | `#ff2a2a` (红色) |
| 背景色 | `#050505` / `#0a0a0a` |
| 边框 | `border-white/10` |
| 切角样式 | `clip-path: polygon(...)` |
| 字体 | Inter, JetBrains Mono |

## 🚀 快速开始

### 在 Google AI Studio 中创建新组件

1. **复制组件模板目录** (参考 task_app)
2. **修改 `metadata.json`** - 设置唯一的 name 和 toolType
3. **配置 `types.ts`** - 定义数据类型和字段映射
4. **实现 `App.tsx`** - 主组件逻辑
5. **创建 `components/`** - 子组件 (TopBar, Sidebar, ItemCard 等)
6. **配置样式 `index.css`** - Cyberpunk 主题变量

详见 [08_开发流程指南](./08_开发流程指南.md)

#### types.ts (基本结构)

```typescript
// 字段映射接口
export interface MyFieldMapping {
    sheetName: string;
    startRow: number;
    columns: {
        id: string;
        name: string;
        // ... 其他字段
    };
}

// 默认映射
export const DEFAULT_MY_MAPPING: MyFieldMapping = {
    sheetName: '',
    startRow: 4,
    columns: {
        id: 'A',
        name: 'B',
    }
};

// 存储键
export const STORAGE_KEY_MAPPING = 'my_app_field_mapping';

// 列号转换
export const colToIndex = (col: string): number => {
    if (!col) return -1;
    col = col.toUpperCase();
    let idx = 0;
    for (let i = 0; i < col.length; i++) {
        idx = idx * 26 + (col.charCodeAt(i) - 64);
    }
    return idx - 1;
};
```
