# 06 数据格式规范

> 本文档定义了组件间数据传输的标准格式。

---

## 📊 同步数据格式

### SyncPayload 结构

```typescript
interface SyncPayload {
    toolType: string;
    sheetData: {
        [sheetName: string]: any[][];
    };
    timestamp: number;
}
```

### 示例

```json
{
    "toolType": "dialogue",
    "sheetData": {
        "DialogueConfig": [
            ["ID", "Type", "Name", "NextID", "Dialog"],
            [1001, 1, "角色A", 1002, "你好！"],
            [1002, 2, "", null, "旁白文本"]
        ]
    },
    "timestamp": 1702900000000
}
```

## 🔢 特殊数据类型

### 数组格式

表格中的数组使用方括号表示：

```
[100,101,102]  -> ['100', '101', '102']
[A, B, C]      -> ['A', 'B', 'C']
```

### 坐标格式

```
[50, 100]  -> { x: 50, y: 100 }
```

### JSON 选项格式

```json
[{"选项A": 1001}, {"选项B": 1002}]
```

## ✅ 数据验证

```typescript
const validateSyncPayload = (payload: any): boolean => {
    if (!payload || typeof payload !== 'object') return false;
    if (!payload.toolType || typeof payload.toolType !== 'string') return false;
    if (!payload.sheetData || typeof payload.sheetData !== 'object') return false;
    if (typeof payload.timestamp !== 'number') return false;
    return true;
};
```
