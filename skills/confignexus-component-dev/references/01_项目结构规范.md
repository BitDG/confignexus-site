# 01 项目结构规范

> 本文档定义了 ConfigNexus 组件的标准目录结构和文件命名规范。

---

## 📁 标准组件目录结构

```
app/
├── [组件名称]/                    # 使用下划线命名法
│   ├── dist/                     # 构建输出目录
│   │   ├── index.html
│   │   └── assets/
│   ├── index.html                # 入口 HTML 文件
│   ├── index.tsx                 # React 入口文件（主组件）
│   ├── index.css                 # 样式文件
│   ├── metadata.json             # 组件元数据
│   ├── package.json              # 组件配置
│   ├── vite.config.ts            # Vite 配置
│   ├── tsconfig.json             # TypeScript 配置
│   ├── tailwind.config.js        # TailwindCSS 配置
│   ├── postcss.config.js         # PostCSS 配置
│   ├── build.bat                 # 构建脚本
│   └── start.bat                 # 开发启动脚本
```

---

## 📄 核心文件说明

### 1. `metadata.json` - 组件元数据

```json
{
    "name": "component_name",
    "version": "0.0.1",
    "description": "组件描述",
    "author": "ConfigNexus Team",
    "toolType": "unique_tool_type",
    "category": "tool",
    "icon": "lucide-icon-name",
    "devPort": 5174,
    "keywords": ["keyword1", "keyword2"],
    "configNexusVersion": "1.0.0"
}
```

**字段说明：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | string | ✅ | 组件唯一标识，使用下划线命名法 |
| `version` | string | ✅ | 语义化版本号 |
| `description` | string | ✅ | 组件功能描述 |
| `author` | string | ❌ | 作者信息 |
| `toolType` | string | ✅ | 工具类型，用于 IPC 通信标识 |
| `category` | string | ✅ | 分类：`tool`（工具）/ `editor`（编辑器） |
| `icon` | string | ❌ | Lucide 图标名称 |
| `devPort` | number | ✅ | 开发服务器端口号（避免冲突） |
| `keywords` | array | ❌ | 搜索关键词 |
| `configNexusVersion` | string | ✅ | 兼容的 ConfigNexus 版本 |

### 2. `index.html` - 入口页面

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>组件名称</title>
    <link rel="stylesheet" href="./index.css">
</head>
<body>
    <div id="root" class="h-screen w-screen"></div>
    <script type="module" src="./index.tsx"></script>
</body>
</html>
```

### 3. `index.tsx` - React 入口

```tsx
import React, { useState, useEffect } from 'react';
import { createRoot } from 'react-dom/client';
import './index.css';

// 类型定义
interface FieldMapping {
    sheetName: string;
    startRow: number;
    columns: {
        // 组件特定字段
    };
}

// 主组件
function App() {
    // 状态管理
    const [fieldMapping, setFieldMapping] = useState<FieldMapping>({
        sheetName: '',
        startRow: 4,
        columns: {}
    });
    
    // IPC 监听
    useEffect(() => {
        // 监听数据同步
        const handleReceiveSync = (event: Event) => {
            const customEvent = event as CustomEvent;
            // 处理同步数据
        };
        
        window.addEventListener('tool:receive-sync', handleReceiveSync);
        return () => window.removeEventListener('tool:receive-sync', handleReceiveSync);
    }, [fieldMapping]);
    
    return (
        <div className="h-screen w-screen">
            {/* 组件内容 */}
        </div>
    );
}

// 渲染
const container = document.getElementById('root');
if (container) {
    createRoot(container).render(<App />);
}
```

## 📦 `package.json` 模板

```json
{
    "name": "component_name",
    "private": true,
    "version": "0.0.1",
    "description": "组件描述",
    "type": "module",
    "scripts": {
        "dev": "vite",
        "build": "vite build",
        "preview": "vite preview"
    },
    "dependencies": {},
    "devDependencies": {}
}
```

> ⚠️ **注意**：`dependencies` 和 `devDependencies` 留空，所有依赖由 `app/node_modules` 提供。

## 📝 命名规范

### 目录命名

| 类型 | 规范 | 示例 |
|------|------|------|
| 组件目录 | 下划线命名法 | `dialogue_component`, `talent_app` |
| 输出目录 | 固定使用 `dist` | `dist/` |
| 资源目录 | 固定使用 `assets` | `assets/` |

### 文件命名

| 类型 | 规范 | 示例 |
|------|------|------|
| 入口文件 | 固定命名 | `index.html`, `index.tsx`, `index.css` |
| 配置文件 | 标准命名 | `vite.config.ts`, `tsconfig.json` |
| 元数据 | 固定命名 | `metadata.json` |
| 脚本文件 | 功能命名 | `build.bat`, `start.bat` |

### 工具类型 (toolType)

| 规范 | 示例 |
|------|------|
| 小写字母 | `talent`, `dialogue` |
| 单词用下划线分隔 | `skill_tree`, `item_editor` |
| 简洁明确 | ~~`game_dialogue_editor_component`~~ → `dialogue` |
