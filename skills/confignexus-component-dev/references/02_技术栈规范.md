## ⚙️ Vite 配置

### `vite.config.ts` 标准模板

```typescript
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';
import tailwindcss from '@tailwindcss/vite';
import { resolve } from 'path';

export default defineConfig({
    // 插件配置
    plugins: [
        react(),
        tailwindcss()
    ],
    
    // 基础路径（构建后使用相对路径）
    base: './',
    
    // 构建配置
    build: {
        outDir: 'dist',
        emptyOutDir: true,
        assetsDir: 'assets',
        sourcemap: false,
        rollupOptions: {
            input: {
                main: resolve(__dirname, 'index.html'),
            },
        },
    },
    
    // 开发服务器配置
    server: {
        port: 5174,         // 使用 metadata.json 中定义的端口
        strictPort: false,  // 端口占用时自动递增
        open: true,         // 自动打开浏览器
        host: '0.0.0.0',    // 允许局域网访问
    },
    
    // 路径别名（可选）
    resolve: {
        alias: {
            '@': resolve(__dirname, '.'),
        }
    },
});
```

### 关键配置说明

| 配置项 | 值 | 说明 |
|--------|-----|------|
| `base` | `'./'` | **必须**：确保构建后使用相对路径，在 Electron 中正确加载 |
| `build.outDir` | `'dist'` | 输出到 dist 目录 |
| `build.emptyOutDir` | `true` | 构建前清空输出目录 |
| `server.port` | 按组件分配 | 避免端口冲突，参考 metadata.json |

## 🎨 TailwindCSS 配置

### `tailwind.config.js` 标准模板

```javascript
/** @type {import('tailwindcss').Config} */
export default {
    content: [
        './*.html',
        './*.tsx',
        './*.ts',
    ],
    darkMode: 'class',
    theme: {
        extend: {
            // 自定义主题扩展
        },
    },
    plugins: [],
};
```

### `postcss.config.js` 标准模板

```javascript
export default {
    plugins: {
        '@tailwindcss/postcss': {},
    },
};
```

> ⚠️ **注意**：TailwindCSS v4 使用 `@tailwindcss/postcss` 而非 `tailwindcss` 和 `autoprefixer`。

### `index.css` 标准模板

```css
@import "tailwindcss";

/* 自定义全局样式 */

    margin: 0;
    padding: 0;
    box-sizing: border-box;
}

    50% { transform: translateY(-8px); }
}

.animate-bounce-indicator {
    animation: bounce-indicator 1s infinite;
}
```

## 📦 端口分配规范

为避免开发时端口冲突，各组件使用不同端口：

| 组件 | 端口 |
|------|------|
| talent_app | 3000 |
| dialogue_app | 5174 |
| 新组件1 | 5175 |
| 新组件2 | 5176 |
| ... | 依次递增 |
