# 10 资源加载规范

> 本文档定义了 ConfigNexus 组件中图片、视频等美术资源的加载规范。

---

## 📍 资源类型支持

| 类型 | 格式 | 说明 |
|------|------|------|
| **网络资源** | `http://` / `https://` | CDN 图片、在线资源 |
| **本地资源** | `file://` / 绝对路径 | 本地文件系统 |
| **Base64** | `data:` | 内嵌 Base64 数据 |
| **相对路径** | `./` | 相对组件目录 |

---

## 🔧 通用解析函数

### resolveImageUrl

统一处理各种资源 URL 格式的工具函数：

```typescript
/**
 * 解析图片 URL，支持 HTTP 网络图片和本地文件路径
 * - HTTP/HTTPS URL: 直接返回
 * - 本地绝对路径: 转换为 file:// 协议
 * - 相对路径: 转换为 file:// 协议（基于应用根目录）
 * - 空值: 返回空字符串
 */
export function resolveImageUrl(url: string | undefined): string {
    if (!url || url.trim() === '') return '';

    const trimmedUrl = url.trim();

    // 1. HTTP/HTTPS URL - 直接返回
    if (trimmedUrl.startsWith('http://') || trimmedUrl.startsWith('https://')) {
        return trimmedUrl;
    }

    // 2. file:// 协议 - 直接返回
    if (trimmedUrl.startsWith('file://')) {
        return trimmedUrl;
    }

    // 3. Base64 data URL - 直接返回
    if (trimmedUrl.startsWith('data:')) {
        return trimmedUrl;
    }

    // 4. Windows 绝对路径 (C:\path\image.png)
    if (trimmedUrl.length > 2 && trimmedUrl[1] === ':') {
        const normalizedPath = trimmedUrl.replace(/\\/g, '/');
        return `file:///${normalizedPath}`;
    }

    // 5. Unix 绝对路径 (/home/user/images)
    if (trimmedUrl.startsWith('/')) {
        return `file://${trimmedUrl}`;
    }

    // 6. 相对路径 - 尝试获取应用路径
    try {
        if ((window as any).electronAPI?.getAppPath) {
            const appPath = (window as any).electronAPI.getAppPath();
            if (appPath) {
                const fullPath = `${appPath}/${trimmedUrl.replace(/^\.\//, '')}`.replace(/\\/g, '/');
                return `file:///${fullPath}`;
            }
        }
    } catch (e) {
        console.warn('[resolveImageUrl] 获取应用路径失败:', e);
    }

    // 7. 回退：基于当前页面 URL
    try {
        const base = window.location.href.substring(0, window.location.href.lastIndexOf('/') + 1);
        if (base.startsWith('file://')) {
            return `${base}${trimmedUrl.replace(/^\.\//, '')}`;
        }
    } catch (e) {
        // 忽略错误
    }

    return trimmedUrl;
}
```

## 📁 本地资源加载

### Windows 路径转换

| 原始路径 | 转换后 |
|----------|--------|
| `C:\Users\art\bg.png` | `file:///C:/Users/art/bg.png` |
| `D:/images/character.jpg` | `file:///D:/images/character.jpg` |

### Unix 路径转换

| 原始路径 | 转换后 |
|----------|--------|
| `/home/user/images/bg.png` | `file:///home/user/images/bg.png` |

### 相对路径转换

需要应用基础路径：

```typescript
// 假设应用路径为 C:/app/dialogue_app
'./assets/bg.png' → 'file:///C:/app/dialogue_app/assets/bg.png'
'images/icon.svg' → 'file:///C:/app/dialogue_app/images/icon.svg'
```

## 🌐 网络资源加载

### 直接使用

```typescript
const imageUrl = resolveImageUrl('https://example.com/image.png');
// 返回: 'https://example.com/image.png'
```

### CDN 图片示例

```typescript
const bgUrl = "https://cdn.example.com/images/background.jpg";
const characterUrl = "https://cdn.example.com/images/character.png";
```

## 🖼️ 在 React 组件中使用

### 基础用法

```tsx
import { resolveImageUrl } from './utils/helpers';

function ImageComponent({ src }: { src: string }) {
    const resolvedSrc = resolveImageUrl(src);
    
    return (
        <img 
            src={resolvedSrc} 
            alt="resource"
            onError={(e) => {
                console.error('图片加载失败:', src);
                // 可设置默认图片
            }}
        />
    );
}
```

### 背景图片用法

```tsx
function BackgroundContainer({ bgUrl }: { bgUrl: string }) {
    const resolvedBg = resolveImageUrl(bgUrl);
    
    return (
        <div 
            className="w-full h-full bg-cover bg-center"
            style={{ backgroundImage: `url(${resolvedBg})` }}
        />
    );
}
```
