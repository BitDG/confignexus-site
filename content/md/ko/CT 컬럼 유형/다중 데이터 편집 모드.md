# 다중 데이터 편집 모드

보상 목록, 속성 조합 등 단일 셀 내에서 복잡한 다중 데이터 구성을 관리합니다.

## 열기 방법

1. 셀 선택 → 오른쪽 클릭 메뉴 → CT 속성 → 다중 데이터 편집기로 설정
2. 해당 열이 다중 데이터 편집기로 설정됩니다
3. 처음 3행을 제외하고 셀을 더블 클릭하면 다중 데이터 편집기 인터페이스가 열립니다

video: Res/zh/videos/多数据编辑器打开.webm|다중 데이터 편집기 열기


## 데이터 설정

보상 데이터 예시: `[{1001:100:30},{1002:200:60},{1003:300:90}]`

형식: 보상ID:수량:가중치

### 작업 단계

1. 먼저 열을 다중 데이터 편집기로 설정
2. 입력할 셀을 더블 클릭하여 다중 데이터 편집기 팝업 열기
3. 해당 열을 오른쪽 클릭하여 열 속성 설정, +를 클릭하여 새 열 생성

video:Res/zh/videos/多数据编辑器设置列.webm|다중 데이터 편집기 열 설정

4. 해당 데이터 입력, "새 행"을 클릭하여 행 데이터 추가

video:Res/zh/videos/多数据编辑器编辑数据.webm|다중 데이터 편집기 데이터 편집

## 고급 작업

> [!TIP]
> - `item`이나 `reward` 같은 필드는 설정 탭에서 **매핑 테이블**로 설정할 수 있습니다
> - 설정 후 셀을 더블 클릭하면 해당 ID 이름이 표시되어 선택 오류를 줄일 수 있습니다
> - 버튼을 통해 해당 ID 구성을 빠르게 추가할 수도 있습니다
