# 날짜 편집기

전용 날짜 선택 및 편집 인터페이스로, 수동 입력 시 날짜 형식 오류를 방지합니다.

createtab:Res/zh/templates/日期编辑演示.cnx

## 기능 개요

| 기능 | 설명 |
|------|------|
| 캘린더 UI | 시각적 캘린더 인터페이스에서 날짜를 선택 |
| 다양한 날짜 형식 | `YYYY-MM-DD`, `YYYY/MM/DD`, 타임스탬프 등 다양한 형식 지원 |
| 빠른 선택 | 오늘, 어제, 이번 주 시작 등 빠른 날짜 선택 기능 |
| 셀 내 편집 | 더블 클릭으로 셀에서 직접 날짜 편집기 열기 |

## 설정 방법

1. 셀 선택 → 오른쪽 클릭 메뉴 → CT 속성 → 날짜 편집기로 설정
2. 해당 열이 날짜 편집기로 설정됩니다
3. 처음 3행(헤더)을 제외하고 셀을 더블 클릭하면 날짜 선택 인터페이스가 열립니다

## 지원되는 날짜 형식

| 형식 | 예시 |
|------|------|
| `YYYY-MM-DD` | 2026-04-17 |
| `YYYY/MM/DD` | 2026/04/17 |
| `YYYY-MM-DD HH:mm:ss` | 2026-04-17 14:30:00 |
| Unix 타임스탬프 | 1776624600 |

## 빠른 선택 옵션

- 오늘 / 어제
- 이번 주 시작 / 이번 달 시작
- 사용자 정의 날짜 직접 입력

## 사용 팁

> [!TIP]
> - 날짜 형식은 열 단위로 설정되며, 같은 열의 모든 데이터 셀에 적용됩니다
> - 처음 3행은 헤더 영역으로 날짜 편집기가 활성화되지 않습니다
> - 키보드 방향키로 캘린더 내에서 빠르게 이동할 수 있습니다
