# 리치 텍스트 편집 모드

Notion과 같은 리치 텍스트 편집 경험을 제공합니다.

## 열기 방법

1. 셀 선택 → 오른쪽 클릭 메뉴 → CT 속성 → 리치 텍스트 편집기로 설정
2. 해당 열이 리치 텍스트 편집기로 설정됩니다
3. 처음 3행을 제외하고 셀을 더블 클릭하면 리치 텍스트 편집기 인터페이스가 열립니다

## 리치 텍스트 편집

### 단축키 작업

- `/`를 입력하여 목록, 제목 등의 구조 생성

video:Res/zh/videos/富文本编辑器-排版.webm|리치 텍스트 편집기 편집

> [!NOTE]
> "이 열은 리치 텍스트 열"이라는 설정(CT 속성)은 열의 메타데이터로 `.cnx`에 저장되며, 별도 필드로 내보내지지 않습니다. `.cnx`로 저장하면 열 타입이 유지되지만 `.xlsx`로 저장하면 사라집니다. [[cnx 프로젝트 파일]] 참고.
