# 리소스 편집기

전문적인 게임 리소스 관리 및 편집 기능으로, 시각적 인터페이스를 통해 리소스를 미리보기하고 관리합니다.

## 기능 개요

| 기능 | 설명 |
|------|------|
| 이미지 미리보기 | 셀에서 이미지 리소스를 직접 미리보기 |
| 오디오 재생 | 오디오 파일을 편집기 내에서 바로 재생 |
| 폴더 관리 | 리소스 폴더를 설정하고 트리 구조로 탐색 |
| 검색 및 이름 변경 | 리소스를 키워드로 검색하고 이름을 변경 |

## 설정 방법

1. 셀 선택 → 오른쪽 클릭 메뉴 → CT 속성 → 리소스 편집기로 설정
2. 셀을 더블 클릭하여 리소스 선택 인터페이스를 엽니다

## 리소스 유형 지원

| 유형 | 지원 형식 |
|------|-----------|
| 이미지 | PNG, JPG, WebP, SVG 등 |
| 오디오 | MP3, WAV, OGG 등 |
| 기타 | 모든 파일 경로 참조 |

## 사용 방법

1. 리소스 폴더 경로를 설정합니다
2. 리소스 편집기에서 트리 구조로 파일을 탐색합니다
3. 원하는 리소스를 선택하면 경로가 자동으로 셀에 입력됩니다
4. 이미지 리소스는 미리보기, 오디오 리소스는 재생 버튼으로 확인 가능합니다

## 검색 기능

리소스 편집기 상단의 검색창에서 파일 이름으로 빠르게 리소스를 검색할 수 있습니다. 검색 결과에서 바로 선택하여 셀에 적용할 수 있습니다.
