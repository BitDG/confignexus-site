# 테이블 비교

"최종_최종_V3_수정완료.xlsx"를 받았을 때 가장 두려운 것은 손에 든 이 버전과 대조하는 일입니다 — 두 테이블 모두 수백 행이라 눈으로 한 행씩 훑거나 Excel의 VLOOKUP으로 임시방편을 쓸 수밖에 없고, 반나절을 들여도 빠뜨리기 쉽습니다. 테이블 비교는 두 파일을 놓으면 어느 셀이 바뀌었고 무엇으로 바뀌었는지 셀 단위로 알려 줍니다, 문자 단위 정밀도로, 5000행도 안 끊깁니다.

두 xlsx / cnx 파일, 또는 같은 파일의 두 버전 사이를 **셀 단위로 비교**합니다 — 어느 셀이 바뀌었고, 무엇으로 바뀌었고, 누가 행을 추가했고, 누가 열을 삭제했는지 한눈에 보입니다.

> [!IMPORTANT]
> 테이블 비교는 **독립 DLC 도구**로, Steam에서 별도로 받아야 합니다. DLC를 설치해야 아래에서 말하는 진입점이 나타납니다.

## 기능 개요

| 기능 | 설명 |
|------|------|
| 문자 단위 diff | 셀 내 텍스트를 문자별로 변화 강조(셀 전체 highlight가 아님) |
| 토큰 단위 diff | 숫자 / JSON / 배열을 토큰으로 나눠 오판 방지 |
| 3단계 흐름 | 폴더 선택 → 차이 파일 목록 보기 → 구체적 셀 diff 보기 |
| 모듈 A: 팝업 | 단일 파일 비교, 팝업 형식 |
| 모듈 B: 독립 창 | 폴더 간 비교, 독립 창 |
| Git / SVN 통합 | "작업 영역 버전 vs HEAD 버전" 직접 비교 |

## 세 가지 여는 방법

### 방식 1: 메뉴 → 테이블 비교

메인 창 메뉴 바 **📊 테이블 비교** → 독립 창(모듈 B)을 열어 완전한 3단계 흐름을 진행:

1. **Step 1 두 폴더 선택**: 왼쪽 "현재 버전", 오른쪽 "참조 버전"
2. **Step 2 차이 파일 목록**: 두 폴더 아래 파일의 추가/삭제/수정 상황을 나열, 행을 클릭해 펼침
3. **Step 3 셀 diff 그리드**: sticky 3행 헤더 + 상하 분층, 셀 단위로 변화를 봄

### 방식 2: Git / SVN 소스 관리 패널

소스 관리 패널에서 변경 목록의 `.xlsx` / `.cnx` 파일을 클릭:

- 테이블 비교 DLC 설치됨 → "테이블 diff인가 텍스트 diff인가" 팝업
- 테이블 diff 선택 → 작업 영역 버전 vs HEAD 버전, 셀 단위 highlight
- 텍스트 diff 선택 → 일반 unified diff

### 방식 3: 브랜치 ↔ 작업 영역 비교

Git 패널의 "이력" 뷰에서 어떤 commit을 우클릭 → **작업 영역과 테이블 diff** → commit 버전을 임시 파일로 자동 내보내 작업 영역 버전과 비교.

## diff 색상

| 색상 | 의미 |
|------|------|
| 초록 배경 | 추가(참조 버전에 없고 현재 버전에 있음) |
| 빨강 배경 | 삭제(참조 버전에 있고 현재 버전에 없음) |
| 노랑 배경 | 수정 |
| 문자 단위 빨강 / 초록 | 같은 셀 내에서 교체된 부분 문자열 |

## 문자 단위 diff란

예를 들어:

| 참조 버전 | 현재 버전 | 강조 효과 |
|---|---|---|
| `攻击力 100` | `攻击力 120` | "100" 빨강, "120" 초록, "攻击力 "은 그대로 |
| `[1,2,3]` | `[1,2,4]` | "3" 빨강, "4" 초록, 나머지 그대로 |
| `奖励：金币` | `奖励：钻石` | "金币" 빨강, "钻石" 초록 |

구현은 LCS(최장 공통 부분 수열) + 토큰 분할을 사용합니다. 알고리즘은 `cell-diff-render.js`에 있고 vitest로 커버됩니다.

## 3단계 흐름 페이지

### Step 1 폴더 선택

좌우에 각각 폴더 하나씩 선택("현재 / 참조" 의미는 자유, 바꾸면 결과가 반대로 됨). "하위 디렉터리 재귀 스캔"을 체크할 수 있습니다.

### Step 2 차이 파일 목록

모든 차이 파일을 나열:

- 추가(초록 +): 참조 버전에 없고 현재에 있음
- 삭제(빨강 -): 참조 버전에 있고 현재에 없음
- 수정(노랑 ~): 양쪽에 다 있지만 내용이 다름
- 동명·동일 hash 파일은 표시 안 함

행을 클릭해 펼침 / 접기, 파일명을 클릭해 Step 3로.

### Step 3 셀 diff 그리드

- 3행 sticky 헤더(시트명 / 열명 / 헤더)
- 행 높이는 내용에 맞춰 자동
- 상하 분층으로 "참조 / 현재" 표시
- 같은 행 같은 열의 양쪽 내용을 나란히

## 성능

문자 단위 diff는 **셀을 펼칠 때만** 계산합니다(지연 계산). 전체 테이블 5000+ 행도 안 끊깁니다.

## 주의 사항

> [!NOTE]
> 테이블 비교 DLC는 유료 DLC로, 구매하지 않으면 메뉴와 Git / SVN의 "테이블 diff" 진입점이 나타나지 않고 해당 IPC도 응답하지 않습니다 — 다만 **일반 텍스트 diff**는 영향받지 않습니다(Git / SVN 자체 기능).

> [!TIP]
> "참조 관계 그래프"와는 다른 기능입니다: 참조 그래프는 "누가 누구를 참조하는가"를 보고, 테이블 비교는 "어느 셀이 무엇으로 바뀌었는가"를 봅니다.
