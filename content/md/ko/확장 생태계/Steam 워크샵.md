# Steam 워크샵

새 프로젝트를 시작할 때마다 템플릿을 처음부터 만들어야 합니다 — 아이템 테이블, 대화 테이블, 임무 테이블을 한 칸씩 다시 짓습니다. Python 스크립트도 마찬가지로, 지난 프로젝트에서 쓸 만한 내보내기 스크립트를 잘 만들어 두었는데 프로젝트가 바뀌면 또 다시 써야 합니다. 워크샵은 이런 재사용 가능한 "템플릿 / 스크립트 / 프리셋"을 패키징해 공유합니다: ConfigNexus 내장 스토어에서 커뮤니티의 성숙한 컴포넌트를 한 번에 구독하거나, 자기가 만든 것을 남에게 올립니다.

> [!IMPORTANT]
> 워크샵은 **Steam 정품 채널에서만** 사용할 수 있습니다. 비Steam 채널(크랙판 / 그린판 / 클라우드 드라이브판)에서는 진입점이 비활성화되고 상단에 "Steam 버전만 사용 가능" 안내가 표시됩니다.

## 기능 개요

| 기능 | 설명 |
|------|------|
| 커뮤니티 컴포넌트 탐색 | ConfigNexus 내장 컴포넌트 스토어에서 검색 / 정렬 / 미리보기 |
| 한 번에 구독 | 구독하면 Steam이 자동으로 다운로드해 로컬에 설치 |
| 자동 업데이트 | 워크샵이 컴포넌트를 업데이트하면 구독자가 다음 시작 시 알림받음 |
| 컴포넌트 업로드 | 자기가 만든 컴포넌트를 미리보기 이미지, 버전 번호, 의존 설명과 함께 패키징해 업로드 |
| 협약 서명 | 업로드 전 Steam 워크샵 법률 협약 서명 필요(일회성) |

## 컴포넌트 스토어 열기

메인 창 메뉴 바 **도구 → 컴포넌트 스토어**, 또는 환영 페이지 / 설정 페이지의 진입점.

![Steam 워크샵-컴포넌트 스토어](Res/zh/images/创意工坊-组件商店.png)

스토어에는 두 개의 탭이 있습니다:

- **설치됨**: 로컬 컴포넌트 + 이미 구독한 워크샵 컴포넌트
- **스토어**: 현재 Steam에서 검색되는 모든 공개 컴포넌트(기본 인기순 정렬)

## 컴포넌트 구독

스토어 탭에서:

1. 원하는 컴포넌트를 검색 / 탐색
2. **구독** 클릭
3. Steam이 백그라운드에서 다운로드(메인 화면을 막지 않음)
4. 다운로드 완료 후 "설치됨" 탭에 자동으로 나타나며 상태가 초록으로 변함

## 구독 취소

"설치됨" 탭에서 해당 컴포넌트를 찾기 → **구독 취소** → 로컬 파일도 함께 삭제할지 선택.

> [!NOTE]
> 구독 취소는 기본적으로 로컬 사본을 **삭제합니다**. 로컬 사본을 한 부 남기고 싶다면 ConfigNexus 외부에서 컴포넌트 디렉터리를 수동으로 백업하세요.

## 컴포넌트 업로드

### 전제 조건

1. **Steam 클라이언트 실행 중**이며 **로그인한 계정이 ConfigNexus를 소유**
2. **첫 업로드**: Steam 워크샵 법률 협약 서명 필요(팝업에서 확인 체크)
3. **Pro 버전 기능**(무료 버전은 다운로드·구독 가능하지만 업로드 불가)

### 업로드 흐름

1. **도구 → 컴포넌트 스토어 → 설치됨** 탭에서 업로드할 로컬 컴포넌트 선택
2. **워크샵에 업로드** 클릭
3. 업로드 메타데이터 입력: 제목 / 소개 / 태그 / 공개 범위(공개 / 친구만 / 비공개) / 미리보기 이미지
4. 검증: 시스템이 컴포넌트 구조 + 메타데이터 적법성 검증
5. 패키징: 컴포넌트 디렉터리를 zip으로 묶어 업로드
6. 협약 서명: 첫 회는 협약 팝업(Steam 클라이언트에서 수락)
7. 업로드 완료 대기

### 후속 업데이트

같은 컴포넌트를 다시 업로드(디렉터리의 `metadata.json`을 그대로 유지)하면, 시스템이 자동으로 "새로 만들기"가 아닌 "업데이트"로 인식하며 협약을 다시 서명할 필요가 없습니다.

## 작성자 신원 검증

- 컴포넌트는 원작성자만 업데이트할 수 있음
- 업로드 시 시스템이 `metadata.authorSteamId`와 현재 로그인한 Steam ID를 비교
- 불일치 시 업로드를 거부하고 "자신이 만든 컴포넌트만 업로드할 수 있습니다"라고 안내

> [!TIP]
> 첫 업로드 시 시스템이 `metadata.authorSteamId`를 현재 사용자로 자동 설정합니다. 그래서 **첫 업로드는 반드시 작성자 본인**이 해야 하며, 그렇지 않으면 이후에 수정할 수 없게 됩니다.

## 오류 대조표

| 오류 코드 | 의미 | 해결 |
|-----------|------|------|
| E_STEAM_UNINITIALIZED | Steam 미실행 또는 미로그인 | Steam 클라이언트 시작 후 로그인 |
| E_STEAM_AGREEMENT_REQUIRED | 워크샵 협약 먼저 서명 필요 | Steam 클라이언트에서 협약 수락 |
| E_AUTHOR_MISMATCH | 현재 계정이 원작성자가 아님 | 원작성자 계정으로 업로드 |
| E_COMPONENT_INVALID | 컴포넌트 구조 부적합 | `metadata.json`이 완전한지, 미리보기 이미지가 있는지 확인 |
| E_UPLOAD_FAILED | 네트워크 / Steam 서버 문제 | 잠시 후 재시도 |

## 주의 사항

> [!WARNING]
> 워크샵에 업로드한 컴포넌트는 **누구나 볼 수 있습니다**("친구만"이나 "비공개"를 선택하지 않는 한). 영업 비밀 / 고객 데이터가 담긴 설정을 공개 워크샵에 업로드하지 마세요.

> [!IMPORTANT]
> Steam 워크샵 법률 협약 위반(타인 작품 도용, 위법 콘텐츠 등)은 Steam 계정 차단으로 이어질 수 있습니다. 업로드 전 해당 콘텐츠에 대한 합법적 권리가 있는지 확인하세요.
