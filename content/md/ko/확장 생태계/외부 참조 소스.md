# 외부 참조 소스

기획 A 테이블에 아이템 ID를 채워야 하는데 아이템 메인 테이블이 다른 프로젝트에 있습니다 — 예전에는 메모해 손으로 베끼거나, Excel 두 개를 열어 대조해 볼 수밖에 없었습니다. 외부 참조 소스는 "다른 프로젝트의 테이블"을 연결해, 이 프로젝트의 수식 / 검증 / 자동 완성이 상대 데이터를 바로 조회하게 합니다 — 대응 관계를 수동으로 관리할 필요가 없습니다.

프로젝트 밖의 파일 / 폴더를 "참조 소스"로 등록해, 수식 / 검증 / 자동 완성이 프로젝트 간 테이블을 조회하게 합니다 — 예를 들어 다른 프로젝트의 `talent.xlsx`를 추가하면, 이 프로젝트의 `id` 열에서 상대의 ID를 드롭다운으로 선택할 수 있습니다.

## 기능 개요

| 기능 | 설명 |
|------|------|
| 다중 소스 지원 | 여러 파일 / 폴더를 동시에 참조 소스로 연결 |
| 별칭 메커니즘 | 각 소스에 기억하기 쉬운 표시 이름을 부여, 드롭다운에서 명확히 구분 |
| 충돌 해결 | 여러 소스에 동명의 테이블 / 열이 있을 때 설정에서 우선순위 지정 가능 |
| 재귀 스캔 | 폴더 소스는 "한 층만 스캔" 또는 "모든 하위 디렉터리 스캔" 선택 가능 |
| 증분 새로 고침 | 개별 소스를 단독으로 새로 고침, 전체를 다시 로드할 필요 없음 |

## 참조 소스 추가

### 방식 1: 파일 브라우저 우클릭

파일 브라우저에서 임의의 파일이나 폴더 우클릭 → **🔗 외부 참조 소스로 추가** → 표시 이름 입력 → 폴더는 재귀 방식을 물음.

### 방식 2: 설정 페이지

메인 창 **설정 → 외부 참조 소스** → **+ 추가** 클릭 → 파일이나 폴더 선택.

## 별칭 vs 표시 이름

| 개념 | 무엇인가 | 사용법 |
|------|----------|--------|
| 표시 이름 | 이 참조 소스에 붙인 라벨 | 드롭다운에서 서로 다른 출처 구분 |
| 별칭 | 소스에서 발견된 각 참조 키 | 수식 / CT 열에서 직접 호출 |

예: `프로젝트B/talent.xlsx`를 추가하고 표시 이름을 "프로젝트B 특성"으로. 시스템이 스캔 후 별칭 `talent`를 등록 — 이 프로젝트에서 `=lookup('talent', 'id', 1001)`로 상대 데이터를 조회할 수 있습니다.

## 충돌 해결

두 소스가 모두 별칭 `talent`를 등록했다면:

1. 설정 페이지 → 외부 참조 소스 → ⚠ 배지가 붙은 소스 확인
2. "충돌 목록" 펼치기
3. 충돌하는 각 별칭에 우선 소스를 하나 선택(또는 하나를 이름 변경)

충돌이 해결되기 전에는 해당 별칭 호출 시 **가장 최근에 추가된** 소스를 사용합니다(경고 로그 동반).

## 새로 고침 메커니즘

- 개별 소스 새로 고침: 설정 페이지에서 해당 소스의 🔄 클릭
- 전체 새로 고침: 설정 페이지 상단 **🔄 전체 새로 고침**
- 소스 파일 수정 후 **자동으로** 다시 스캔하지 않음 — 수동 새로 고침 필요

> [!TIP]
> 참조 소스의 스캔 결과는 프로젝트 로컬에 캐시되어 세션 간 유지됩니다. 큰 폴더(수백 개 xlsx)를 처음 추가하면 몇 초 걸릴 수 있습니다.

## 삭제 / 비활성화

- **비활성화**: 이 소스를 일시적으로 조회에 참여시키지 않되 설정은 유지(설정 페이지에서 스위치 클릭)
- **삭제**: 완전히 제거(삭제 후 이미 이 소스를 참조한 수식은 값을 조회하지 못함)

## 수식 통합

셀에 작성:

```
=lookup('<별칭>', '<열명>', <기본키 값>)
```

`<별칭>`은 등록된 참조 소스 별칭이어야 합니다. 별칭 충돌이 해결되지 않았다면 함수는 "가장 최근 추가" 원칙으로 해석하며 warning을 남깁니다.

## 주의 사항

> [!WARNING]
> 외부 참조 소스는 **읽기 전용**입니다 — 이를 통해 조회한 데이터는 이 프로젝트에서 직접 수정할 수 없습니다. 상대의 값을 바꾸려면 상대 파일을 열어야 합니다.

> [!NOTE]
> 옛 프로젝트의 mapping 설정은 업그레이드 시 외부 참조 소스로 **자동 마이그레이션**되어 수동으로 다시 할 필요가 없습니다. 마이그레이션 결과가 잘못되었다면 설정 페이지 → 외부 참조 소스 → 고급 → "옛 mapping에서 다시 가져오기"를 쓸 수 있습니다.
