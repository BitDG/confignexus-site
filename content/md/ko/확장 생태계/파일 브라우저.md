# 파일 브라우저

프로젝트가 커지면 설정 테이블이 십수 개 폴더에 흩어집니다 — 파일은 기억에 의존해 찾고, 파일명을 바꾸면 어디서 참조가 끊기는지 알 수 없으며, Git/SVN 상태는 터미널을 열어야만 볼 수 있습니다. 파일 브라우저는 이것들을 하나의 사이드바에 모읍니다: 독립 창이 메인 창 왼쪽에 붙어, 파일 트리 + 버전 관리 배지 + 참조 그래프 진입점을 셋으로 결합해, 소프트웨어를 벗어나지 않고도 프로젝트 전체 디렉터리를 관리합니다.

독립 창 형태의 파일 트리로 메인 창 왼쪽에 머물며, 프로젝트 디렉터리 전체의 설정 파일을 관리하는 데 특화되어 있습니다 — 새로 만들기 / 이름 변경 / 삭제 / 메인 창으로 드래그해 열기, Git / SVN 배지, 참조 관계 그래프, 외부 참조 소스 등 확장 기능을 통합합니다.

## 기능 개요

| 기능 | 설명 |
|------|------|
| 파일 트리 | 폴더 계층별 펼침, 폴더 지연 로드(펼칠 때만 스캔), 만 단위 파일도 안 끊김 |
| 다중 위치 전환 | 상단 드롭다운으로 "작업 위치"(여러 프로젝트 루트 디렉터리) 전환 |
| 검색창 | 키워드 입력 시 트리의 파일명을 실시간 필터링 |
| 우클릭 메뉴 | 파일 / 폴더 새로 만들기, 이름 변경, 삭제, 파일 관리자에서 표시, 외부 참조 소스로 추가 |
| 메인 창에서 더블 클릭 열기 | 지원 파일(xlsx / json / cnx 등)을 더블 클릭해 메인 창에서 열기 |
| 배지 시스템 | 파일명 옆에 Git/SVN 상태(M/A/D/U/C) 표시, git-mod·svn-mod 플러그인이 제공 |
| 참조 관계 그래프 진입점 | 파일 행 내 🔍 단일 파일 뷰, 좌측 하단 🔗 현재 폴더 전체 뷰 |
| 확장 슬롯 | 왼쪽 세로 아이콘 바(Git / SVN / 설정 / 참조 그래프)를 플러그인이 동적 등록 |

## 파일 브라우저 열기

메인 창 메뉴 바 **보기 → 파일 브라우저**. 창은 기본적으로 메인 창 왼쪽에 붙고, 너비는 메인 창의 31.25%, 메인 창과 같은 높이이며, 메인 창을 따라 움직입니다.

> [!TIP]
> 파일 브라우저는 **독립 창**으로 메인 창과는 두 프로세스 간 통신입니다. 닫아도 메인 창에서 이미 연 테이블에 영향을 주지 않으며, 다시 열면 지난번 탐색 위치를 유지합니다.

## 작업 위치 전환

상단 드롭다운에는 **설정 → 파일 브라우저 위치**에서 설정한 모든 작업 위치(각 위치 = 하나의 프로젝트 루트 디렉터리)가 나열됩니다. 전환하면 트리 전체가 다시 로드됩니다.

위치를 하나도 설정하지 않으면 파일 브라우저는 "지난번 메인 창에서 연 프로젝트 디렉터리"를 루트로 삼습니다.

## 파일 트리 작업

| 작업 | 설명 |
|------|------|
| 파일 단일 클릭 | 강조 선택(열지 않음) |
| 파일 더블 클릭 | 메인 창에서 열기(지원 형식만: xlsx / xlsm / xls / json / csv / cnx) |
| 폴더 단일 클릭 | 펼침 / 접기 |
| 파일명 옆 🔍 단일 클릭 | 해당 파일의 참조 관계 그래프 열기(지원 형식만) |
| 임의 노드 우클릭 | 메뉴 표시: 새로 만들기 / 이름 변경 / 삭제 / 파일 관리자에서 표시 / 외부 참조 소스로 추가 |

> [!NOTE]
> 삭제는 **시스템 휴지통**을 거치므로 복구 가능합니다. 이름 변경 / 이동 시 파일이 이미 메인 창에서 열려 있으면 "이 파일은 편집 중입니다"라고 먼저 안내합니다.

## 검색

상단 검색창에 키워드를 입력하면 현재 트리에 보이는 파일명을 **실시간 필터링**(경로 일부 매칭 포함)합니다. ESC를 누르거나 오른쪽 ✕를 클릭하면 비웁니다.

검색은 이미 펼쳐진 부분만 필터링합니다. 트리 전체를 검색하려면 먼저 폴더를 모두 펼치세요.

## 배지(Git / SVN 상태)

현재 위치가 Git 저장소나 SVN 작업 사본 안이라면 파일명 오른쪽에 한 글자 배지가 나타납니다:

| 배지 | 색상 | 의미 |
|------|------|------|
| M | 노랑 | 수정됨 |
| A | 초록 | 추가됨 |
| D | 빨강 | 삭제됨 |
| U / ? | 회색 | 추적 안 됨 |
| C | 빨강 | 충돌 |

배지는 30초마다 새로 고쳐지며, commit / 되돌리기 / 스테이징 등을 하면 배지가 즉시 갱신됩니다.

> [!TIP]
> 배지 기능은 **git-mod** / **svn-mod** 플러그인이 제공하며, 시스템 PATH에 `git` / `svn.exe`가 있어야 합니다. 없으면 자동으로 숨겨지며 다른 기능에 영향을 주지 않습니다.

## 참조 관계 그래프 진입점

- **파일 행 내 🔍**: "이 파일이 누구에게 참조되는가 / 이 파일이 무엇을 참조하는가"의 단일 파일 뷰 열기
- **좌측 하단 🔗**: 현재 루트 디렉터리를 범위로, 전체 관련 참조 그래프 표시

두 진입점 모두 탭을 메인 창에 열며, 단일 인스턴스 재사용(다시 클릭하면 기존 탭으로 전환, 여러 개 열리지 않음)합니다.

## 외부 참조 소스로 추가

임의의 파일이나 폴더를 우클릭해 **🔗 외부 참조 소스로 추가** 선택:

- 표시 이름 입력(드롭다운 메뉴에서 출처 구분용)
- 폴더는 "재귀 스캔 여부"를 물음("예"=모든 하위 디렉터리 스캔, "아니오"=첫 층만 스캔)
- 추가 성공 시 별칭 수를 표시. 별칭 충돌이 있으면 **설정 → 외부 참조 소스**에서 해결

[[외부 참조 소스]] 튜토리얼 참고.

## 확장 슬롯: 왼쪽 세로 아이콘 바

왼쪽 44px 너비의 세로 아이콘 바는 플러그인이 동적으로 등록합니다:

| 아이콘 | 출처 | 작용 |
|--------|------|------|
| 🌿 | git-mod | Git 소스 관리 패널 열기(commit / pull / push / stash / branch) |
| 🌐 | svn-mod | SVN 소스 관리 패널 열기(commit / update / log) |
| 🔗 | 내장 | 현재 폴더 관련 참조 관계 그래프 |
| ⚙️ | 내장 | 파일 브라우저 설정 |

아이콘 순서, 표시 여부는 `plugins/<plugin>/manifest.json`의 `contributesSettings.sidebar.order`로 제어합니다.

## 주의 사항

> [!WARNING]
> 파일 브라우저의 "새로 고침" 버튼은 **루트 디렉터리를 다시 스캔**합니다 — 파일이 많으면 1-2초 기다립니다. 일상 사용에는 수동 새로 고침이 필요 없으며, 파일 변동은 watcher가 감지해 자동 반영합니다.

> [!NOTE]
> 파일 브라우저는 **메인 창의 메모리를 차지하지 않습니다**. 독립 렌더링 프로세스를 가지며 메인 창과 IPC로 통신합니다.
