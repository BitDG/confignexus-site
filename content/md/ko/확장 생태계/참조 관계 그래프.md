# 관련 참조 관계 그래프

한 테이블의 ID 열을 바꿨는데 프로젝트의 어느 테이블들이 그것을 참조하는지 모릅니다 — 하나씩 열어 손으로 확인하면 수십 분이 걸리고 빠뜨리기도 쉽습니다. 참조 관계 그래프는 프로젝트의 모든 테이블 간 의존 관계를 하나의 그래프로 그립니다: 들어와서 "이 테이블이 누구에게 참조되고, 또 어떤 테이블에 의존하는지"를 한눈에 보고, 수정 전에 영향 범위를 먼저 점검해, 마음 놓고 움직입니다.

현재 프로젝트에서 "어느 테이블이 누구에게 참조되는가 / 그것이 무엇을 참조하는가"의 그래프를 시각적으로 표시합니다 — "ID를 바꾼 뒤 어느 테이블이 영향받는가", "이 보상 설정이 몇 개 테이블에 쓰이는가"를 점검하는 데 씁니다.

## 기능 개요

| 기능 | 설명 |
|------|------|
| 단일 파일 뷰 | 한 파일을 중심으로 직접 / 간접 참조 관계 표시 |
| 전체 디렉터리 뷰 | 현재 루트 디렉터리를 범위로 전체 관련 그래프 표시 |
| 노드 점프 | 노드를 클릭하면 메인 창에서 해당 테이블을 바로 열기 |
| 단일 인스턴스 탭 | 다른 폴더로 전환 시 같은 탭을 재사용, 참조 그래프가 우후죽순 열리지 않음 |

## 여는 방법

### 방식 1: 파일 행 내 🔍(단일 파일 뷰)

파일 브라우저에서 임의의 지원 파일(xlsx / json / cnx) 위에 마우스를 올리면 오른쪽에 🔍 아이콘이 나타납니다. 클릭 → "이 파일의 참조 관계 그래프" 탭 열기.

### 방식 2: 좌측 하단 🔗(전체 디렉터리 뷰)

파일 브라우저 좌측 하단의 🔗 아이콘 → 현재 위치(rootPath)를 루트로, 해당 폴더 아래 모든 파일 간 참조 관계를 나열.

## 그래프 읽는 법

- **화살표 방향**: A → B는 A가 B를 참조함을 의미
- **노드 색상**:
  - 파랑: 현재 초점 파일
  - 초록: 초점 파일이 참조하는 대상
  - 주황: 초점 파일을 참조하는 대상
- **노드 크기**: 참조된 횟수가 많을수록 노드가 큼

## 노드 작업

| 작업 | 효과 |
|------|------|
| 노드 단일 클릭 | 메인 창 탭에서 해당 파일 열기 |
| 노드 더블 클릭 | 그래프의 초점을 이 노드로 전환(이 노드를 중심으로 다시 그림) |
| 노드 드래그 | 레이아웃 조정, 구조를 보기 편하게 |
| 휠 줌 | 전체 그래프 줌 |
| 빈 곳 드래그 | 뷰 이동 |

## 단일 인스턴스 탭

🔍 / 🔗를 몇 번 클릭하든 메인 창에는 **하나**의 "🔗 참조 · xxx" 탭만 존재합니다. 클릭할 때마다 그 내용을 갱신하고 전환하며, 여러 개로 열리지 않습니다.

## 데이터 출처

참조 관계 그래프는 다음 출처를 스캔합니다:

- **프로젝트 내**: 열었던 적 있거나 프로젝트 루트 디렉터리 아래의 xlsx / json / cnx 파일 전부
- **외부 참조 소스**: 설정에서 연결한 모든 소스([[외부 참조 소스]] 튜토리얼 참고)

> [!TIP]
> 데이터는 **비동기 스캔**됩니다 — 큰 프로젝트는 그래프를 처음 열 때 1-2초 걸릴 수 있습니다. 결과는 다음 수동 새로 고침까지 캐시됩니다.

## 주의 사항

> [!WARNING]
> 참조 관계는 **명시적인 lookup / 외래 키 설정**을 기반으로 계산됩니다. 참조가 Python 스크립트 안에 쓰여 있거나 리치 텍스트에 흩어져 쓰여 있으면 그래프가 스캔하지 못합니다.

## 다음에 배울 내용

- 파일 브라우저에서 참조 관계 그래프 진입점 여는 방법 → [[파일 브라우저]]
- 다른 프로젝트의 테이블을 연결해 그래프가 프로젝트 간 참조도 보게 → [[외부 참조 소스]]
- 두 버전의 차이를 셀 단위로 비교 → [[테이블 비교]]

> [!NOTE]
> 🔍 / 🔗를 클릭한 뒤 **반응이 없다면**, 먼저 파일이 지원 형식(xlsx / json / cnx)인지, 파일 브라우저가 작업 위치를 선택했는지 확인하세요. 그래도 반응이 없으면 파일 브라우저를 닫았다 다시 열면 복구됩니다.
