# 폰트 서브셋

게임을 출시하려는데 그제야 중국어 폰트 패키지가 12MB라서 폰트 로딩만으로 몇 초씩 끊긴다는 걸 알게 됩니다 — 사실 당신의 테이블에는 한자가 삼천 개밖에 쓰이지 않았는데도요. 폰트 서브셋은 "폰트에서 쓰이지 않은 글리프"를 지워, 프로젝트에 실제로 등장한 문자만 남깁니다. 중국어 폰트는 흔히 10MB+인데, 서브셋 후 보통 수백 KB로 압축할 수 있습니다.

> [!tip]
> **스토어 추천 도구**. 먼저 [[다국어 문자 추출]]로 프로젝트의 문자표를 얻은 뒤 여기서 폰트를 자르면, 두 단계로 가장 손쉽습니다.

## 한마디 원리

폰트 파일(ttf / otf)에는 모든 문자의 글리프 데이터가 들어 있습니다. 게임은 실제로 테이블에 등장한 수천 글자만 씁니다. 쓰이지 않은 문자의 글리프를 폰트 파일에서 **지워** 더 작은 폰트 파일을 얻습니다.

## 3단계 흐름

### Step 1 프로젝트에 쓰인 모든 문자 추출

메인 창 메뉴 → **도구 → 다국어 문자 추출**

- 스캔할 워크시트 선택(기본 전체)
- 스캔할 열 선택(기본 모든 텍스트 열)
- 출력: `charset.txt` —— 프로젝트에 등장한 모든 중복 없는 문자

[[다국어 문자 추출]] 튜토리얼 참고.

### Step 2 폰트 서브셋

메인 창 메뉴 → **도구 → 폰트 서브셋**

- 폰트 소스 파일 선택(ttf / otf)
- 문자표 선택(Step 1에서 생성한 `charset.txt`)
- 출력 경로(버전 접미사 권장, 예: `font-v1.ttf`)

시스템이 내장 도구(fonttools 기반)를 호출해 폰트를 잘라 냅니다.

### Step 3 게임의 폰트 교체

서브셋된 폰트를 게임 리소스 디렉터리에 넣어 원본 폰트를 교체합니다.

## 패키지 압축 효과(전형적)

| 폰트 | 원본 | 서브셋 후 | 압축비 |
|------|------|-----------|--------|
| 본고딕 Regular | 11.2 MB | 412 KB | -96% |
| 알리바바 푸후이체 | 9.8 MB | 380 KB | -96% |
| 잔쿠 콰이러체(중문+소량 영일) | 8.5 MB | 290 KB | -97% |

영문 폰트는 자체가 작아(수백 KB) 서브셋 효과가 미미합니다 — 이 도구는 주로 한·중·일 폰트를 위해 설계되었습니다.

## 다중 폰트 일괄 처리

프로젝트에서 여러 폰트(제목 폰트 / 본문 폰트 / 숫자 폰트)를 쓴다면 한 번에 일괄 처리할 수 있습니다:

- 여러 폰트 소스 파일 선택(Ctrl 누르고 다중 선택)
- 같은 문자표 공유
- 통일된 디렉터리로 출력

## 문자표 갱신 전략

프로젝트가 계속 발전하면 새 텍스트가 추가되므로, 폰트는 일정 주기마다 다시 서브셋해야 합니다:

- 자동화: 문자 추출 + 폰트 서브셋을 CI 흐름에 포함
- 수동: 배포 전마다 한 번 실행

> [!tip]
> 문자표는 딱 맞게 커버하기보다 **상위 집합**으로 두는 편이 더 안전합니다 — ASCII 전체 + 자주 쓰는 문장 부호 + 숫자를 추가해 문자 누락을 피하세요. CHANGELOG / 버전 번호처럼 임시로 등장하는 문자도 네모로 변하지 않습니다.

## 주의 사항

> [!warning]
> 서브셋된 폰트를 제3자에게 **배포하지 마세요** — 폰트 자체에 저작권이 있으며, 서브셋은 당신 자신의 프로젝트에만 쓸 수 있습니다. 상업용 폰트의 서브셋이 합법인지는 라이선스 협약을 보세요.

> [!note]
> 폰트 서브셋은 fonttools(Python 도구 체인)를 사용하며, ConfigNexus에 내장되어 별도 설치가 필요 없습니다.
