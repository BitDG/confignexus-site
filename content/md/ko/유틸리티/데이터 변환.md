# 데이터 변환

매핑 테이블 설정에 따라 복잡한 다중 데이터 셀 내용을 자동으로 계산하고 변환합니다.

## 기능 개요

| 기능 | 설명 |
|------|------|
| 데이터 파싱 및 그룹화 | 복합 데이터 구조를 자동으로 파싱하여 그룹별로 분류 |
| 매핑 테이블 | 외부 매핑 테이블을 참조하여 값을 조회하고 변환 |
| 기대값 계산 | 확률과 수량을 기반으로 기대값을 자동 계산 |
| 구분자 감지 | 중괄호, 쉼표 등 구분자를 자동으로 감지하여 파싱 |

## 사용 시나리오

CT 다중 데이터 편집기의 데이터에 적용하여 매핑 테이블 설정에 따라 계산과 변환을 수행합니다.

### 보상 배열 예시

`[{1001,30,0.75},{1002,50,0.85}]`

데이터 구조: `{보상ID, 보상 수량, 획득 확률}`

### 계산 요구 사항

이 셀의 구체적인 가치를 계산하려면:

1. 매핑 테이블 `item`에서 해당 골드 가격을 찾기
2. 골드 가격과 보상 수량, 획득 확률을 곱하기
3. `{}` 내의 데이터를 합산하여 최종 보상 가치를 계산

### 계산 공식

```
총 가치 = Σ (골드 가격 × 보상 수량 × 획득 확률)
```

## 사용 방법

1. 변환할 셀 또는 열을 선택합니다
2. 데이터 변환 기능을 열어 매핑 테이블을 지정합니다
3. 각 데이터 필드의 역할(ID, 수량, 확률 등)을 설정합니다
4. 변환을 실행하여 계산 결과를 확인합니다
