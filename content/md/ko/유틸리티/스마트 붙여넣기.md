# 스마트 붙여넣기

클립보드의 Markdown 테이블이나 JSON 데이터를 자동으로 감지하여 스프레드시트 형식으로 변환하여 붙여넣습니다.

## 기능 개요

| 기능 | 설명 |
|------|------|
| Markdown 테이블 변환 | 클립보드의 Markdown 테이블을 자동 감지하여 셀에 변환 붙여넣기 |
| JSON 배열 변환 | JSON 배열 데이터를 자동 감지하여 테이블 형식으로 변환 |
| 확인 대화상자 | 변환 전 미리보기와 확인 대화상자를 표시하여 안전하게 적용 |

## 지원되는 데이터 형식

### Markdown 테이블

클립보드에 Markdown 형식의 테이블이 포함되어 있으면 자동으로 감지합니다:

```markdown
| ID | 이름 | 가격 |
|----|------|------|
| 1001 | 아이템A | 100 |
| 1002 | 아이템B | 200 |
```

붙여넣기 시 헤더와 데이터가 각 셀에 자동으로 분배됩니다.

### JSON 배열

JSON 배열 형식의 데이터도 자동 변환됩니다:

```json
[
  {"id": 1001, "name": "아이템A", "price": 100},
  {"id": 1002, "name": "아이템B", "price": 200}
]
```

키가 열 헤더로, 값이 셀 데이터로 자동 매핑됩니다.

## 사용 방법

1. 외부에서 Markdown 테이블이나 JSON 데이터를 복사합니다
2. ConfigNexus에서 대상 셀을 선택합니다
3. `Ctrl+V`로 붙여넣기합니다
4. 스마트 붙여넣기 대화상자가 나타나면 미리보기를 확인합니다
5. 「적용」을 클릭하여 변환된 데이터를 셀에 채웁니다

## 확인 대화상자

스마트 붙여넣기가 감지되면 확인 대화상자가 표시됩니다:

- 변환 전후 데이터 미리보기
- 일반 붙여넣기 또는 스마트 붙여넣기 선택 가능
- 취소하여 원래 상태로 되돌리기 가능
