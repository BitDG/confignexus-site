# 다중 데이터 일괄 수정

여러 데이터 값을 포함하는 셀에 대한 강력한 일괄 수정 기능.

## 지원되는 데이터 형식

1. **CT 다중 데이터 편집 형식**: ConfigNexus 다중 데이터 편집기로 만든 셀
2. **단순 배열 형식**: 예: `[1,2]`
3. **불규칙 중첩 형식**: 예: `[1,{2,3,4},{222,33}]`

## 일괄 편집 작업

일괄 수정을 위한 다음 단계를 따르세요:

1. 수정할 셀 선택
2. 오른쪽 클릭 메뉴 → 기존 콘텐츠 수정 → 일괄 수정
3. 팝업에서 연산자를 사용하여 값을 일괄 수정
4. 필요한 경우 반올림 기능 활성화
