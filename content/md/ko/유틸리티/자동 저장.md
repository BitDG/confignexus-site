# 자동 저장

편집 중 데이터 손실을 방지하기 위해 유휴 상태를 감지하여 자동으로 파일을 저장합니다.

## 기능 개요

| 기능 | 설명 |
|------|------|
| 유휴 감지 (2분) | 마지막 편집 후 2분간 유휴 상태가 지속되면 자동 저장 실행 |
| 최소 간격 (1분) | 연속 편집 시에도 저장 간격이 최소 1분 이상 유지 |
| 원본 형식 유지 | xlsx, cnx 등 원본 파일 형식을 그대로 유지하여 저장 |
| 실패 알림 | 저장 실패 시 사용자에게 알림을 표시하여 데이터 손실 방지 |

## 동작 방식

### 유휴 감지

1. 사용자가 셀을 편집하면 유휴 타이머가 초기화됩니다
2. 마지막 편집으로부터 2분간 입력이 없으면 자동 저장이 트리거됩니다
3. 저장이 완료되면 상태 표시줄에 저장 시간이 표시됩니다

### 최소 간격 보장

- 자동 저장 간의 최소 간격은 1분입니다
- 이 간격 내에는 유휴 감지가 되어도 저장이 지연됩니다
- 과도한 저장 작업으로 인한 성능 저하를 방지합니다

## 저장 형식

| 파일 유형 | 동작 |
|-----------|------|
| `.cnx` 프로젝트 | 프로젝트 형식으로 저장 |
| `.xlsx` 파일 | Excel 형식을 유지하여 저장 |
| `.xls` 파일 | 원본 형식을 유지하여 저장 |
| 새 파일 | 사용자에게 저장 경로 선택을 요청 |

## 실패 처리

> [!WARNING]
> 자동 저장이 실패하면 토스트 알림이 표시됩니다. 디스크 공간 부족, 파일 잠금 등의 원인을 확인하고 수동으로 저장해 주세요.

## 설정

자동 저장 기능은 기본적으로 활성화되어 있으며, 설정에서 비활성화하거나 유휴 시간을 조정할 수 있습니다.
