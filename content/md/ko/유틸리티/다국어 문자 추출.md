# 다국어 문자 추출

게임에 수천 줄의 텍스트가 있고, 최종적으로 게임용 폰트에 넣어야 하는데 — 폰트 파일에는 수만 개의 글리프가 들어 있지만 실제로는 그중 이삼천 개만 씁니다. 이 도구는 프로젝트의 다국어 형식으로 표시된 모든 열을 스캔해, 등장한 문자를 중복 제거해 하나의 문자표로 정리하고, 폰트 서브셋 도구에 넘겨 폰트를 10MB+에서 수백 KB로 압축합니다.

> [!tip]
> **스토어 추천 도구**: 프로젝트의 모든 다국어 텍스트 스캔 → **중복 없는 문자 집합** 추출 → `charset.txt` 생성. [[폰트 서브셋]]과 함께 쓰면 게임 폰트를 원래의 5% 이하로 압축할 수 있습니다.

## 용도

| 상황 | 사용법 |
|------|--------|
| 폰트 서브셋 | 여기서 생성한 문자표로 폰트 서브셋 도구에서 폰트를 자름 |
| 문자 감사 | 프로젝트가 실제로 몇 개의 중복 없는 문자를 쓰는지 확인 |
| 문자 호환성 검사 | 문자표를 폰트 도구에 넣어 어떤 폰트가 지원하지 않는지 확인 |

## 사용 방법

### 1단계: 도구 열기

메인 창 메뉴 → **도구 → 다국어 문자 추출**

### 2단계: 스캔 범위 설정

| 옵션 | 설명 |
|------|------|
| 스캔 범위 | 현재 워크시트 / 현재 프로젝트의 모든 테이블 / 직접 선택 |
| 스캔 열 | 모든 열 / 텍스트 타입 열만 / 직접 선택 |
| 포함 언어 | 간체 / 번체 / EN / JP / KR / 전체 선택 |
| 문자 필터 | ASCII 건너뛰기 / 숫자 건너뛰기 / 문장 부호 건너뛰기(선택) |
| 출력 경로 | 기본값 `<프로젝트>/charset.txt` |

### 3단계: 실행 및 결과 확인

![다국어 문자 추출 패널](Res/zh/images/多语言字符提取面板.png)

「**추출**」을 클릭하면 완료 후 상태 바에 문자 총수가 표시됩니다. `charset.txt` 내용 예시:

```
攻击力防御暴击率天赋技能Hello World 你好こんにちは안녕하세요123456...
```

각 문자가 한 자리를 차지하며, 중복 제거되고, 유니코드 코드 포인트순으로 정렬됩니다.

> [!tip]
> 게임 폰트는 보통 7000~9000개의 한자를 포함합니다. 추출한 수천 개로 충분하며, 서브셋 후 압축비가 95% 이상이 됩니다.

## 흔한 사용법

### 사용법 1: "폰트 서브셋"과 연동

가장 흔한 사용법. 문자 집합을 추출한 뒤 바로 [[폰트 서브셋]] 도구로 보내 폰트를 자르세요, 해당 튜토리얼 참고.

### 사용법 2: 프로젝트에 "이상한 문자"가 없는지 검사

때로 기획자가 복사·붙여넣기로 **전각 공백 / 보이지 않는 문자 / emoji**를 들여올 수 있습니다 — 이런 것들은 게임 폰트에서 네모로 표시되게 합니다.

문자 추출을 한 번 돌려 `charset.txt`에 다음이 있는지 확인하세요:
- 전각 공백 `　`
- 폭 0 공백
- 제어 문자
- emoji(emoji를 지원할 계획이 없다면)

발견되면 "찾기 바꾸기"로 일괄 정리하세요.

### 사용법 3: 증분 추출

배포 전마다 한 번 돌려 이전 버전의 문자표와 diff하면, 이번 버전에 어떤 문자가 새로 추가되었는지 볼 수 있습니다 — 폰트를 다시 서브셋할지 결정할 수 있습니다.

## 고급

출력된 `charset.txt`는 **문자 화이트리스트**입니다 — 폰트 서브셋 도구, 현지화 검사 스크립트, 아티스트의 아트 폰트 제작(이 문자들만 그리면 되게)에 동시에 줄 수 있습니다.

> [!note]
> 스캔은 셀의 **수식 결과**도 포함합니다 — 예를 들어 `=CONCATENATE("玩家", A1)`이 계산한 "玩家张三"이면 "玩家张三" 다섯 글자를 추출합니다.

> [!note]
> "제외"를 하고 싶다면 — 예를 들어 모든 간체자를 제외하고 번체 / 영 / 일 문자만 얻고 싶다면 — 현재는 지원하지 않으며, 추출 후 스크립트로 charset.txt를 후처리해야 합니다.
