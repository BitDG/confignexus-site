# 데이터 연결

여러 열의 데이터를 일괄 연결하여 다국어 키 이름, 리소스 경로 등을 생성합니다.

createtab:Res/zh/templates/数据拼接演示.cnx

## 기능 개요

| 기능 | 설명 |
|------|------|
| 다중 열 연결 | 여러 열의 데이터를 하나의 문자열로 연결 |
| 사용자 정의 구분자 | 밑줄, 슬래시, 점 등 다양한 구분자 설정 가능 |
| 형식 템플릿 | 연결 형식을 미리 정의하여 재사용 |
| 결과 미리보기 | 연결 결과를 실시간으로 미리보기 후 적용 |

## 사용 방법

1. 연결할 데이터가 있는 열을 선택합니다
2. 데이터 연결 기능을 열어 연결 규칙을 설정합니다
3. 구분자와 형식 템플릿을 지정합니다
4. 미리보기에서 결과를 확인한 후 적용합니다

## 형식 템플릿 예시

다양한 형식의 연결 패턴을 지원합니다:

```
접두사_열A_열B    → txt_item_1001
열A/열B/열C.확장자  → res/icon/item_1001.png
열A-열B           → skill-fire
```

## 응용 시나리오

- **다국어 키 이름 생성**: `txt_item_1001`
- **리소스 경로 연결**: `res/icon/item_1001.png`
- **고유 식별자 생성**: 여러 필드를 조합하여 고유 키 생성

## 결과 미리보기

연결 규칙을 설정하면 결과를 실시간으로 미리보기할 수 있으며, 확인 후 선택한 셀에 일괄 적용됩니다.
