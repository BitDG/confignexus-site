# 일괄 편집

다중 데이터 열의 데이터를 테이블 형식으로 펼쳐서 일괄 편집할 수 있는 기능입니다.

createtab:Res/zh/templates/批量编辑演示.cnx

## 기능 개요

| 기능 | 설명 |
|------|------|
| 다중 데이터 열 식별 | CT 다중 데이터 타입 열을 자동으로 식별하여 편집 가능 |
| 일괄 편집 테이블 | 복합 데이터를 테이블 형식으로 펼쳐서 직관적으로 편집 |
| 우클릭 메뉴 | 셀 우클릭 메뉴에서 빠르게 일괄 편집 기능에 접근 |
| 값 수집 | 여러 셀의 값을 수집하여 한꺼번에 편집 적용 |

## 사용 방법

### 일괄 편집 열기

1. CT 다중 데이터 타입이 설정된 열의 셀을 선택합니다
2. 오른쪽 클릭 메뉴에서 「일괄 편집」을 선택합니다
3. 일괄 편집 테이블이 열리며 데이터가 행과 열로 펼쳐집니다

### 데이터 편집

1. 테이블에서 원하는 셀을 직접 편집합니다
2. 행 추가, 삭제, 순서 변경이 가능합니다
3. 편집이 완료되면 「적용」을 클릭하여 원본 셀에 반영합니다

## 지원되는 데이터 구조

복합 데이터 구조를 테이블로 펼쳐서 편집합니다:

```
원본: [{1001,30,0.75},{1002,50,0.85}]

일괄 편집 테이블:
| 보상ID | 수량 | 확률 |
|--------|------|------|
| 1001   | 30   | 0.75 |
| 1002   | 50   | 0.85 |
```

## 값 수집

여러 행의 같은 열에서 값을 수집하여 일괄적으로 편집할 수 있습니다:

1. 대상 셀 범위를 선택합니다
2. 「값 수집」을 클릭하면 모든 셀의 데이터가 테이블에 표시됩니다
3. 테이블에서 일괄 수정 후 「적용」을 클릭합니다
4. 수정된 값이 각 셀에 자동으로 반영됩니다
