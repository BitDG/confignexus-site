## 기능 개요

| 기능 | 설명 |
|------|------|
| 스크립트 편집기 | 내장 CodeMirror 코드 편집기, 구문 강조 및 자동 완성 지원 |
| 사용자 정의 함수 | 스크립트 내에서 함수를 정의하고 테이블 수식 시스템에 등록하여 VBA와 유사한 경험 제공 |

| 서드파티 라이브러리 지원 | pandas, numpy 등 일반적인 라이브러리를 import 가능 |

## 사용 가능한 API

스크립트는 샌드박스 환경에서 실행되며, 다음 API를 통해 테이블 데이터를 조작합니다:

| API | 파라미터 | 설명 |
|-----|----------|------|
| `get_cell(row, col)` | 행 번호, 열 번호 | 단일 셀 값 가져오기 |
| `set_cell(row, col, value)` | 행 번호, 열 번호, 값 | 단일 셀 값 설정 |
| `get_range(r1, c1, r2, c2)` | 시작행, 시작열, 종료행, 종료열 | 영역 데이터 가져오기(2차원 배열) |
| `set_range(r1, c1, data)` | 시작행, 시작열, 2차원 배열 | 영역 데이터 일괄 쓰기 |
| `get_column(col)` | 열 번호 | 전체 열 데이터 가져오기 |
| `get_row(row)` | 행 번호 | 전체 행 데이터 가져오기 |
| `insert_row(row, data)` | 행 번호, 데이터 리스트 | 지정 위치에 행 삽입 |
| `delete_row(row)` | 행 번호 | 지정 행 삭제 |
| `get_sheet_name()` | 없음 | 현재 워크시트 이름 가져오기 |

## 코드 예제

```python
# B열의 모든 가격에 할인 계수를 곱하기
for row in range(5, 100):
    price = get_cell(row, 1)
    if price:
        set_cell(row, 1, float(price) * 0.8)
```
