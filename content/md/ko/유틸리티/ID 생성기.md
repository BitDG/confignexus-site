# ID 생성기

고유 ID를 자동으로 생성하여 수동 입력 시 중복이나 누락을 방지합니다.

createtab:Res/zh/templates/ID生成器演示.cnx

## 기능 개요

| 기능 | 설명 |
|------|------|
| 형식 템플릿 | 사용자 정의 ID 형식 템플릿(접두사, 자릿수, 구분자) 지원 |
| 자동 증가 / 랜덤 / UUID | 다양한 ID 생성 모드 선택 가능 |
| 프리셋 관리 | 자주 사용하는 ID 규칙을 프리셋으로 저장하여 재사용 |
| 일괄 채우기 | 선택한 셀 범위에 자동으로 ID를 일괄 채우기 |

## 사용 방법

1. 대상 셀 또는 셀 범위를 선택합니다
2. **열 머리글**（스프레드시트 상단의 열 문자 행, 예: A, B, C）을 **오른쪽 클릭** → 「콘텐츠 생성」→「ID 생성기」를 선택합니다
3. ID 형식, 시작 번호, 증가 방식을 설정합니다
4. 「생성」을 클릭하면 선택한 셀에 ID가 자동으로 채워집니다

## 지원되는 ID 형식

- **자동 증가**: `1001`, `1002`, `1003`...
- **접두사 + 자동 증가**: `item_1001`, `item_1002`...
- **랜덤 숫자**: 지정된 자릿수의 랜덤 숫자 생성
- **UUID**: 표준 UUID 형식 식별자 생성

## 프리셋 관리

자주 사용하는 ID 규칙을 프리셋으로 저장할 수 있습니다:

- 프리셋 이름과 ID 규칙을 설정하여 저장
- 다음 사용 시 프리셋 목록에서 빠르게 선택
- 프리셋을 편집하거나 삭제하여 관리

## 사용 팁

> [!TIP]
> - 이미 값이 있는 셀은 건너뛰고 빈 셀에만 ID를 채울 수 있습니다
> - 시작 번호를 지정하면 기존 ID 체계와 연속된 ID를 생성할 수 있습니다

> [!WARNING]
> 랜덤 모드는 전역 고유성을 보장하지 않고, **이번 생성 배치 내에서만 중복되지 않음**을 보장합니다. 테이블에 이미 다른 ID가 있다면 [[데이터 검증]]의 `unique` 규칙으로 중복을 추가로 점검하세요.
