# 리치 텍스트 편집 모드

Notion과 같은 리치 텍스트 편집 경험을 제공합니다.

## 열기 방법

1. 셀 선택 → 오른쪽 클릭 메뉴 → CT 속성 → 리치 텍스트 편집기로 설정
2. 해당 열이 리치 텍스트 편집기로 설정됩니다
3. 처음 3행을 제외하고 셀을 더블 클릭하면 리치 텍스트 편집기 인터페이스가 열립니다
