# 사용자 정의 수식

사용자가 직접 수식을 등록하고 관리할 수 있으며, 셀에서 호출하여 데이터 처리를 자동화합니다.

## 기능 개요

| 기능 | 설명 |
|------|------|
| 수식 등록 | JavaScript 기반 사용자 정의 수식을 등록하여 셀에서 호출 |
| CRUD 관리 | 수식의 생성, 조회, 수정, 삭제를 지원 |
| 영구 저장 | 등록된 수식은 프로젝트에 영구적으로 저장 |
| 가져오기 / 내보내기 | 수식 정의를 파일로 내보내거나 다른 프로젝트에서 가져오기 |

## 사용 방법

### 수식 등록

1. 메뉴에서 「사용자 정의 수식 관리」를 엽니다
2. 「새 수식」을 클릭합니다
3. 수식 이름, 설명, 파라미터를 설정합니다
4. JavaScript로 수식 로직을 작성합니다
5. 「저장」을 클릭하여 등록합니다

### 셀에서 호출

등록된 수식은 셀에서 일반 수식처럼 호출할 수 있습니다:

```
=MY_FORMULA(A1, B1)
```

## 수식 관리

| 작업 | 설명 |
|------|------|
| 생성 | 새 수식 추가 |
| 편집 | 기존 수식의 이름, 설명, 코드 수정 |
| 삭제 | 더 이상 필요 없는 수식 삭제 |
| 가져오기 | JSON 파일에서 수식 정의를 가져오기 |
| 내보내기 | 수식 정의를 JSON 파일로 내보내기 |

## 영구 저장

등록된 수식은 프로젝트 설정에 자동으로 저장되며, 프로젝트를 다시 열어도 수식이 유지됩니다.
