# 영구 스크립트 라이브러리

새 프로젝트를 열 때마다 지난번에 다듬어 둔 스크립트들을 다시 작성해야 하나요? 잘 만든 수식 함수가 여기저기 프로젝트에 흩어져 찾을 수 없나요? 스크립트 라이브러리가 바로 이것을 해결합니다: 스크립트 편집기에서 작성한 스크립트 / 등록한 수식 함수를 **한 번 저장해 프로젝트 간 영구 재사용**하니, 다시 작성할 필요가 없습니다.

## 스크립트 라이브러리 열기

메인 창 메뉴 → **도구 → 스크립트 라이브러리**

또는 Python 스크립트 편집기 상단에서 **스크립트 라이브러리** 버튼을 클릭하세요.

## 스크립트 라이브러리 패널

열면 분류별로 그룹화된 스크립트 목록이 나타납니다:

![스크립트 라이브러리 패널](Res/zh/images/脚本库面板.png)

- **그룹**: "기능 분류" 태그로 자동 그룹화
- **스코프 전환**: 전역(모든 프로젝트에서 사용) / 현재 프로젝트 전용
- **활성화 / 비활성화**: 비활성화하면 함수를 호출할 수 없지만 설정은 유지
- **검색**: 상단 검색창으로 스크립트명 / 태그 / 설명 필터링

## 스크립트 메타데이터

각 스크립트는 코드 자체 외에도 다음을 가집니다:

| 필드 | 필수 | 설명 |
|------|------|------|
| 이름 | ✅ | 수식 호출명, 고유 |
| 분류 태그 | ❌ | 그룹화용(수치 계산 / 문자열 처리 / ...) |
| 설명 | ❌ | 호버 툴팁 / 문서 생성용 |
| 작성자 | ❌ | 누가 작성했는지 |
| 버전 | ❌ | 팀 동기화용 |
| 스코프 | ✅ | 전역 / 현재 프로젝트 |

## 프로젝트 간 동기화

**전역** 스크립트는 `~/.configNexus/scripts/global/`에 저장되어 모든 프로젝트가 공유합니다.

**현재 프로젝트** 스크립트는 `<프로젝트>/scripts/local/`에 저장되어 프로젝트를 따라갑니다(Git 버전 관리에 포함 권장).

## Steam 워크샵과 연동

스크립트 라이브러리의 스크립트는 **컴포넌트로 패키징**해 Steam 워크샵에 업로드할 수 있습니다:

1. 패키징할 스크립트 몇 개를 선택
2. **컴포넌트로 패키징** → 컴포넌트 메타데이터 입력
3. 워크샵에 업로드

다른 사람이 구독하면 이 스크립트들이 그의 스크립트 라이브러리에 자동으로 나타납니다.

## 스크립트 의존성

스크립트끼리 서로 호출할 수 있습니다:

```python
# 스크립트 A: 기본 도구
def round_to(value, step):
    return round(value / step) * step

# 스크립트 B: A 호출
from script_lib import round_to  # 특수 import 문법

def calc_price(base, level):
    raw = base * (1 + level * 0.1)
    return round_to(raw, 0.1)
```

> [!NOTE]
> `from script_lib import xxx`는 ConfigNexus 고유의 import 문법으로 — 스크립트 라이브러리에서 다른 스크립트를 가져올 수 있습니다. 일반 Python `import`로는 안 됩니다.

## 문서 생성

스크립트 라이브러리 패널 우측 상단 **문서 생성** → Markdown 파일을 내보내, 모든 스크립트 + 설명 + 시그니처를 나열합니다. 적합한 용도:

- 팀 온보딩 문서
- 프로그래머에게 "기획 쪽에서 어떤 함수를 쓸 수 있는지" 보여주기

## 보안

스크립트는 샌드박스에서 실행됩니다([[Python 스크립트 편집기]] 튜토리얼 참고). 스크립트 라이브러리도 같은 제한:

- `open()` 파일 불가
- `subprocess` 불가
- `os.environ` 변경 불가

어떤 스크립트가 예외적으로 권한이 필요하면(드묾), 스크립트 메타데이터에서 "권한 상승"을 신청하면 시작 시 확인 대화상자가 뜹니다.

## 주의 사항

> [!WARNING]
> 스크립트 삭제는 **복구할 수 없습니다** — 로컬 파일도 함께 삭제됩니다. 중요한 스크립트는 먼저 Git으로 백업하거나, 내보낸 뒤 삭제하기를 권장합니다.

> [!TIP]
> 명명 권장: 동사로 시작, 소문자 밑줄(`calc_exp` / `validate_id` / `gen_localized_key`). 이렇게 하면 셀 수식 호출 시 가장 자연스럽게 보입니다.
