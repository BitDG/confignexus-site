# Python 수식 통합

캐릭터 경험치 공식을 바꿨더니 수천 개 셀을 수동으로 새로 고쳐야 하나요? 공격력 알고리즘을 조정하면 하나를 건드려도 전부 바꿔야 하나요? Python 수식 통합은 복잡한 계산 로직을 Python 함수로 작성해 셀에 연결합니다 — Excel 수식처럼, 의존하는 셀이 바뀌면 모든 하위 셀이 **전부 자동 재계산**됩니다. 복잡한 수치 규칙을 한 줄로 해결합니다.

"Python 스크립트 편집기"(직접 작성한 스크립트로 일괄 처리)와는 서로 다른 두 기능입니다:

| 항목 | Python 스크립트 편집기 | Python 수식 통합(이 글) |
|------|------------------------|--------------------------|
| 트리거 방식 | 수동으로 "실행" 클릭 | 셀에 수식을 쓰면 자동 계산 |
| 용도 | 일회성 일괄 처리 | 지속적으로 작동하는 계산 로직 |
| 캐시 | 캐시 안 함 | SmartCache 자동 캐시 |
| 일괄 최적화 | 최적화 안 함 | BatchExecutor 자동 병합 |

## 빠른 시작

1. Python 스크립트 편집기를 열고 함수 하나를 작성합니다:

   ```python
   def calc_exp(level):
       return level ** 2 * 100
   ```

2. 수식 시스템에 등록(편집기 상단 버튼 **수식으로 등록**)

3. 임의의 셀에 작성:

   ```
   =calc_exp(A2)
   ```

   A2 = 5일 때 이 셀은 자동으로 2500을 계산합니다. A2를 바꾸면 → 이 셀이 자동 재계산됩니다.

## 수식으로 등록

스크립트 편집기 상단 **수식으로 등록** 버튼 → 등록할 함수 선택 → 수식 이름 지정(기본값은 함수명).

등록 후 함수는 수식 시스템에 영구히 존재하며, 프로젝트 간 사용 가능(기본 스코프)하거나 "현재 프로젝트 전용"으로 지정할 수도 있습니다.

## SmartCache 스마트 캐시

같은 입력 → 같은 출력 → 중복 계산 안 함:

- 캐시 키: `함수명(파라미터 직렬화)`
- LRU 정책: 최근 사용한 1000개 결과를 메모리에 캐시
- TTL: 기본 5분, 의존 데이터 변화 시 수동으로 지움

효과: 한 테이블의 10000개 셀이 같은 함수를 호출하고 대부분 파라미터가 중복되면 → 실제로는 수십 번만 계산.

## BatchExecutor 일괄 실행

같은 함수가 여러 셀에서 호출되면 시스템이 자동으로 요청을 병합합니다:

- 10ms 내에 N개의 동일 함수 호출을 감지 → 한 번의 Python 프로세스 호출로 병합
- Python 함수가 받는 것은 파라미터 배열 → 결과 배열을 반환 → 각 셀로 분배

효과: 셀을 하나씩 호출하면 원래 N번의 Python 프로세스 왕복인데 → 실제로는 1번만 왕복. 큰 테이블 일괄 재계산이 분에서 초로 단축됩니다.

> [!TIP]
> 작성한 Python 함수는 일괄 최적화를 **신경 쓸 필요가 없습니다**. 시스템이 "이 함수를 일괄화할 수 있는가"를 자동 판단합니다 — 부작용 없는 순수 함수는 자동으로 batch를, I/O가 있는 함수는 자동으로 단건 호출을 합니다.

## 셀에 무엇을 쓸 수 있는가

- 기본 호출: `=my_func(A1)`
- 중첩: `=my_func(other_func(A1, B1))`
- 내장 수식과 혼용: `=SUM(my_func(A1:A10))`(주의: range를 넘길 때는 함수가 배열 파라미터를 지원해야 함)
- 문자열 리터럴: `=lookup('item', 'id', A1)`

## 함수 시그니처 규약

수식으로 등록하는 함수는 반드시:

1. **부작용 없음**(파일 쓰기 금지, 전역 상태 변경 금지)
2. **기본 타입 반환**(int / float / str / bool / list / dict) — 객체 / 클래스 인스턴스 반환 금지
3. **파라미터 순서 고정**(수식 호출은 위치 인자로 전달, 키워드 인자 미지원)

규약에 맞지 않는 함수는 등록 시 경고되고 실행 시 오류가 납니다.

## 오류 처리

수식 안에서 Python이 예외를 던지면 → 셀에 `#ERR!`가 표시되고, 마우스를 올리면 예외 상세를 봅니다:

```
#ERR! ZeroDivisionError: division by zero
  at calc_exp(level=0)
```

## 성능 벤치마크

| 상황 | 캐시 없음 / 일괄 없음 | SmartCache + BatchExecutor |
|------|----------------------|----------------------------|
| 5000 셀 호출, 파라미터 전부 동일 | 5000번 Python 호출 | 1번(캐시 적중 4999번) |
| 5000 셀 호출, 파라미터 전부 다름 | 5000번 Python 호출 | 5번(배치당 1000) |
| 5000 셀 호출, 80% 중복 | 5000번 | ~1번(중복은 전부 캐시) |

> [!WARNING]
> 함수 안에 `time.sleep` / 네트워크 IO / 파일 IO를 **쓰지 마세요** — 전체 테이블 재계산을 느리게 합니다. 이런 작업은 "스크립트 편집기"에서 수동으로 실행하세요.
