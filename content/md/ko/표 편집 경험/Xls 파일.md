# Xls 파일

Excel 97-2003 형식(.xls)의 가져오기 및 사용을 지원합니다.

## Xls 파일 가져오기

### 방법 1: 메뉴 가져오기

파일 → xlsx 가져오기 → xls 형식 파일 선택하여 가져오기

video:Res/zh/videos/导入xls.webm|xls 파일 가져오기

### 방법 2: 드래그 앤 드롭

xls 파일을 직접 인터페이스에 드래그 앤 드롭하여 가져올 수도 있습니다.

## 형식 지원 세부 정보

ConfigNexus로 가져온 Xls 파일은 다음 기능을 지원합니다:
- ❌ 수식 (미지원 — Python 수식으로 대체 가능, [[Python 수식 통합]])
- ✅ 글꼴 색상
- ✅ 글꼴 스타일
- ✅ 글꼴 크기
- ✅ 워크시트 탭 색상
