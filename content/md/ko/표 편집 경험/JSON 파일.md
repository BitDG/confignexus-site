# JSON 파일

JSON 객체 배열 형식의 가져오기 및 내보내기를 지원합니다.

## 지원되는 객체 배열

### 표준 JSON 배열

```json
[
  {
    "id": 1,
    "name": "아이템1",
    "type": "weapon",
    "price": 100
  },
  {
    "id": 2,
    "name": "아이템2",
    "type": "armor",
    "price": 200
  }
]
```

## JSON 가져오기

### 방법 1: 메뉴 가져오기

파일 → JSON 가져오기 → JSON 파일 선택
