# JSON 파일

JSON 객체 배열 형식의 가져오기 및 내보내기를 지원합니다.

## 지원되는 객체 배열

### 표준 JSON 배열

```json
[
  {
    "id": 1,
    "name": "아이템1",
    "type": "weapon",
    "price": 100
  },
  {
    "id": 2,
    "name": "아이템2",
    "type": "armor",
    "price": 200
  }
]
```

## JSON 가져오기

### 방법 1: 메뉴 가져오기

파일 → JSON 가져오기 → JSON 파일 선택

video:Res/zh/videos/导入json.webm|JSON 가져오기

### 방법 2: 붙여넣기 가져오기

복사한 JSON 콘텐츠는 붙여넣기 시 자동으로 인식되어 가져옵니다

video:Res/zh/videos/复制gif.webm|JSON 붙여넣기 가져오기

> [!NOTE]
> JSON 내보내기는 데이터 내용만 포함하고 스타일(색상, 글꼴 크기)은 포함하지 않습니다. CT 열 타입 같은 프로젝트 설정은 JSON에 나타나지 않으며 `.cnx` 파일에 저장됩니다. [[cnx 프로젝트 파일]] 참고.
