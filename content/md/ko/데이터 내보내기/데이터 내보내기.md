# 데이터 내보내기

다양한 프로젝트 요구 사항을 충족하는 다중 형식 데이터 내보내기를 지원합니다.

## 내보내기 경로 설정

설정 → 내보내기 구성에서 다양한 파일 형식의 내보내기 경로를 구성할 수 있습니다.

video:Res/zh/videos/导出数据地址配置.webm|내보내기 경로 구성

## 내보내기 작업

1. 파일 → 데이터 내보내기 클릭
2. 해당 데이터 형식을 선택하여 내보내기
3. 선택적으로 "데이터 검증"을 체크

video:Res/zh/videos/导出数据.webm|데이터 내보내기

> [!IMPORTANT]
> 데이터 검증이 활성화되어 있고 실패하면 내보내기를 완료할 수 없습니다.

## 내보내기 범위

- 데이터 내보내기는 **현재 탭**의 데이터만 내보냅니다
- 각 워크시트는 별도의 파일로 내보내집니다
