# json文件

## 解决什么问题

JSON 导入解决已有结构化数据需要回到表格里维护的问题。它适合把程序侧数据、工具导出的 JSON 或临时配置载入 ConfigNexus。

## 什么时候用

- 已有 .json 数据文件。
- 想把结构化数据转成表格检查。
- 需要把程序数据交给策划维护。

## 怎么开启

1. 从导入入口选择 json 文件。
2. 确认系统识别出的表结构。
3. 必要时调整字段名和类型。

## 操作步骤

### 第 1 步：导入 JSON

选择目标文件。数组通常会转成多行，对象字段会转成列。

### 第 2 步：检查字段展开

重点看嵌套对象、数组字段是否按预期展开。复杂结构可能需要保留为 JSON 单元格。

### 第 3 步：保存工程

整理后保存为 .cnx，方便继续配置 CT、验证和导出规则。

## 常见错误

> [!warning]
> JSON 结构太自由时，自动展开结果不一定符合策划维护习惯。必要时改用 JSON 编辑器列。

> [!tip]
> 导入后先导出一次，对比原 JSON 的关键字段是否一致。
