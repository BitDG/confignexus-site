# JSON 文件

支持导入和导出 JSON 的对象数组格式。

## 支持对象数组

### 标准 JSON 数组

```json
[
  {
    "id": 1,
    "name": "道具1",
    "type": "weapon",
    "price": 100
  },
  {
    "id": 2,
    "name": "道具2",
    "type": "armor",
    "price": 200
  }
]
```

## JSON 导入

### 方式一：菜单导入

文件 → 导入 JSON → 选择 JSON 文件
