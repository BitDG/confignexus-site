# JSON 文件

策划表改完，要导出给程序员一份 JSON——或者程序员给了一份 JSON 数据让你用 ConfigNexus 改几行再导出。ConfigNexus 支持 JSON 对象数组格式的双向读写：**导入直接变成表格，编辑完一键导出**。但有一个坑要提前知道：导出时**空格子的 key 会被省略，不是变成 `null`**——引擎那边要按可选字段处理，否则访问不存在的 key 会崩。

> [!tip]
> 对象数组（Object Array）就是这种格式：`[{...}, {...}]`——外面是数组，里面每个元素是一行记录（key-value 对象）。ConfigNexus 只支持这种格式，不支持外层再套一个 key 的嵌套结构。

## 它能接受什么格式的 JSON

只支持**顶层是数组、元素是对象**的格式：

```json
[
  { "id": 1001, "name": "烈焰剑", "type": "weapon", "price": 500 },
  { "id": 1002, "name": "寒冰护盾", "type": "armor", "price": 300 }
]
```

不支持的格式及处理方法：

| 不支持的格式 | 处理方法 |
|---|---|
| 外面套了一层 key：`{ "items": [...] }` | 用文本编辑器去掉外层，只保留 `[...]` |
| 单个对象：`{ "id": 1, "name": "xxx" }` | 包一层数组变成 `[{...}]` |
| 子对象字段：`"effect": { "hp": 100 }` | 导入后会变成字符串；建议改用 JSON 列类型（见[[JSON编辑器]]） |

## 怎么导入

### 第 1 步：菜单导入

主窗口菜单 → **文件 → 导入 JSON** → 选你的 `.json` 文件 → 确认。

导入完成后，JSON 数组里每个对象的 key 自动成为列名（第一行），每条记录的值填进对应行。

video:Res/zh/videos/导入json.webm|导入 JSON 文件

### 第 2 步：或者直接粘贴

复制一段 JSON 数组文本 → 在主窗口表格里按 **Ctrl+V** → 软件自动识别 JSON 格式，直接导入为新行，省去存文件的步骤。

video:Res/zh/videos/复制gif.webm|粘贴 JSON 数组直接导入

## 怎么导出回 JSON

编辑完数据，一键导出：

1. 菜单 **文件 → 导出数据**，打开导出面板。
2. 勾选 **JSON**。
3. 给 JSON 指定一个输出文件夹，点导出。

产物是标准对象数组 `.json`，引擎可以直接读。

video:Res/zh/videos/导出JSON.webm|导出 JSON 数据

## 导出时的关键坑：空格子不等于 null

导出 JSON 时，**空单元格的 key 在那条记录里直接消失**——不是写成 `"effect": null`，而是那个 key 根本不存在。

举例：某道具的 `effect` 列留空，导出后这条记录是：

```json
{ "id": 1004, "name": "魔力晶石", "type": "material", "price": 200 }
```

而不是：

```json
{ "id": 1004, "name": "魔力晶石", "type": "material", "price": 200, "effect": null }
```

> [!important]
> 引擎那边读这类 JSON，**所有非主键字段都要按可选字段处理**（C# 用可空类型 `string?`，TypeScript 用 `field?: string`），否则访问不存在的 key 会抛出运行时错误。演示工程里的 `effect` 列有一行故意留空，导出后可以看到这个行为。

> [!warning]
> **主键列（第一列）为空的整行不会导出**——那行在 JSON 里直接消失，不会出现 `{ "id": null, ... }`。演示工程里故意留了一行空 ID 的行，试试导出后行数是否比表格里少一行。

> [!note]
> JSON 导出只有数据内容，不带样式（颜色、字号）。CT 列类型等工程配置不会出现在 JSON 里，那些信息存在 `.cnx` 文件里。详见[[Cnx工程文件]]。
