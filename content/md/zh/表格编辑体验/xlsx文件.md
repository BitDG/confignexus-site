# xlsx / xlsm 文件

手头一堆 xlsx 配置表，想直接搬进 ConfigNexus 又担心格式丢——颜色没了、公式跑偏了、合并单元格变形了？ConfigNexus 基于 Luckysheet 内核渲染 xlsx，**导进来的数据、样式、公式几乎原样保留**，操作手感跟 Excel 一致。

## 导入方式

### 方式一：菜单导入

主窗口菜单 → **文件 → 导入 xlsx** → 选文件 → 完成。

video:Res/zh/videos/导入xlsx.webm|导入xlsx文件

### 方式二：拖拽

直接把 .xlsx / .xlsm 拖到主窗口任意位置，自动导入。

### 方式三：从文件浏览器双击

文件浏览器里双击 .xlsx 文件 → 在主窗口新页签打开。

## 导入向导

文件较复杂时（多 sheet、有合并单元格、含富文本），系统会启动**导入向导**：

| 步骤 | 选项 |
|------|------|
| Step 1 | 选要导入的 sheet（多选） |
| Step 2 | 配置每个 sheet 的字段映射（哪一列是 ID / 标题 / 描述等） |
| Step 3 | 自动识别 CT 列类型（图片列 / 日期列 / JSON 列等） |
| Step 4 | 预览导入结果 |

字段映射和 CT 列类型识别**会保存到 ConfigNexus 配置**，下次导入同名 sheet 自动套用。

## 保留的特性

| 特性 | 状态 |
|------|------|
| 公式 | ✅ |
| 字体颜色 / 样式 / 字号 | ✅ |
| 单元格背景色 | ✅ |
| 合并单元格 | ✅ |
| 边框 | ✅ |
| 工作表标签颜色 | ✅ |
| 数据有效性（下拉框） | ✅ 但会转为 CT 枚举列 |
| 条件格式 | ✅ |
| 冻结行列 | ✅ |
| 图表 | ❌ 暂不支持 |
| 透视表 | ❌ |

## xlsm 文件

xlsm 是带宏的 xlsx。ConfigNexus **不支持执行宏 / VBA**——为了安全。

替代方案：

- 简单宏 → 改写为 Python 脚本（详见教程[[Python脚本编辑器]]）
- 复杂宏 → 改写为 Python 公式（详见[[Python公式集成]]）

> [!NOTE]
> 不支持宏 ≠ 拒绝导入。xlsm 文件能正常导入，只是宏代码会被**丢弃**。导入完成后会有提示告诉你丢弃了多少段宏。

## 导出回 xlsx

主窗口菜单 → **文件 → 导出 → xlsx** → 选输出路径。

退化的东西：

- CT 列类型 → 退化为普通字符串 / 数字列
- Python 公式 → **不导出**（xlsx 没有 Python 运行环境）
- 验证规则 DSL → 部分转为 xlsx 数据有效性

要保留全部信息，存为 cnx 工程文件（详见[[cnx工程文件]]）。

| 场景 | 选 |

## 性能

- 单 sheet 1 万行：导入 < 1 秒，渲染流畅
- 单 sheet 10 万行：启用无限滚动模式（自动），仍流畅
- 多 sheet 50 个：导入 5-10 秒，靠预渲染机制保证切换瞬间

## 注意事项

> [!TIP]
> 第一次导入大文件慢是因为要建索引（CT 列识别、字段映射推断）。导入完成后下次打开同一 cnx 工程是秒开。

> [!WARNING]
> 不要在 ConfigNexus 打开的同时用 Excel 改同一个 xlsx——两边各自有未保存版本，会冲突。先在 ConfigNexus 里关闭再用 Excel 打开。
