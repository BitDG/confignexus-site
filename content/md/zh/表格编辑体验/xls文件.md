# xls 文件（Excel 97-2003 旧格式）

老项目继承来的数据、美术同学给的表，有时候还是 `.xls` 格式——比 `.xlsx` 少一个字母，却少了很多：行列上限只有 65536×256，最要命的是 **xls 本身就不支持公式，导入后公式格子只剩当时的计算结果，公式本身丢失**。ConfigNexus 能直接吃 .xls，但这几个坑要提前知道。

> [!warning]
> **xls 公式导入后会变成纯数值**——原表里的 `=A1+B1` 导进来只剩结果数字，公式本身消失，在 ConfigNexus 里也不会重算。如果源表有关键计算公式，建议在 Excel 里先「全选 → 复制 → 粘贴为值」把公式固化成数字，再导入；或者直接让对方导出成 .xlsx 再给你。

## 它是什么

`.xls` 是 Microsoft Excel 97–2003 时代的二进制格式，现已被 `.xlsx` 取代。主要限制：

| 限制 | 说明 |
|------|------|
| 最大行数 | 65536 行（xlsx 是 1048576 行） |
| 最大列数 | 256 列（xlsx 是 16384 列） |
| 公式 | 不支持——仅存储上次的计算结果 |
| 宏 / VBA | 不执行，出于安全被丢弃 |

## 怎么导入

### 第 1 步：菜单打开

主窗口菜单 → **文件 → 导入 xlsx** → 在文件选择框把文件类型切成「所有文件 (*.*)」→ 选你的 `.xls` 文件 → 确认。

> [!note]
> xls 和 xlsx 共用同一个菜单入口「导入 xlsx」，不要去找单独的「导入 xls」——没有那个。选文件时记得把文件类型切成「所有文件」才能看到 .xls。

video:Res/zh/videos/导入xls.webm|导入 xls 文件

### 第 2 步：或者直接拖拽

把 .xls 文件拖进主窗口任意区域，自动识别格式并导入，无需找菜单。

## 导入后保留什么

| 特性 | 状态 | 说明 |
|------|------|------|
| 数据内容 | ✅ | 所有格子的值原样进来 |
| 字体颜色 / 样式 / 字号 | ✅ | |
| 工作表标签颜色 | ✅ | |
| 合并单元格 | ✅ | |
| 公式 | ❌ | 只保留当时的计算结果，公式丢失 |
| 图表 | ❌ | 暂不支持 |
| 宏 / VBA | ❌ | 出于安全被丢弃，导入后会有提示 |
| 超出行列上限的内容 | ❌ | 65536 行或 256 列以外的部分被截断 |

## 导入完成后：建议转格式

xls 是过渡文件，不适合长期在 ConfigNexus 里用。导入完成后建议：

- **存成 cnx**：菜单 **文件 → 另存为 cnx**，保留 CT 列类型、验证规则，日常工作用这个（详见[[Cnx工程文件]]）。
- **导出为 xlsx**：菜单 **文件 → 导出 → xlsx**，升级成新格式再给别人用或进版本控制。

## 注意事项

> [!warning]
> 如果源表靠公式做关键计算（如"总价 = 单价 × 数量"），导入后那列只有结果数字，修改单价不会自动更新总价。可在 ConfigNexus 里补 Python 公式（详见[[Python公式集成]]），或在导入前先在 Excel 里把公式固化成值。

> [!tip]
> 遇到"导入后行数比原表少"，先排查原表是否超出 65536 行——xls 规格上限，多出来的行连 Excel 自己都存不下，导进来自然也没有。
