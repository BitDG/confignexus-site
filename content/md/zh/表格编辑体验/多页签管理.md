# 多页签管理

改 A 表到一半，要去 B 表查个数值，把 B 表打开——结果 A 表刚才的选区和光标位置全丢了。多页签就是解决这个的：主窗口**同时打开多张表**，每张表一个标签，切来切去各自保持编辑状态，互不打扰。

## 页签类型

| 类型 | 图标 | 含义 |
|------|------|------|
| 普通工作表 | 📊 | xlsx / cnx 文件的某个 sheet |
| 欢迎页 | 🏠 | 首页（本页所在） |
| 设置 | ⚙️ | 设置中心 |
| 引用关系图 | 🔗 | 单实例复用，详见[[引用关系图]] |

![多页签管理-页签栏](Res/zh/images/多页签管理-页签栏.png)

## 打开新页签

| 操作 | 说明 |
|------|------|
| 文件浏览器双击文件 | 在新页签打开 |
| 菜单 文件 → 打开 | 选文件 → 新页签 |
| 菜单 文件 → 新建 | 空白工作表 → 新页签 |
| 拖文件到主窗口 | 自动打开为新页签 |
| 点页签栏最右的 **+** | 新建空白工作表 |
| 点欢迎页 → 设置 | 单实例设置页 |

## 页签栏右键菜单

页签上右键：

- **关闭** —— 关闭这一个
- **关闭其他** —— 留这个，关所有其他
- **关闭右侧所有** —— 关掉这个页签右侧所有
- **复制路径** —— 复制源文件路径到剪贴板
- **在文件管理器中显示** —— 跳到该文件所在文件夹

## 性能优化（重要）

ConfigNexus 不会一打开就把所有页签都完整渲染——只有当前激活的页签**真的渲染** Luckysheet 实例。切到别的页签时：

- 当前页签的 Luckysheet 实例**保留状态**（光标位置、选区、未保存改动）
- 隐藏起来不占 CPU
- 切回来瞬间恢复

效果：开几十个页签内存占用线性增长，但 CPU 不会被几十个隐藏页签拖慢。

## 预渲染机制

为了切页签时不需要等"创建 Luckysheet 实例"那 1-2 秒，系统会**预渲染**一个隐藏的实例：

- 启动时如果没打开任何表，后台静默渲染一个空 Luckysheet
- 用户点 **+** 时直接用预渲染的实例 → 即时显示
- 用完再后台准备下一个

这是为什么"新建空白页签"几乎瞬间出来。

## 拖拽排序

页签可以拖动排序——长按页签头横向拖到目标位置。

## 关闭未保存改动

关闭有未保存改动的页签时弹确认框：

- **保存并关闭**
- **不保存关闭**
- **取消**

设置里可以改默认行为（详见[[自动保存]]）。

## 页签数量上限

理论无上限，但建议**不超过 20 个同时打开**。开太多会让页签栏挤成一团（虽然能横向滚），切换体感也会下降。

## 注意事项

> [!TIP]
> 切页签的快捷键：**Ctrl+Tab** 下一个 / **Ctrl+Shift+Tab** 上一个。可以快速在两个常用表之间来回切。

> [!NOTE]
> 欢迎页 / 设置页 / 引用关系图 都是**单实例**——再次打开会切到已有页签，不会爆开第二个。
