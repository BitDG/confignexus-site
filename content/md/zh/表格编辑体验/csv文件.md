# CSV 文件支持

支持标准 CSV 格式的导入和使用，具备自动编码检测、分隔符识别和异步解析能力。

createtab:Res/zh/templates/CSV导入演示.cnx

## 功能总览

| 功能 | 说明 |
|------|------|
| Web Worker 异步解析 | 大文件解析在后台线程执行，不阻塞界面操作 |
| 自动编码检测 | 自动识别 UTF-8、GBK、Shift_JIS 等编码格式 |
| 自动分隔符检测 | 智能识别逗号、制表符、分号等分隔符 |
| 拖拽导入 | 直接拖拽 CSV 文件到界面即可导入 |

## 支持的分隔符

| 分隔符 | 说明 |
|--------|------|
| `,` | 逗号（默认） |
| `\t` | 制表符（TSV 格式） |
| `;` | 分号（欧洲地区常用） |
| `\|` | 竖线 |

## 导入方式

### 方式一：菜单导入

文件 → 导入 CSV → 选择 CSV 格式文件进行导入

video:Res/zh/videos/导入csv.webm|导入CSV

### 方式二：拖拽导入

直接拖拽 CSV 格式的文件到 ConfigNexus 界面即可导入

video:Res/zh/videos/拖拽csv.webm|拖拽导入CSV

## 注意事项

> [!NOTE]
> - CSV 格式仅包含数据内容，不包含显示格式（如字体、颜色等样式信息）
> - 含有换行符的字段需用双引号包裹
> - 导入大文件时请耐心等待 Web Worker 解析完成
