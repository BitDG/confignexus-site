# 🚀 新手第一课

第一次打开 ConfigNexus，看到一堆按钮不知道从哪下手？这篇就带你**一条龙走通第一个配置表**——从打开软件，到把数据导出成游戏引擎能直接吃的格式。全程不用写代码，跟着点就行。

> [!tip]
> 这篇是「总览路线图」。每一步里提到的功能都有专门的详细教程，想深入就去左侧目录找对应那篇（本文用《书名号》标出）。

---

## 它是干什么的

一句话：**ConfigNexus 是给游戏配置数据用的"超级 Excel"**。你像用 Excel 一样填表（数值、文本、道具、对话……），它帮你校验数据有没有填错，最后一键导出成 Unity / Unreal / Godot / 自研引擎能直接读的格式（JSON、C#、Lua 等）。

策划填表、程序读数据、美术配资源，三方共用一个工程，不再靠"传 Excel 改 Excel"。

---

## 第 1 步：认识界面

打开后是一个类 Excel 的主窗口。先认四个地方：

| 位置 | 是什么 |
|------|--------|
| 顶部菜单栏 | **文件 / 视图 / 工具 / 帮助** 四个菜单，所有功能入口都在这 |
| 表格区 | 中间的大表格，跟 Excel 操作一样（填值、筛选、冻结、公式） |
| 页签栏 | 表格上方，可以同时开多张表，互不影响（详见[[多页签管理]]） |
| 右下角桌宠 | 一只会动的小助手，点它能展开 AI 对话和常用工具 |

> [!note]
> 顶部菜单的归属记住就好：**新建/打开/导入/导出/保存**都在「文件」；**日志/文件浏览器**在「视图」；**Python 脚本/脚本库**在「工具」；**教程/关于**在「帮助」。

---

## 第 2 步：建你的第一张表

有四种开局方式，挑一个：

1. **从零新建**：菜单 **文件 → 新建项目**（或点页签栏的 ➕），得到一张空表，自己填。
2. **导入已有 Excel**：菜单 **文件 → 导入Excel**，选你手头的 `.xlsx` / `.xls`，数据原样进来（详见[[Xlsx文件]]）。
3. **导入 JSON / CSV**：菜单 **文件 → 导入JSON** 或 **导入CSV**（详见[[JSON文件]][[CSV文件]]）。
4. **套用模板**：菜单 **文件 → 模板**，挑一个起步模板直接改。

> [!tip]
> 新手建议先用「导入 Excel」把你现有的一张表搬进来，最有体感。

---

## 第 3 步：编辑数据

进表之后就像用 Excel 一样直接填。ConfigNexus 比 Excel 多的是 **CT 列类型**——给某一列指定"这列装的是什么数据"，编辑体验立刻升级：

- **右键列头 → 设置列类型**，可选：
  - **日期**：双击弹日期选择器，不用手敲（详见[[日期编辑]]）
  - **资源**：双击选图片/音频，单元格里显示缩略图（详见[[资源编辑]]）
  - **JSON**：复杂嵌套结构用代码+树状视图编辑，不在格子里手搓（详见[[JSON编辑器]]）
  - **多数据**：`[{...},{...}]` 这种对象数组，可视化批量编辑（详见[[多数据编辑]]）
  - **富文本**：像 Notion 一样所见即所得排版（详见[[富文本编辑]]）

> [!tip]
> 一开始不用急着配 CT，纯文本/数字直接填就行。等遇到"日期老填错格式""图片路径记不住"这类痛点，再回头给那一列设对应的 CT 类型。

---

## 第 4 步：检查数据有没有填错

表填完，导出前先体检一遍，别把错误数据带进游戏。

ConfigNexus 用**验证规则 DSL**：在表头那一行写一小段规则（比如某列 `required`（必填）、`unique`（不能重复）、`range(1,100)`（值在 1~100 之间）），软件就会**实时把填错的格子标红**，点验证日志能直接跳到出错的格子。

- 详细写法看[[数据验证]]和[[验证规则DSL]]两篇。
- 新手记一个最有用的：给"ID 列"加 `unique`，立刻能查出重复 ID。

---

## 第 5 步：导出给引擎用

数据没问题了，一键导出：

1. 菜单 **文件 → 导出数据**，打开导出面板。
2. 勾选你引擎要的格式（可多选）——一共 **10 种**：
   - 文本类：**JSON / YAML / CSV**
   - 代码类（自带加载器）：**C# / TypeScript / Lua / C++**
   - 二进制类：**Bytes / MessagePack / Protobuf**
3. 给每种格式选输出文件夹，点导出。
4. 建议勾上「导出前验证」，有错会拦下来。

> [!tip]
> 不知道选哪个？用 Unity 就选 **C# + JSON**；用 Unreal 选 **C++ + JSON**；前端/小游戏选 **TypeScript** 或 **JSON**。详见[[数据导出]]。

---

## 第 6 步：保存工程

记得保存你的工作：

- 菜单 **文件 → 保存项目**，或快捷键 `Ctrl+S`。
- 推荐存成 **`.cnx`** 格式（ConfigNexus 原生工程文件）——它会**完整保留** CT 列类型、跨表引用、Python 公式这些 Excel 存不下来的东西，关掉重开原样还在。

> [!warning]
> 如果存成 `.xlsx`，CT 类型、跨表引用、公式这些高级信息会丢。日常工作请用 `.cnx` 存，要交给别人或归档时再导出成对应格式。
