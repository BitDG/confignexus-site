# 资源编辑器

可视化的游戏资源管理和编辑功能，支持图片预览、音频播放和资源文件夹管理。

## 功能总览

| 功能 | 说明 |
|------|------|
| 图片资源预览 | 鼠标悬停在单元格上时自动显示图片缩略图 |
| 音频资源播放 | 支持直接在编辑器内播放音频资源 |
| 资源文件夹管理 | 配置多个资源目录，统一管理资源路径 |
| 文件搜索 | 在资源目录中按名称快速搜索文件 |
| 文件操作 | 支持资源文件的重命名和删除 |
| 拖拽引用 | 从资源面板拖拽文件到单元格自动填入路径 |

## 使用方法

### 步骤 1：设置列类型

选择单元格 → 鼠标右键菜单 → CT 属性 → 设置为资源编辑器。

### 步骤 2：配置资源目录

在资源编辑器设置中添加项目的资源文件夹路径，支持配置多个目录。

### 步骤 3：选择资源

双击单元格打开资源选择界面，浏览或搜索目标资源文件。

### 步骤 4：资源引用

选中资源后，文件路径会自动填入单元格。也可直接从资源面板拖拽文件到目标单元格。

## 资源预览

设置为资源编辑器的列，鼠标悬停在单元格上时会自动显示资源预览：
- **图片文件**（png, jpg, webp 等）：显示缩略图预览
- **音频文件**（mp3, wav, ogg 等）：显示播放控件
- **其他文件**：显示文件名和类型图标

## 注意事项

> [!NOTE]
> - 资源路径基于配置的资源目录，填入单元格的是相对路径
> - 修改资源目录配置后需重新加载才能生效
> - 支持常见的游戏资源格式（图片、音频、动画等）
