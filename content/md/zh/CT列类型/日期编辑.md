# 日期编辑器

表里有个"开始日期"列，策划每人各填各的——`2026.4.17`、`4/17/2026`、`20260417` 混在一起，导出 JSON 给程序员，格式不统一直接报解析错误。日期编辑器就是干这个的：把某列设成日期类型，双击格子弹出可视化日历，选完自动用你定的格式写回去，整列格式从此统一，导出再也不炸。

> [!tip]
> 日期编辑器适合所有"要填日期"的列——活动开始时间、版本发布日期、任务截止时间等。设了之后，这列的日期只能通过日历选，格式由你统一配置，不会再出现手敲格式不一致的情况。

## 支持的输出格式

| 格式 | 示例 |
|------|------|
| `yyyy-mm-dd` | 2026-04-17 |
| `yyyy/mm/dd` | 2026/04/17 |
| `yyyy-mm-dd HH:mm:ss` | 2026-04-17 14:30:00 |
| 时间戳（秒） | 1776556200 |
| 时间戳（毫秒） | 1776556200000 |

## 三步上手

### 第 1 步：把某列设成日期编辑器

选中目标列任意一格 → **右键** → **CT 属性 → 设置为日期编辑器**。整列一次生效。

### 第 2 步：双击数据格打开日历

在日期列里**双击数据行的格子**，日历面板弹出来了。

> [!note]
> 只有数据行双击才弹。表头区（字段名/类型等前几行）双击不弹——故意的。

### 第 3 步：选日期、确认

在日历面板点选目标日期，或点**今天**/**明天**快捷按钮。选完自动按整列配置的格式填入格子，不用手敲。

> [!tip]
> 日期格式在哪配？右键列 → CT 属性 → 在设置面板里选输出格式。整列统一，改一次所有新选的日期都用新格式。已填的旧数据不会自动重新格式化——如需统一历史数据，点**重新格式化此列**按钮。

## 注意事项

> [!warning]
> - 如果某格已有内容，双击打开日历时会预选到已有值对应的日期（能识别常见格式）；若识别失败，日历默认落在今天。
> - "这列是日期列"存在 `.cnx` 工程文件里，存成 `.xlsx` 会丢列类型（日期格式设置一并丢失）。

> [!note]
> 日期数据导出时，格子里存的是什么格式就导出什么字符串（比如 `2026-04-17` 或时间戳数字）；程序那边按约定好的格式解析即可。
