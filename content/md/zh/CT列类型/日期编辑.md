# 日期编辑器

专用的日期选择和编辑界面，通过可视化日历面板避免手动输入日期格式错误。

createtab:Res/zh/templates/日期编辑演示.cnx

## 功能总览

| 功能 | 说明 |
|------|------|
| 日历 UI 面板 | 可视化日历选择器，支持年/月/日逐级选取 |
| 多种日期格式 | 支持 yyyy-mm-dd、yyyy/mm/dd、时间戳等格式 |
| 快捷日期选择 | 一键选择今天、明天等常用日期 |
| 单元格内编辑 | 双击单元格直接弹出日期选择面板 |

## 支持的日期格式

| 格式 | 示例 |
|------|------|
| `yyyy-mm-dd` | 2026-04-17 |
| `yyyy/mm/dd` | 2026/04/17 |
| `yyyy-mm-dd HH:mm:ss` | 2026-04-17 14:30:00 |
| 时间戳（秒） | 1776556200 |
| 时间戳（毫秒） | 1776556200000 |

## 使用方法

### 步骤 1：设置列类型

选择单元格 → 鼠标右键菜单 → CT 属性 → 设置为日期编辑器。设置后该列将启用日期编辑功能。

### 步骤 2：编辑日期

双击数据区域的单元格（前三行表头除外），会弹出日期选择面板。

### 步骤 3：选择日期

在日历面板中选择目标日期，或使用快捷按钮选择「今天」「明天」。选择后日期会按照设定的格式自动填入单元格。

## 注意事项

> [!NOTE]
> - 列的 CT 属性设置为日期编辑器后，该列所有数据行双击都会打开日期面板
> - 前三行（表头区域）不受日期编辑器影响，可正常编辑
> - 日期格式可在列属性中配置，统一控制整列的输出格式
