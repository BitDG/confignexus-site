# 富文本编辑模式

装备描述想给关键词加粗、技能说明想分行分点、剧情文本想标个重点色——纯文本格子干不了这些，填进去就是一坨没格式的字。富文本列就是干这个的：某列开了富文本，双击格子就弹出一个像 Notion 那样的编辑器，标题、加粗、列表、颜色随手排，排好直接存进格子、跟着导出走，不用手敲 `&lt;b&gt;` 这种标签。

> [!tip]
> 富文本（rich text，带格式的文本）适合放"给玩家看的大段说明"——装备 / 技能 / 任务 / 剧情。短名字、数字这种用普通格子就行，别上富文本。

## 怎么用

### 第 1 步：把某列设成富文本

选中目标列任意一格 → **右键** → **CT 属性 → 设置为富文本编辑器**。整列一次生效。

> [!note]
> CT 属性（Column Type，列类型）就是给"这列装什么数据"贴的标签，设一次整列都管，不用一格格点。

### 第 2 步：双击数据格打开编辑器

在富文本列里**双击一个数据行的格子**，编辑器窗口就弹出来了。

> [!warning]
> 只有**数据行**双击才弹。最上面几行是表头区（字段名、中文名、数据类型、描述、数据验证），双击它们不弹——故意的，免得把表头当数据改。

video:Res/zh/videos/富文本编辑器-打开.webm|设为富文本列 → 双击打开编辑器

### 第 3 步：排版

常用就这几招：

- **加粗 / 斜体 / 颜色**：选中一段文字，上方浮出工具栏，点 B、i、Color。
- **标题 / 列表 / 引用 / 表格 / 分割线 / 代码块**：光标停在空行，按 **Tab** 呼出区块菜单挑一个。
- **Markdown 手感**：行首打 `# ` 出标题、`- ` 出列表、`1. ` 出有序列表、`> ` 出引用，跟写 Markdown 一样顺。
- 顶部能在**实时预览 / 纯文本**间切，想直接看底层代码就切纯文本。

> [!tip]
> 装了智能助手（AI）插件的话，空行按空格、或选中文字点工具栏「问智能助手」，能让它帮你润色 / 翻译 / 改语气。没装就不显示，不影响排版。

video:Res/zh/videos/富文本编辑器-排版.webm|加粗 / 改色 / Tab 区块菜单 / 列表 / 保存并应用

### 第 4 步：保存并应用

点底部**保存并应用**，排好的内容就写回格子、存进工程。不想存就点取消。

## 存进格子是什么格式

这点最容易踩坑：

- 排好的内容，是以 **HTML 字符串**存进格子的，比如 `&lt;h3&gt;烈焰长剑&lt;/h3&gt;&lt;p&gt;攻击力 &lt;strong&gt;+120&lt;/strong&gt;&lt;/p&gt;`。表格格子里直接显示的就是这串带标签的文本，导出时导出的也是它。
- 勾了编辑器底部的**保存为 Markdown**，就改存成 Markdown 文本（`### 烈焰长剑` 那种）。
- 导出时**存啥导啥**：导成 JSON / CSV，这字段的值就是上面那串原文。

> [!important]
> 引擎拿到的是**带标签的字符串**，不是排好版的图。引擎那边得有能渲染 HTML / Markdown 的文本控件（或自己解析），才显示得出加粗、颜色、换行。导出前跟程序对一句：吃 HTML 用默认，吃 Markdown 就勾"保存为 Markdown"。

> [!note]
> "这列是富文本列"这个设置（CT 属性）是列的元数据，存在 `.cnx` 里，不会当成额外字段导出。存 `.cnx` 能留住列类型，存 `.xlsx` 会丢。详见[[Cnx工程文件]]。

## 注意事项

> [!warning]
> - 只有数据行双击会弹编辑器，表头区的行不弹。
> - 格子里存的是 HTML / Markdown 字符串，不是图片，导出后靠引擎渲染。
> - 想留住"这列是富文本"，工程存 `.cnx`；存 `.xlsx` 会丢列类型。
