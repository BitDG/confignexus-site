# 富文本编辑

富文本编辑器用于编辑带格式的长文本，例如装备描述、技能说明、任务文本、剧情对白。

## 解决什么问题

普通表格单元格只能放纯文本。想要加粗、分段、列表、强调色时，手写 HTML 或 Markdown 容易出错，也不直观。富文本编辑器提供所见即所得的编辑界面，让文本排版可以直接在单元格对应的编辑器里完成。

## 什么时候用

- 文本会展示给玩家。
- 需要标题、列表、加粗、颜色或分段。
- 文本内容较长，普通单元格不好编辑。
- 希望导出 HTML 或 Markdown 供引擎渲染。

短名字、数值、枚举值不需要富文本。

## 怎么开启

1. 选中目标列的任意单元格。
2. 右键打开菜单。
3. 进入 **CT 属性**。
4. 把列类型设为 **富文本编辑**。
5. 保存工程为 `.cnx`。

## 操作步骤

### 第 1 步：打开富文本单元格

双击富文本列里的数据行单元格，打开编辑器。

### 第 2 步：编辑排版

使用标题、加粗、列表、引用、颜色等工具整理内容。适合把说明文本拆成更容易阅读的结构。

### 第 3 步：确认保存格式

默认保存为带标签的文本。导出前要和程序确认使用 HTML、Markdown 还是纯文本。

### 第 4 步：保存回表格

点击保存后，内容写回当前单元格。

## 常见错误

> [!warning]
> 富文本保存的是文本内容，不是图片。游戏内要显示出加粗、颜色和换行，需要引擎侧文本控件支持对应格式。

> [!tip]
> 如果只是短句或普通名称，用普通文本列更简单，不需要打开富文本编辑器。
