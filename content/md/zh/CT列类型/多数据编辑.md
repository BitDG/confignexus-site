# 多数据编辑模式

在单个单元格中管理复杂的多数据配置，如奖励列表、属性组合等。

createtab:Res/zh/templates/多数据编辑.cnx

打开演示文件参照流程

## 打开方式

1. 选择单元格 → 鼠标右键菜单 → CT 属性 → 设置为多数据编辑器
2. 该列就被设置为多数据编辑器
3. 除该列的前三行数据外，双击单元格都会打开多数据编辑器界面

video: Res/zh/videos/多数据编辑器打开.webm|多数据编辑器打开


## 设置数据

以配置奖励数据为例：`[{1001:100:30},{1002:200:60},{1003:300:90}]`

表示：奖励ID:奖励数量:权重

### 操作步骤

1. 先设置该列为多数据编辑器
2. 双击要填写的单元格，打开多数据编辑器弹窗
3. 在对应的列右键设置列属性，点击 + 号可新建列

video:Res/zh/videos/多数据编辑器设置列.webm|多数据编辑器设置列

4. 填写对应的数据，点击「新建行」可新增行数据

video:Res/zh/videos/多数据编辑器编辑数据.webm|多数据编辑器编辑数据

## 进阶操作

> [!TIP]
> - 类似 `item`、`reward` 的字段可在设置页签中设置为**映射表格**
> - 设置后双击单元格会显示对应的 ID 名称，选择时不易出错
> - 还可以通过按钮快速新增对应的 ID 配置
