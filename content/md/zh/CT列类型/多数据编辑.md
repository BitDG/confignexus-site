# 多数据编辑

奖励列表写成 `[{1001:100:30},{1002:200:60},{1003:300:90}]` ——放一个格子里，策划填完根本看不懂谁是 ID 谁是数量，改错了不知道，导出了程序反序列化报错才发现。多数据编辑就是干这个的：把这种"对象数组"列设成多数据编辑器，双击弹出一张内嵌小表格，每行一条数据、每列对应一个字段，可视化填写再也不怕填串位。

> [!tip]
> 多数据编辑（ct:list，结构化列表）适合"每行结构完全一样"的嵌套数据，比如奖励列表、掉落配置、技能效果列表。结构复杂或不固定时，用 JSON 编辑器更灵活（详见[[JSON编辑器]]）。

## 三步上手

### 第 1 步：把某列设成多数据编辑器

选中目标列任意一格 → **右键** → **CT 属性 → 设置为多数据编辑器**。整列一次生效。

video:Res/zh/videos/多数据编辑器打开.webm|设为多数据编辑器列 → 双击打开编辑器

### 第 2 步：定义列字段

双击一个数据行的格子，弹出多数据编辑器窗口。在编辑器里：

1. 点右上角 **+**（新建列）添加字段；每列右键可以设置**列名称**和**数据类型**
2. 常用字段类型：`int`（整数）、`float`（小数）、`string`（文本）、`bool`（是否）

video:Res/zh/videos/多数据编辑器设置列.webm|在编辑器里新建列、设置字段名和类型

### 第 3 步：填数据、保存

每行填一条记录，点**新建行**可追加；全部填好后点**保存**，数据就以结构化格式写回格子。

video:Res/zh/videos/多数据编辑器编辑数据.webm|填写数据行、新建行、保存回格子

## 进阶：映射表格

> [!tip]
> 类似 `item`、`reward` 这类引用 ID 的字段，可以在编辑器**设置页签**里配置**映射表格**——设置后双击单元格会同时显示对应的 ID 名称（如"铁剑"），选择时不易拼错 ID，还能快速新增对应配置。

## 注意事项

> [!warning]
> 只有**数据行**双击才弹编辑器。表头区（字段名/类型/验证规则等前几行）双击不弹——故意的，免得把表头当数据改。

> [!note]
> - 格子里实际存的是紧凑格式字符串，如 `[{1001:100:30}]`——这是引擎读的原始形式，不是 JSON。
> - 字段定义（列名和类型）存在 `.cnx` 里，存成 `.xlsx` 会丢。
> - 导出时，多数据列按数据类型行的声明序列化；引擎侧需对应解析器（详见[[数据导出]]）。
