# JSON编辑器

JSON 编辑器用于编辑一个单元格里的复杂 JSON 内容，例如奖励参数、关卡参数、技能配置或临时调试字段。

## 解决什么问题

如果直接在格子里写 `{"items":[{"id":1001,"rate":0.5}],"gold":50}`，格子太窄看不全，少一个引号或括号就会导致导出后程序解析失败。JSON 编辑器把单元格内容放进更大的代码编辑区，并提供结构化视图，方便检查层级和格式。

## 什么时候用

- 单元格内容是一个 JSON 对象。
- 结构层级不固定，不能简单拆成固定列。
- 需要临时存放一段复杂参数。
- 比多数据编辑器更需要灵活结构。

如果每条记录字段固定，例如奖励列表里的 `id/count/rate`，优先看 [[多数据编辑]]。

## 怎么开启

1. 选中目标列的任意单元格。
2. 右键打开菜单。
3. 进入 **CT 属性**。
4. 把列类型设为 **JSON编辑器**。
5. 保存工程为 `.cnx`。

## 操作步骤

### 第 1 步：打开 JSON 单元格

在 JSON 列里双击一个数据行单元格。表头区域不会弹出编辑器。

### 第 2 步：编辑并校验

在代码编辑区修改 JSON。保存前先确认结构完整，常见错误包括尾逗号、单引号、缺少右括号、数组和对象层级写错。

### 第 3 步：保存回表格

确认 JSON 合法后保存。编辑器会把内容写回当前单元格。

## 常见错误

> [!warning]
> JSON 必须使用双引号。`{'id':1001}` 不是合法 JSON，应写成 `{"id":1001}`。

> [!tip]
> 如果内容是一组结构完全相同的数据，例如 `[{id:1001,count:2},{id:1002,count:3}]`，多数据编辑器会比 JSON 编辑器更适合策划填写。
