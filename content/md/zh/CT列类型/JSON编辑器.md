# JSON 编辑器

针对单元格里嵌着大段 JSON 的场景——商店标★的"新"功能。基于 Monaco 编辑器 + 树状视图双视图同步，左侧改文本右侧树同步、右侧树点节点左侧高亮。

## 功能总览

| 功能 | 说明 |
|------|------|
| Monaco 代码视图 | 跟 VS Code 同款编辑器，语法高亮 / 错误标红 / 智能补全 |
| 树状结构视图 | 嵌套对象一层层展开，每个节点单独可点 |
| 双向同步 | 改代码树跟着变；点树左侧光标定位 |
| 节点弹窗编辑 | 树里任意层节点右键 → 弹窗编辑单个值（不用在大 JSON 里翻） |
| 类型保护 | 解析失败时不让保存，避免坏数据写回单元格 |

## 打开 JSON 编辑器

任意单元格的 CT 列类型选成 JSON 后，双击该单元格 → 弹出 JSON 编辑器弹窗。

如果单元格内容不是合法 JSON，编辑器会先尝试自动修复（去尾逗号 / 单引号转双引号），不行的话提示具体错误位置。

## 双视图布局

```
+--------------------------+---------------------+
| Monaco 代码视图          | 树状视图            |
| {                        | ▼ root              |
|   "id": 1001,            |   ├ id: 1001        |
|   "name": "测试",        |   ├ name: "测试"    |
|   "rewards": [           |   ▼ rewards         |
|     {"type": "coin",     |     ▶ [0]           |
|      "count": 100}       |     ▶ [1]           |
|   ]                      |   ...               |
| }                        |                     |
+--------------------------+---------------------+
| 错误：第 5 行缺少逗号                          |
+------------------------------------------------+
```

左边改文本 → 右边树立即重渲染。
右边点节点 → 左边编辑器光标跳到对应行。

## 树视图操作

| 操作 | 效果 |
|------|------|
| 点节点 | 选中（左侧光标定位） |
| 双击节点 | 编辑该节点的值（弹小窗，根据类型显示合适控件） |
| 右键节点 | 菜单：新增子节点 / 删除 / 复制路径 / 折叠所有 |
| 拖动节点 | 调整数组元素顺序 |
| 折叠 / 展开 | 节点前的三角图标 |

## 错误处理

代码区下方的状态栏实时显示当前 JSON 是否合法：

- ✅ 合法 → "JSON 有效" + 节点数 + 嵌套层数
- ❌ 错误 → 红色高亮错误行 + 错误描述

JSON 解析错误时，**保存按钮置灰**——避免坏 JSON 写回单元格。

## 类型保护

每个值的类型在树视图里显示：

- 字符串：紫色
- 数字：蓝色
- 布尔：橙色
- null：灰色
- 数组：绿色 `[N]` 元素数
- 对象：绿色 `{N}` 字段数

类型不会在双向同步时被意外转换（除非你手动改代码区）。

## 跟"多数据编辑"的关系

| 场景 | 用哪个 |
|------|--------|
| 单元格里就一个 JSON 对象 / 数组 | JSON 编辑器 |
| 单元格是结构化的对象数组（每个对象有相同 schema） | 多数据编辑（schema 驱动） |
| 不确定 / 临时探索 | JSON 编辑器（更灵活） |

两个工具不冲突——同一列可以挂任意一个 CT 类型。

## 注意事项

> [!TIP]
> 复制路径功能（树节点右键 → 复制路径）会得到 `rewards[0].count` 这样的 JSONPath，可以直接用在公式 `=json_get('rewards[0].count')` 里。

> [!WARNING]
> 单元格里塞超大 JSON（几 MB）时编辑器可能加载慢——这类数据更适合放外部 `.json` 文件，用外部引用源接进来。
