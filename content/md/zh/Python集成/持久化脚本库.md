# 持久化脚本库

每次打开新项目都要重写上次调好的那批脚本？写好的公式函数散在各个工程里找不着？脚本库专门解决这个：在脚本编辑器里写过的脚本 / 注册过的公式函数，**一次存入、跨项目永久复用**，不用再重写。

## 打开脚本库

主窗口菜单 → **工具 → 脚本库**

或在 Python 脚本编辑器顶部点 **脚本库** 按钮。

## 脚本库面板

打开后看到的是一个按分类分组的脚本列表：

![脚本库面板](Res/zh/images/脚本库面板.png)

- **分组**：按"功能分类"标签自动分组
- **作用域切换**：全局（所有项目都能用） / 当前项目专属
- **启用 / 禁用**：禁用后函数不可调用，但配置保留
- **搜索**：顶部搜索框过滤脚本名 / 标签 / 描述

## 脚本元数据

每个脚本除了代码本身，还有：

| 字段 | 必填 | 说明 |
|------|------|------|
| 名字 | ✅ | 公式调用名，唯一 |
| 分类标签 | ❌ | 用于分组（数值计算 / 字符串处理 / ...） |
| 描述 | ❌ | hover 提示 / 文档生成用 |
| 作者 | ❌ | 谁写的 |
| 版本 | ❌ | 用于团队同步 |
| 作用域 | ✅ | 全局 / 当前项目 |

## 跨项目同步

**全局**脚本存在 `~/.configNexus/scripts/global/`，所有项目共用。

**当前项目**脚本存在 `<项目>/scripts/local/`，跟项目走（建议纳入 Git 版本控制）。

## 跟创意工坊配合

脚本库里的脚本可以**打包成组件**上传到 Steam 创意工坊：

1. 选要打包的几个脚本
2. **打包为组件** → 输入组件元数据
3. 上传到工坊

别人订阅后这些脚本会自动出现在他的脚本库里。

## 脚本依赖

脚本之间可以互相调用：

```python
# 脚本 A：基础工具
def round_to(value, step):
    return round(value / step) * step

# 脚本 B：调用 A
from script_lib import round_to  # 通过特殊导入语法

def calc_price(base, level):
    raw = base * (1 + level * 0.1)
    return round_to(raw, 0.1)
```

> [!NOTE]
> `from script_lib import xxx` 是 ConfigNexus 特有的导入语法——能从脚本库里导入其他脚本。普通 Python `import` 不行。

## 文档生成

脚本库面板右上角 **生成文档** → 导出 Markdown 文件，列出所有脚本 + 描述 + 签名。适合：

- 团队 onboarding 文档
- 给程序员看"策划这边能用什么函数"

## 安全

脚本在沙箱里运行（详见教程[[Python脚本编辑器]]）。脚本库里同样的限制：

- 不能 `open()` 文件
- 不能 `subprocess`
- 不能动 `os.environ`

如果某个脚本需要破例（少见），在脚本元数据里申请"提权"，启动时会弹确认框。

## 注意事项

> [!WARNING]
> 删除脚本是**不可恢复**的——会同时删掉本地文件。重要脚本建议先用 Git 备份，或导出再删。

> [!TIP]
> 命名建议：用动词开头、小写下划线（`calc_exp` / `validate_id` / `gen_localized_key`）。这跟单元格公式调用时看起来最自然。
