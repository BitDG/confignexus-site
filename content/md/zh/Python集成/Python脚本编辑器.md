# Python脚本编辑器

## 解决什么问题

Python 脚本编辑器用于写一次性或可复用脚本，批量处理表格数据、生成内容或执行自定义检查。

## 什么时候用

- 内置工具不够用。
- 需要批量生成或修改数据。
- 项目已有 Python 处理逻辑想接进来。

## 怎么开启

1. 打开 Python 脚本编辑器。
2. 编写或选择脚本。
3. 运行前确认目标表和参数。

## 操作步骤

### 第 1 步：准备脚本

写清输入、输出和作用范围。不要一开始就改全表，先用小范围测试。

### 第 2 步：运行脚本

在编辑器里执行脚本，查看输出日志和错误信息。

### 第 3 步：检查结果

确认表格数据变化符合预期，再保存工程。

## 常见错误

> [!warning]
> 脚本会批量改数据，运行前建议保存工程或准备可回退副本。

> [!tip]
> 持续参与单元格计算的逻辑更适合 Python 公式，不适合手动脚本。
