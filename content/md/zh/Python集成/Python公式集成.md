# Python公式集成

## 解决什么问题

Python 公式集成让单元格像 Excel 公式一样调用 Python 函数，适合持续计算和依赖重算。

## 什么时候用

- 数值公式复杂，普通表格公式不够用。
- 依赖数据变动后希望自动重算。
- 想复用 Python 函数做配置计算。

## 怎么开启

1. 在 Python 编辑器中写函数。
2. 注册为公式。
3. 在单元格里用公式形式调用。

## 操作步骤

### 第 1 步：编写函数

函数应尽量是纯计算：输入参数，返回结果，不写文件、不访问网络。

### 第 2 步：注册为公式

把函数注册到公式系统，给它一个稳定名称。

### 第 3 步：在单元格调用

用类似 `=calc_exp(A2)` 的方式调用。依赖单元格变化后会触发重算。

## 常见错误

> [!warning]
> 不要在公式函数里做耗时 IO，例如联网、读写大文件或 sleep。它会拖慢整张表重算。

> [!tip]
> 一次性批处理更适合 Python 脚本编辑器，持续计算才适合公式。
