# Python 公式集成

★ 商店里"Python 函数深度集成"的核心能力——在单元格里像写 Excel 公式一样**调 Python 函数**。复杂数值规则一行搞定。

跟"Python 脚本编辑器"（手写脚本批处理）是两个不同功能：

| 维度 | Python 脚本编辑器 | Python 公式集成（本篇） |
|------|------------------|----------------------|
| 触发方式 | 手动点"运行" | 单元格写公式自动算 |
| 用途 | 一次性批处理 | 持续生效的计算逻辑 |
| 缓存 | 不缓存 | SmartCache 自动缓存 |
| 批量优化 | 不优化 | BatchExecutor 自动合并 |

> [!IMPORTANT]
> 此功能为 ConfigNexus 专业版功能，需在 Steam 购买后使用。

## 快速上手

1. 打开 Python 脚本编辑器，写一个函数：

   ```python
   def calc_exp(level):
       return level ** 2 * 100
   ```

2. 注册到公式系统（编辑器顶部按钮 **注册为公式**）

3. 在任意单元格写：

   ```
   =calc_exp(A2)
   ```

   A2 = 5 时这一格自动算出 2500。改 A2 → 这一格自动重算。

## 注册为公式

脚本编辑器顶部 **注册为公式** 按钮 → 选要注册的函数 → 给一个公式名（默认就是函数名）。

注册后函数永久存在公式系统里，跨项目可用（默认作用域），也可以指定为"当前项目专属"。

## SmartCache 智能缓存

同样的输入 → 同样的输出 → 不重复计算：

- 缓存 key：`函数名(参数序列化)`
- LRU 策略：最近用过的 1000 条结果缓存在内存
- TTL：默认 5 分钟，依赖数据变化时手动清

效果：一张表 10000 个单元格调同一个函数、大部分参数重复 → 实际只算几十次。

## BatchExecutor 批量执行

同一个函数被一批单元格调用时，系统自动合并请求：

- 检测到 10ms 内有 N 个相同函数调用 → 合并成一次 Python 进程调用
- Python 函数接到的是参数数组 → 返回结果数组 → 分发回各单元格

效果：单元格逐个调本来是 N 次 Python 进程往返 → 实际只 1 次往返。大表批量重算从分钟降到秒。

> [!TIP]
> 你写的 Python 函数**不用关心**批量优化。系统自动判断"这个函数可以批量化吗"——副作用纯函数自动开 batch、有 I/O 的函数自动单调用。

## 单元格里能写什么

- 基本调用：`=my_func(A1)`
- 嵌套：`=my_func(other_func(A1, B1))`
- 跟内置公式混用：`=SUM(my_func(A1:A10))`（注意：传 range 时函数要支持数组参数）
- 字符串字面量：`=lookup('item', 'id', A1)`

## 函数签名约定

注册成公式的函数必须：

1. **无副作用**（不写文件、不改全局状态）
2. **返回基础类型**（int / float / str / bool / list / dict）—— 不返回对象 / 类实例
3. **参数顺序固定**（公式调用按位置传参，不支持关键字参数）

不符合的函数注册时会被警告，运行时报错。

## 错误处理

公式里 Python 抛异常 → 单元格显示 `#ERR!`，鼠标悬停看异常详情：

```
#ERR! ZeroDivisionError: division by zero
  at calc_exp(level=0)
```

## 持久化脚本库

注册过的公式函数自动存到 **脚本库**：

- 主窗口菜单 → **Python 脚本库**
- 看所有已注册函数列表
- 启用 / 禁用 / 删除
- 跨项目复用（默认作用域的函数所有项目都能用）

详见教程《持久化脚本库》（待出）。

## 性能基准

| 场景 | 没缓存 / 不批量 | SmartCache + BatchExecutor |
|------|---------------|---------------------------|
| 5000 格调用，参数全相同 | 5000 次 Python 调用 | 1 次（缓存命中 4999 次） |
| 5000 格调用，参数全不同 | 5000 次 Python 调用 | 5 次（每批 1000） |
| 5000 格调用，80% 重复 | 5000 次 | ~1 次（重复的全部缓存） |

> [!WARNING]
> 函数里**不要**写 `time.sleep` / 网络 IO / 文件 IO——这会拖慢整张表的重算。这类操作放进"脚本编辑器"手动跑。
