# 自定义公式

将自定义公式注册到 Luckysheet 公式系统，支持 CRUD 管理与持久化存储。

## 功能总览

| 功能 | 说明 |
|------|------|
| 公式注册 | 将自定义公式注册到 Luckysheet，可在单元格中直接调用 |
| CRUD 管理 | 支持添加、编辑、删除自定义公式 |
| 持久化存储 | 公式定义保存在 localStorage，重启后自动加载 |
| 导入/导出 | 支持公式集的 JSON 文件导入导出，便于团队共享 |

## 公式定义示例

```javascript
// 自定义公式：计算带税价格
{
  name: "TAXPRICE",
  formula: function(price, taxRate) {
    return price * (1 + taxRate);
  },
  description: "计算含税价格 = 价格 × (1 + 税率)"
}
```

在单元格中使用：`=TAXPRICE(B2, 0.13)` → 输出含税价格

## 使用方法

### 步骤 1：打开公式管理器

通过菜单栏打开自定义公式管理面板。

### 步骤 2：添加公式

点击「添加公式」，输入公式名称、实现代码和描述信息。

### 步骤 3：测试公式

在预览区域输入测试参数，验证公式输出是否正确。

### 步骤 4：使用公式

注册成功后，在任意单元格中输入 `=公式名(参数)` 即可调用。

## 导入/导出

团队间共享自定义公式集：

```
导出：公式管理器 → 导出 → 保存为 JSON 文件
导入：公式管理器 → 导入 → 选择 JSON 文件 → 合并或覆盖
```

## 注意事项

> [!NOTE]
> - 公式名称不能与 Luckysheet 内置公式冲突
> - 公式保存在浏览器 localStorage 中，清除浏览器数据会丢失
> - 建议定期导出公式集作为备份
