# 智能粘贴

从文档、ChatGPT 或 API 工具复制了一张 Markdown 表格或一段 JSON 数组，Ctrl+V 粘进单元格——结果全塌成一团字符串。智能粘贴就是为了解决这个：**软件检测到剪贴板里是结构化数据时，自动弹出确认框，一键转换成规整的表格行列**，普通文本完全不受影响。

> [!tip]
> 智能粘贴只拦截两种格式：**Markdown 表格** 和 **JSON 数组**。其它文本（CSV、纯文字、代码片段）走原生粘贴，不会弹框打扰你。

## 它是干什么的

把"剪贴板里的结构化文本 → 表格数据"这个转换步骤从手工变成一次点击。两种常见场景：

- **Markdown 表格**：从技术文档、Notion、GitHub wiki 复制的 `|列名|` 格式表格
- **JSON 数组**：从接口文档、ChatGPT 输出或 API 返回值复制的 `[{...},{...}]` 格式数据

## 三步上手

### 第 1 步：复制结构化数据

在外部工具里复制目标内容。

Markdown 表格示例：

```markdown
| ID | 名称 | 价格 |
|----|------|------|
| 1  | 铁剑 | 100  |
| 2  | 木盾 | 50   |
```

JSON 数组示例：

```json
[
  {"id": 1, "name": "铁剑", "price": 100},
  {"id": 2, "name": "木盾", "price": 50}
]
```

### 第 2 步：在表格里按 Ctrl+V

光标停在你想写入的起始单元格，按 **Ctrl+V**。

软件检测到结构化数据后，会**自动弹出确认框**，显示即将写入的数据预览。

> [!note]
> 如果没有弹确认框，说明剪贴板内容不符合识别条件（两种格式之一），软件走普通粘贴，不影响正常使用。

### 第 3 步：预览并确认

确认框里会显示转换结果：
- **Markdown 表格** → 行列直接对应，表头行单独映射
- **JSON 数组** → key 自动成为列头，每个对象展开为一行

没问题就点**「转换并粘贴」**写入；不想转换就点**「取消」**，走普通粘贴。

## 注意事项

> [!warning]
> - 写入从当前光标位置开始，**会覆盖右下方已有数据**，操作前确认目标区域为空。
> - JSON 数组展开时，key 顺序以第一个对象为准；后续对象有额外 key 会补在末尾列。
> - 嵌套对象（`"stats": {"atk": 10}`）不会递归展开，会以 JSON 字符串形式写入单元格。
