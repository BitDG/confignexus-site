# 智能粘贴

自动检测剪贴板中的结构化数据（Markdown 表格、JSON 数组等），转换为 Luckysheet 表格格式后粘贴。

createtab:Res/zh/templates/智能粘贴演示.cnx

## 功能总览

| 功能 | 说明 |
|------|------|
| Markdown 表格检测 | 自动识别剪贴板中的 Markdown 表格并转换为单元格数据 |
| JSON 数组检测 | 识别 JSON 数组格式，按字段展开为表格行列 |
| 确认对话框 | 粘贴前弹出预览，确认转换结果后再写入 |
| 多语言支持 | 界面和提示信息支持中/英/日/韩四种语言 |

## 支持的数据格式

### Markdown 表格

```markdown
| ID | 名称 | 价格 |
|----|------|------|
| 1  | 铁剑 | 100  |
| 2  | 木盾 | 50   |
```

粘贴后自动识别为 2 行 3 列的表格数据，写入对应单元格。

### JSON 数组

```json
[
  {"id": 1, "name": "铁剑", "price": 100},
  {"id": 2, "name": "木盾", "price": 50}
]
```

粘贴后自动将 key 作为列头，每个对象展开为一行数据。

## 使用方法

### 步骤 1：复制结构化数据

从网页、文档或编辑器中复制 Markdown 表格或 JSON 数组。

### 步骤 2：粘贴到表格

在目标单元格位置使用 Ctrl+V 粘贴。系统检测到结构化数据后会弹出确认对话框。

### 步骤 3：预览并确认

在对话框中查看转换后的数据预览，确认无误后点击「确定」写入表格。

## 注意事项

> [!NOTE]
> - 仅当剪贴板内容匹配 Markdown 表格或 JSON 数组格式时才会触发智能粘贴
> - 普通文本粘贴不受影响，仍按默认方式处理
> - 如不需要转换，可在确认对话框中选择「取消」使用原始粘贴
