# ID生成器

## 解决什么问题

ID 生成器用于给新增配置自动分配不重复 ID，减少手工编号冲突。

## 什么时候用

- 表里有唯一 ID 列。
- 新增大量配置行。
- 多人协作时容易撞 ID。

## 怎么开启

1. 打开 ID 生成器。
2. 选择目标 ID 列。
3. 设置起始值、步长或规则。

## 操作步骤

### 第 1 步：选择 ID 列

指定哪一列是唯一 ID。

### 第 2 步：设置生成规则

配置起始值、递增步长、前缀或分段策略。

### 第 3 步：生成并检查

生成后运行唯一性验证，确认没有重复。

## 常见错误

> [!warning]
> 不同表共用 ID 空间时，不能只看当前表是否重复。需要和团队约定分段规则。

> [!tip]
> ID 列建议同时配置唯一验证规则。
