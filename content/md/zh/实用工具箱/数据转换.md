# 数据转换

根据映射表格配置，自动计算和转换复杂的多数据单元格内容，适用于奖励价值计算等场景。

## 功能总览

| 功能 | 说明 |
|------|------|
| 分隔符解析 | 自动检测并按分隔符解析原始数据为分组 |
| 映射表关联 | 从其他 Sheet 读取映射关系进行数据转换 |
| 期望价值计算 | 按权重/概率计算数据的期望值 |
| 自动分隔符检测 | 智能识别逗号、分号、竖线等分隔符 |

## 工作原理

数据转换适配 CT 多数据编辑器的数据格式，根据映射表格的配置进行计算和转换。

### 数据结构示例

以奖励数组为例：`[{1001,30,0.75},{1002,50,0.85}]`

数据结构：`{奖励ID, 奖励数量, 获得概率}`

### 计算流程

1. **解析数据**：按分隔符将单元格内容拆分为多组数据
2. **映射查找**：在映射表格 `item` 中查找奖励 ID 对应的金币价格
3. **加权计算**：将金币价格与奖励数量、获得概率相乘
4. **汇总结果**：将所有分组的计算结果求和

### 计算公式

```
总价值 = Σ (金币价格 × 奖励数量 × 获得概率)

示例：
  物品 1001 价格=10, 数量=30, 概率=0.75 → 10×30×0.75 = 225
  物品 1002 价格=20, 数量=50, 概率=0.85 → 20×50×0.85 = 850
  总价值 = 225 + 850 = 1075
```

## 使用方法

### 步骤 1：准备映射表

确保工作簿中有对应的映射 Sheet（如 `item` 表），包含 ID 和对应的数值列。

### 步骤 2：选择数据列

选中包含多数据格式的单元格或列。

### 步骤 3：配置转换规则

指定映射表名称、关联字段和计算方式。系统会自动检测数据的分隔符格式。

### 步骤 4：执行转换

运行转换后，结果将写入目标列或显示在预览面板中。
