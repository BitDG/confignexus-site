# 多数据批量修改

## 功能概述

多数据编辑器支持强大的批量修改功能，可以对选中的多个单元格同时进行计算或格式化操作。

## 快速开始

### 1. 选择单元格

- **单选**: 点击单元格
- **范围选择**: 按住 Shift 键点击
- **多选**: 按住 Ctrl/Cmd 键点击
- **拖拽选择**: 按住鼠标左键拖拽

### 2. 打开批量修改

- 右键点击选中区域
- 在菜单中选择"批量修改"

### 3. 选择操作类型

#### 计算模式
对数值进行数学运算

#### 前后缀模式
为文本添加前缀或后缀

## 计算模式

### 支持的运算

| 运算符 | 说明 | 示例 | 结果 |
|--------|------|------|------|
| `+` | 加法 | `+10` | 原值 + 10 |
| `-` | 减法 | `-5` | 原值 - 5 |
| `*` | 乘法 | `*1.5` | 原值 × 1.5 |
| `/` | 除法 | `/2` | 原值 ÷ 2 |
| `%` | 取模 | `%10` | 原值 % 10 |

### 多步骤运算

可以添加多个运算步骤，按顺序执行：

**示例**: 将经验值乘以 1.5，然后加 100
1. 步骤1: `*1.5`
2. 点击"添加步骤"
3. 步骤2: `+100`

**计算过程**: 
- 原值: `200`
- 步骤1: `200 * 1.5 = 300`
- 步骤2: `300 + 100 = 400`
- 结果: `400`

### 取整功能

在所有运算完成后，可以向下取整到指定倍数：

| 取整因数 | 说明 | 示例 |
|----------|------|------|
| `1` | 取整到整数 | `23.7 → 23` |
| `0.1` | 保留一位小数 | `23.75 → 23.7` |
| `10` | 取整到 10 的倍数 | `23 → 20` |
| `100` | 取整到 100 的倍数 | `237 → 200` |

**示例**: 
```
原值: 23.75
运算: *2 +10
结果: 57.5
启用取整，因数: 10
最终结果: 50
```

## 前后缀模式

为单元格的值添加前缀或后缀文本。

### 使用场景

#### 添加命名空间
```
前缀: player.
原值: health → 结果: player.health
原值: mana → 结果: player.mana
```

#### 添加版本标识
```
后缀: _v1
原值: config → 结果: config_v1
原值: data → 结果: data_v1
```

#### 同时添加前后缀
```
前缀: item_
后缀: _rare
原值: sword → 结果: item_sword_rare
```

## 实用示例

### 示例1: 游戏数值平衡

**需求**: 所有武器攻击力增加 20%

**操作**:
1. 选中攻击力列
2. 右键 → 批量修改
3. 计算模式 → 输入 `*1.2`
4. 点击确定

### 示例2: 物品 ID 格式化

**需求**: 为物品 ID 添加前缀 `item_`

**操作**:
1. 选中 ID 列
2. 右键 → 批量修改
3. 前后缀模式 → 前缀: `item_`
4. 点击确定

### 示例3: 复杂经验值调整

**需求**: 经验值乘以 1.5，加 100，取整到 50 的倍数

**操作**:
1. 选中经验值列
2. 右键 → 批量修改
3. 计算模式
4. 步骤1: `*1.5`
5. 添加步骤
6. 步骤2: `+100`
7. 勾选"启用取整"
8. 取整因数: `50`
9. 点击确定

**计算示例**:
```
原值: 200
步骤1: 200 * 1.5 = 300
步骤2: 300 + 100 = 400
取整: FLOOR(400 / 50) * 50 = 400
结果: 400
```

### 示例4: 配置键重命名

**需求**: 为配置键添加模块前缀和环境后缀

**操作**:
1. 选中配置键列
2. 右键 → 批量修改
3. 前后缀模式
4. 前缀: `game.config.`
5. 后缀: `.prod`
6. 点击确定

**结果**:
```
health → game.config.health.prod
mana → game.config.mana.prod
speed → game.config.speed.prod
```

## 注意事项

### 计算模式
- ✅ 只对数值类型的单元格生效
- ✅ 非数值单元格会被自动跳过
- ✅ 除数为 0 时会自动跳过该运算
- ⚠️ 表达式必须以运算符开头: `+10` ✓, `10+` ✗

### 前后缀模式
- ✅ 适用于所有类型的单元格
- ✅ 会将数值转换为文本
- ⚠️ 应用后无法直接用于数值计算

### 实时预览
- 预览显示第一个选中单元格的结果
- 所有选中单元格会应用相同的操作
- 建议先预览确认无误后再应用

## 常见问题

### Q: 为什么有些单元格没有被修改？
A: 计算模式只对数值类型有效。如果单元格包含文本，会被自动跳过。

### Q: 如何撤销批量修改？
A: 目前不支持撤销功能，建议在修改前先保存或备份数据。

### Q: 可以对多个不连续的区域同时操作吗？
A: 可以。按住 Ctrl/Cmd 键选择多个区域，批量修改会应用到所有选中的单元格。

### Q: 取整功能什么时候执行？
A: 取整在所有运算步骤完成后执行，确保最终结果符合要求。

### Q: 前后缀模式会影响数值计算吗？
A: 会。应用前后缀后，单元格会变成文本类型，无法直接用于数值计算。

## 最佳实践

1. **先预览再应用**: 使用预览功能确认结果正确
2. **分步操作**: 复杂修改可以分多次完成
3. **备份数据**: 重要数据修改前先保存
4. **测试小范围**: 先在少量数据上测试，确认无误后再应用到全部
5. **合理使用取整**: 根据实际需求选择合适的取整因数
