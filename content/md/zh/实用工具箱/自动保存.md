# 自动保存

在用户空闲时自动保存当前文件，防止意外丢失未保存的修改。

## 功能总览

| 功能 | 说明 |
|------|------|
| 空闲检测 | 2 分钟无操作后自动触发保存 |
| 最小保存间隔 | 两次自动保存之间至少间隔 1 分钟，避免频繁写入 |
| 原格式写回 | 按文件原始格式保存（xlsx、xls、cnx 等），不改变文件类型 |
| 失败通知 | 保存失败时弹出提示通知，提醒用户手动保存 |

## 工作原理

### 触发机制

```
用户操作表格 → 标记为"有修改"
  → 用户停止操作 → 开始计时
    → 2 分钟无操作 → 检查最小间隔
      → 满足间隔条件 → 执行自动保存
      → 不满足间隔 → 等待下次触发
```

### 空闲检测

系统监听以下用户操作事件来重置空闲计时器：
- 键盘输入
- 鼠标点击/移动
- 单元格编辑
- 滚动操作

### 保存流程

1. 检测到空闲超时且文件有未保存修改
2. 按文件原始格式执行保存
3. 保存成功后清除"有修改"标记
4. 保存失败时通过 Toast 通知用户

## 注意事项

> [!NOTE]
> - 自动保存不会改变文件的保存路径和格式
> - 新建的未命名文件不会触发自动保存（需先手动保存一次）
> - 自动保存过程中界面不会被阻塞，可继续编辑
> - 如果文件正在被其他程序占用，保存可能失败并给出提示
