# 数据拼接

将多列数据按自定义格式拼接为一列，适用于生成多语言键名、资源路径等场景。

createtab:Res/zh/templates/数据拼接演示.cnx

## 功能总览

| 功能 | 说明 |
|------|------|
| 多列拼接 | 选择多个源列，拼接结果写入目标列 |
| 自定义分隔符 | 支持任意字符串作为拼接分隔符 |
| 格式模板 | 使用 `{A}_{B}_{C}` 格式灵活控制拼接方式 |
| 结果预览 | 拼接前可实时预览输出结果 |

## 格式模板示例

| 模板 | 源数据 | 输出结果 |
|------|--------|----------|
| `{A}_{B}` | A=txt, B=item | txt_item |
| `{A}_{B}_{C}` | A=txt, B=item, C=1001 | txt_item_1001 |
| `res/{A}/icon/{B}.png` | A=item, B=sword | res/item/icon/sword.png |
| `{A}-{B}` | A=config, B=001 | config-001 |

## 使用方法

### 步骤 1：选择源列

选中需要参与拼接的多个列。每列会被分配一个占位符（A、B、C...）。

### 步骤 2：设置格式模板

输入拼接格式模板，使用 `{A}`、`{B}`、`{C}` 引用对应列的数据。也可以直接指定分隔符进行简单拼接。

### 步骤 3：预览结果

实时查看拼接后的数据预览，确认格式正确。

### 步骤 4：执行拼接

确认后将拼接结果写入目标列。

## 应用场景

- **多语言键名生成**：`txt_item_1001`、`txt_skill_2001`
- **资源路径拼接**：`res/icon/item_1001.png`
- **唯一标识生成**：`module_type_id` 格式的复合键
- **配置引用**：`Sheet_Column` 格式的跨表引用标识
