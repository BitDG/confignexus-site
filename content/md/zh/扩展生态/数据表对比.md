# 数据表对比

两个 xlsx / cnx 文件、或同一个文件的两个版本之间，**逐单元格对比**——哪一格改了、改成啥、谁加了行、谁删了列，一目了然。是商店描述里的"表差异引擎"。

> [!IMPORTANT]
> 数据表对比是**独立 DLC 工具**，需要在 Steam 上单独获取。装了 DLC 才会出现下面说的入口。

## 功能总览

| 功能 | 说明 |
|------|------|
| 字符级 diff | 单元格内的文字按字符高亮变化（不是整格 highlight） |
| Token 级 diff | 数字 / JSON / 数组按 token 切分，避免误判 |
| 三步流程 | 选文件夹 → 看差异文件列表 → 看具体单元格 diff |
| 模块 A：弹窗 | 单文件对比，弹窗形式 |
| 模块 B：独立窗口 | 跨文件夹对比，独立窗口 |
| Git / SVN 集成 | 直接对比"工作区版本 vs HEAD 版本" |

## 三种打开方式

### 方式一：菜单 → 数据表对比

主窗口菜单栏 **📊 数据表对比** → 打开独立窗口（模块 B），走完整三步流程：

1. **Step 1 选两个文件夹**：左侧"当前版本"、右侧"参考版本"
2. **Step 2 差异文件清单**：列出两个文件夹下文件的增/删/改情况，点行展开
3. **Step 3 单元格 diff 网格**：sticky 三行表头 + 上下分层，逐格看变化

### 方式二：Git / SVN 源代码面板

源代码面板里点改动列表的 `.xlsx` / `.cnx` 文件：

- 装了数据表对比 DLC → 弹"按表格 diff 还是文本 diff"
- 选表格 diff → 工作区版本 vs HEAD 版本，单元格级 highlight
- 选文本 diff → 普通 unified diff

### 方式三：分支 ↔ 工作区对比

在 Git 面板的"历史"视图里，右键某个 commit → **跟工作区按表格 diff** → 自动把 commit 的版本导出到临时文件，跟工作区版本对比。

## diff 配色

| 颜色 | 含义 |
|------|------|
| 绿色背景 | 新增（参考版本里没有，当前版本里有） |
| 红色背景 | 删除（参考版本里有，当前版本里没有） |
| 黄色背景 | 修改 |
| 字符级红 / 绿 | 同一单元格内被替换的子串 |

## 字符级 diff 是什么

举个例子：

| 参考版本 | 当前版本 | 高亮效果 |
|---|---|---|
| `攻击力 100` | `攻击力 120` | "100" 红、"120" 绿，"攻击力 " 不变 |
| `[1,2,3]` | `[1,2,4]` | "3" 红、"4" 绿，其他不变 |
| `奖励：金币` | `奖励：钻石` | "金币" 红、"钻石" 绿 |

实现走 LCS（最长公共子序列）+ token 切分。算法在 `cell-diff-render.js`，vitest 覆盖。

## 三步流程的页面

### Step 1 选文件夹

左右各选一个文件夹（"当前 / 参考"语义自定，对调结果就反一下）。可以勾"递归扫描子目录"。

### Step 2 差异文件清单

列出所有差异文件：

- 增（绿色 +）：参考版没有、当前有
- 删（红色 -）：参考版有、当前没
- 改（黄色 ~）：两边都有但内容不同
- 同名同 hash 的文件不显示

点行展开 / 收起，点文件名进 Step 3。

### Step 3 单元格 diff 网格

- 三行 sticky 表头（sheet 名 / 列名 / 表头）
- 行高度按内容自适应
- 上下分层显示"参考 / 当前"
- 同一行同一列的两边内容并排

## 性能

字符级 diff 只在**单元格被点开时**才算（懒计算）。整张表 5000+ 行也不卡。

## 注意事项

> [!NOTE]
> 数据表对比 DLC 是付费 DLC，未购买时菜单和 Git / SVN 里的"按表格 diff"入口都不会出现，对应 IPC 也不响应——但**普通文本 diff** 不受影响（Git / SVN 自带的功能）。

> [!TIP]
> 跟"引用关系图"是不同的功能：引用图看"谁引用谁"，数据表对比看"哪一格改了什么"。
