# Steam 创意工坊

每次开新项目都要从零搭模板——道具表、对话表、任务表一格格重建；Python 脚本也是，上个项目写好了个好用的导出脚本，换项目又要重写一遍。创意工坊就是把这些可复用的"模板 / 脚本 / 预设"打包分享：在 ConfigNexus 内置商店里一键订阅社区里的成熟组件，或者把自己做的上传给别人用。

> [!IMPORTANT]
> 创意工坊**仅 Steam 正版渠道**可用。非 Steam 渠道（破解版 / 绿色版 / 网盘版）会看到入口置灰 + 顶部提示"仅 Steam 版可用"。

## 功能总览

| 功能 | 说明 |
|------|------|
| 浏览社区组件 | 在 ConfigNexus 内置的组件商店里搜 / 排序 / 预览 |
| 一键订阅 | 订阅后 Steam 自动下载并安装到本地 |
| 自动更新 | 创意工坊更新组件时，订阅者下次启动会被通知 |
| 上传组件 | 自己做的组件可以打包上传，附带预览图、版本号、依赖描述 |
| 协议签署 | 上传前需要签署 Steam 创意工坊法律协议（一次性） |

## 打开组件商店

主窗口菜单栏 **工具 → 组件商店**，或欢迎页 / 设置页里的入口。

![创意工坊-组件商店](Res/zh/images/创意工坊-组件商店.png)

商店有两个标签页：

- **已安装**：本地组件 + 已订阅的创意工坊组件
- **商店**：当前 Steam 上能搜到的所有公开组件（默认按热度排序）

## 订阅组件

商店标签页里：

1. 搜索 / 浏览到你想要的组件
2. 点 **订阅**
3. Steam 在后台下载（不阻塞主界面）
4. 下载完成后自动出现在"已安装"标签里，状态变绿

## 取消订阅

"已安装" 标签下找到该组件 → **取消订阅** → 选择是否同时删除本地文件。

> [!NOTE]
> 取消订阅默认**会**删除本地副本。如果你想保留一份本地拷贝，先在 ConfigNexus 之外手动备份一下组件目录。

## 上传组件

### 前置条件

1. **Steam 客户端运行中**且**登录的账号拥有 ConfigNexus**
2. **首次上传**：需要签署 Steam 创意工坊法律协议（弹窗里勾确认）
3. **专业版功能**（免费版可下载订阅，但不能上传）

### 上传流程

1. **工具 → 组件商店 → 已安装** 标签，选要上传的本地组件
2. 点 **上传到工坊**
3. 填上传元数据：标题 / 简介 / 标签 / 可见性（公开 / 仅好友 / 私有）/ 预览图
4. 校验：系统会校验组件结构 + 校验元数据合法性
5. 打包：把组件目录打成 zip 上传
6. 协议签署：首次会弹出协议（在 Steam 客户端里接受）
7. 等待上传完成

### 后续更新

后续上传同一个组件（保持目录里的 `metadata.json` 不变），系统会自动识别为"更新"而非"新建"，不需要重新签协议。

## 作者身份校验

- 一个组件只能由它的原作者更新
- 上传时系统会比较 `metadata.authorSteamId` 与当前登录的 Steam ID
- 不匹配时会拒绝上传并提示 "只能上传自己创建的组件"

> [!TIP]
> 首次上传时，系统会自动把 `metadata.authorSteamId` 设为当前用户。所以**第一次上传必须是作者本人**操作，否则后续就改不动了。

## 错误对照

| 错误码 | 含义 | 解决 |
|--------|------|------|
| E_STEAM_UNINITIALIZED | Steam 未运行或未登录 | 启动 Steam 客户端并登录 |
| E_STEAM_AGREEMENT_REQUIRED | 需先签创意工坊协议 | 在 Steam 客户端里接受协议 |
| E_AUTHOR_MISMATCH | 当前账号不是原作者 | 用原作者账号上传 |
| E_COMPONENT_INVALID | 组件结构不合规 | 检查 `metadata.json` 是否齐全、预览图是否存在 |
| E_UPLOAD_FAILED | 网络 / Steam 服务器问题 | 稍后重试 |

## 注意事项

> [!WARNING]
> 上传到工坊的组件**任何人都能看到**（除非选了"仅好友"或"私有"）。不要把含商业秘密 / 客户数据的配置上传到公开工坊。

> [!IMPORTANT]
> 违反 Steam 创意工坊法律协议（盗用他人作品、违法内容等）可能导致 Steam 账号被封禁。上传前请确认你拥有该内容的合法权利。
