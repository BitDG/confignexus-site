# 外部引用源

把项目之外的文件 / 文件夹注册成"引用源"，让公式 / 校验 / 自动补全可以跨项目查表——比如把另一个项目的 `talent.xlsx` 添加进来，本项目的 `id` 列就能下拉选到对面的 ID。

是老 mapping 子系统的升级版（mapping 已统一迁移到外部引用源）。

## 功能总览

| 功能 | 说明 |
|------|------|
| 多源支持 | 同时挂多个文件 / 文件夹做引用源 |
| 别名机制 | 每个源给一个易记的显示名，下拉菜单里看得清 |
| 冲突解决 | 多个源里有同名表 / 列时，可以在设置里指定哪个优先 |
| 递归扫描 | 文件夹源可以选"只扫一层"或"扫所有子目录" |
| 增量刷新 | 单个源可以单独刷新，不用重新加载全部 |

## 添加引用源

### 方式一：文件浏览器右键

文件浏览器右键任意文件或文件夹 → **🔗 添加为外部引用源** → 输入显示名 → 文件夹会询问递归方式。

### 方式二：设置页

主窗口 **设置 → 外部引用源** → 点 **+ 添加** → 选择文件或文件夹。

## 别名 vs 显示名

| 概念 | 是什么 | 怎么用 |
|------|--------|--------|
| 显示名 | 你给这个引用源起的标签 | 下拉菜单里区分不同来源 |
| 别名 | 源里每个被发现的引用键 | 公式 / CT 列里直接调用 |

例：把 `项目B/talent.xlsx` 加进来，显示名叫"项目B 天赋"。系统扫描后注册出别名 `talent` —— 本项目里 `=lookup('talent', 'id', 1001)` 就能查到对面的数据。

## 冲突解决

如果两个源都注册了别名 `talent`：

1. 设置页 → 外部引用源 → 看到带 ⚠ 角标的源
2. 点开"冲突列表"
3. 对每个冲突的别名选一个优先源（或重命名其中一个）

冲突未解决前，调用该别名会用**最近添加**的源（带警告日志）。

## 刷新机制

- 单个源刷新：设置页里点该源的 🔄
- 全部刷新：设置页顶部 **🔄 刷新全部**
- 源文件修改后**不会自动**重新扫描——需要手动刷新

> [!TIP]
> 引用源的扫描结果是缓存在项目本地的，跨会话保留。第一次添加大文件夹（几百个 xlsx）可能要等几秒。

## 删除 / 禁用

- **禁用**：暂时不让这个源参与查表，但保留配置（设置页里点开关）
- **删除**：彻底移除（删除后已经引用过这个源的公式会查不到值）

## 与公式集成

在单元格写：

```
=lookup('<别名>', '<列名>', <主键值>)
```

`<别名>` 必须是已注册的引用源别名；如果别名冲突未解决，函数会按"最近添加"原则解析并打 warning。

## 注意事项

> [!WARNING]
> 外部引用源**只读**——通过它查到的数据不能在本项目里直接修改。要改对面的值，得打开对面那个文件。

> [!NOTE]
> 老项目的 mapping 配置在升级时**自动迁移**到外部引用源，不用手动重做。如果发现迁移结果不对，可以从设置页 → 外部引用源 → 高级 → "重新从旧 mapping 导入"。
