# 源代码管理

## 解决什么问题

源代码管理用于把配置工程纳入 Git 或 SVN 流程，追踪修改、提交版本和协作合并。

## 什么时候用

- 多人协作配置。
- 需要回退历史版本。
- 配置文件要随项目一起提交。

## 怎么开启

1. 打开源代码管理面板。
2. 选择仓库目录。
3. 查看变更并提交。

## 操作步骤

### 第 1 步：关联仓库

选择当前项目所在的 Git 或 SVN 工作目录。

### 第 2 步：查看变更

检查 .cnx、导出文件和资源配置是否发生变化。

### 第 3 步：提交版本

写清提交说明，和团队约定哪些文件需要提交。

## 常见错误

> [!warning]
> 自动保存不等于版本管理。错误保存后，仍要依靠 Git/SVN 回退。

> [!tip]
> 导出文件是否入库要和程序团队约定，避免重复生成文件造成冲突。
