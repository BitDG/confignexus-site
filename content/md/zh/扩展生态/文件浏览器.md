# 文件浏览器

独立窗口形式的文件树，停在主窗口左侧，专门用来管理整个项目目录下的配置文件——新建 / 重命名 / 删除 / 拖到主窗口打开，集成 Git / SVN 角标、引用关系图、外部引用源等扩展能力。

## 功能总览

| 功能 | 说明 |
|------|------|
| 文件树 | 按文件夹层级展开，文件夹懒加载（点开才扫描），万级文件不卡 |
| 多位置切换 | 顶部下拉切"工作位置"（多个项目根目录） |
| 搜索框 | 输入关键词实时过滤树中文件名 |
| 右键菜单 | 新建文件 / 文件夹、重命名、删除、在文件管理器中显示、添加为外部引用源 |
| 双击主窗口打开 | 双击支持的文件（xlsx / json / cnx 等）在主窗口打开 |
| 角标系统 | 文件名旁边显示 Git/SVN 状态（M/A/D/U/C），由 git-mod、svn-mod 插件提供 |
| 引用关系图入口 | 文件行内 🔍 单文件视图、左下角 🔗 当前文件夹整体视图 |
| 扩展槽 | 左侧竖排图标栏（Git / SVN / 设置 / 引用图）由插件动态注册 |

## 打开文件浏览器

主窗口菜单栏 **文件 → 文件浏览器**，或快捷键打开。窗口默认贴在主窗口左侧、宽度为主窗口的 31.25%、与主窗口同高，会跟随主窗口移动。

> [!TIP]
> 文件浏览器是**独立窗口**，跟主窗口是两个进程间通信，关闭它不影响主窗口里已打开的表格；再次打开它，会保持上次浏览的位置。

## 工作位置切换

顶部下拉框列出在 **设置 → 文件浏览器位置** 里配置的所有工作位置（每个位置 = 一个项目根目录）。切换后整棵树重新加载。

未配置任何位置时，文件浏览器会拿"上一次主窗口打开的项目目录"作为根。

## 文件树操作

| 操作 | 说明 |
|------|------|
| 单击文件 | 高亮选中（不打开） |
| 双击文件 | 在主窗口打开（仅支持的格式：xlsx / xlsm / xls / json / csv / cnx） |
| 单击文件夹 | 展开 / 折叠 |
| 单击文件名旁 🔍 | 打开该文件的引用关系图（仅支持的格式） |
| 右键任意节点 | 弹出菜单：新建 / 重命名 / 删除 / 在文件管理器中显示 / 添加为外部引用源 |

> [!NOTE]
> 删除操作走的是**系统回收站**，可恢复。重命名 / 移动时如果文件已经被主窗口打开，会先提示"该文件正在编辑中"。

## 搜索

顶部搜索框输入关键词，**实时过滤**当前树中可见的文件名（含路径片段匹配）。按 ESC 或点右侧 ✕ 清空。

搜索只过滤已展开的部分；如果你想搜整棵树，先把文件夹全展开。

## 角标（Git / SVN 状态）

如果当前位置在 Git 仓库或 SVN 工作副本内，文件名右侧会出现单字母角标：

| 角标 | 颜色 | 含义 |
|------|------|------|
| M | 黄 | 已修改 |
| A | 绿 | 新增 |
| D | 红 | 已删除 |
| U / ? | 灰 | 未跟踪 |
| C | 红 | 冲突 |

角标每 30 秒刷新一次；做完 commit / 撤销 / 暂存等动作角标会立即更新。

> [!TIP]
> 角标功能由 **git-mod** / **svn-mod** 插件提供，需要系统 PATH 上有 `git` / `svn.exe`。没装会自动隐藏，不影响其他功能。

## 引用关系图入口

- **文件行内 🔍**：打开"这个文件被谁引用 / 这个文件引用了谁"的单文件视图
- **左下角 🔗**：以当前根目录为范围，展示整张关联引用图

两个入口都把页签开在主窗口里，单实例复用（再次点击切到已有页签，不会开多个）。

## 添加为外部引用源

右键任意文件或文件夹，选 **🔗 添加为外部引用源**：

- 输入显示名称（用于下拉菜单区分来源）
- 文件夹会询问"是否递归扫描"（"是"=扫所有子目录、"否"=只扫第一层）
- 添加成功后会显示别名数量；如果有别名冲突，去 **设置 → 外部引用源** 解决

详见教程《外部引用源》。

## 扩展槽：左侧竖排图标栏

左侧 44px 宽的竖排图标条由插件动态注册：

| 图标 | 来源 | 作用 |
|------|------|------|
| 🌿 | git-mod | 打开 Git 源代码面板（commit / pull / push / stash / branch） |
| 🌐 | svn-mod | 打开 SVN 源代码面板（commit / update / log） |
| 🔗 | 内置 | 当前文件夹关联引用关系图 |
| ⚙️ | 内置 | 文件浏览器设置 |

图标顺序、可见性由 `plugins/<plugin>/manifest.json` 的 `contributesSettings.sidebar.order` 控制。

## 注意事项

> [!WARNING]
> 文件浏览器的"刷新"按钮会**重新扫描根目录**——文件多时会有 1-2 秒等待。日常用不需要手动刷新，文件变动会被 watcher 监听并自动反映。

> [!NOTE]
> 文件浏览器**不会占用主窗口的内存**。它有独立的渲染进程，跟主窗口通过 IPC 通信。
