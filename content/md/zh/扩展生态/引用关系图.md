# 关联引用关系图

改了一个表的 ID 列，不知道项目里哪几张表引用了它——逐个打开手查要花几十分钟，还容易漏。引用关系图把项目里所有表之间的依赖关系画成一张图：点进来一眼看清"这张表被谁引用、它又依赖哪些表"，改动之前先排查影响范围，心里有数再动手。

可视化展示当前项目里"哪个表被谁引用 / 它引用了谁"的图谱——用于排查"改了 ID 后哪些表会受影响"、"这个奖励配置被几张表用到"。

![引用关系图：项目里各表的依赖关系画成节点图，连线表示引用](Res/zh/images/引用关系图-整图.png)

## 功能总览

| 功能 | 说明 |
|------|------|
| 单文件视图 | 以一个文件为中心，展示直接 / 间接引用关系 |
| 整目录视图 | 以当前根目录为范围，展示整张关联图 |
| 节点跳转 | 点节点直接在主窗口打开对应表 |
| 单实例页签 | 切换不同文件夹时复用同一个页签，不会爆出一堆引用图 |

## 打开方式

### 方式一：文件行内 🔍（单文件视图）

文件浏览器里，把鼠标移到任意支持的文件（xlsx / json / cnx）上，右侧出现 🔍 图标。点击 → 打开"这个文件的引用关系图"页签。

### 方式二：左下角 🔗（整目录视图）

文件浏览器左下角的 🔗 图标 → 以当前位置（rootPath）为根，列出该文件夹下所有文件之间的引用关系。

## 图怎么读

- **箭头方向**：A → B 表示 A 引用了 B
- **节点颜色**：
  - 蓝色：当前焦点文件
  - 绿色：被焦点文件引用
  - 橙色：引用了焦点文件
- **节点大小**：被引用次数越多，节点越大

## 节点操作

| 操作 | 效果 |
|------|------|
| 单击节点 | 在主窗口的页签里打开该文件 |
| 双击节点 | 把图的焦点切到这个节点（重新以它为中心） |
| 拖动节点 | 调整布局，方便看清结构 |
| 滚轮缩放 | 缩放整张图 |
| 空白处拖动 | 平移视图 |

## 单实例页签

不管你点几次 🔍 / 🔗，主窗口只会有**一个**"🔗 引用 · xxx" 页签。每次点击会更新它的内容并切换过去，不会爆开多个。

## 数据来源

引用关系图扫描以下来源：

- **项目内**：所有打开过 / 项目根目录下的 xlsx / json / cnx 文件
- **外部引用源**：你在设置里挂的所有源（详见教程[[外部引用源]]）

> [!TIP]
> 数据是**异步扫描**的——大项目第一次打开关系图可能要等 1-2 秒。结果会缓存到下次手动刷新。

## 注意事项

> [!WARNING]
> 引用关系是基于**显式的 lookup / 外键配置**算出来的。如果你的引用是写在 Python 脚本里、或者在富文本里散写的，关系图扫不到。
