# Multi-Data Batch Modification

Powerful batch modification features for cells containing multiple data values.

## Supported Data Formats

1. **CT Multi-Data Edit Format**: Cells created using ConfigNexus multi-data editor
2. **Simple Array Format**: e.g., `[1,2]`
3. **Irregular Nested Format**: e.g., `[1,{2,3,4},{222,33}]`

## Batch Edit Operations

Follow these steps for batch modification:

1. Select the cells to modify
2. Right-click menu → Modify Existing Content → Batch Modify
3. Use operators in the popup to batch modify values
4. Enable rounding option if needed
