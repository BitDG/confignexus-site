# CT System Overview

CT means Configuration Type. It tells ConfigNexus that a column should use a dedicated editor instead of plain text editing.

## When To Use CT

Use CT when a cell stores structured content:

- styled text
- JSON objects
- reward lists or condition lists
- dates
- asset paths

## Basic Flow

1. Set the CT type in the table header type row.
2. Double-click a data cell.
3. ConfigNexus opens the matching editor.
4. Save the result back to the cell.
5. Export with the current table structure.
