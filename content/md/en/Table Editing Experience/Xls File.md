# Xls File

Support for Excel 97-2003 format (.xls) import and usage.

## Xls File Import

### Method 1: Menu Import

File → Import xlsx → Select xls format file for import

video:Res/zh/videos/导入xls.webm|Import xls File

### Method 2: Drag and Drop

You can also drag and drop xls files directly into the interface for import.

## Format Support Details

Xls files imported into ConfigNexus support the following features:
- ❌ Formulas (not supported)
- ✅ Font colors
- ✅ Font styles
- ✅ Font sizes
- ✅ Worksheet tab colors
