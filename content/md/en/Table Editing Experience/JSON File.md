# JSON File

Support for importing and exporting JSON object array format.

## Supported Object Arrays

### Standard JSON Array

```json
[
  {
    "id": 1,
    "name": "Item1",
    "type": "weapon",
    "price": 100
  },
  {
    "id": 2,
    "name": "Item2",
    "type": "armor",
    "price": 200
  }
]
```

## JSON Import

### Method 1: Menu Import

File → Import JSON → Select JSON file
