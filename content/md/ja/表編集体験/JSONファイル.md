# JSONファイル

JSONオブジェクト配列形式のインポートとエクスポートをサポートします。

## サポートオブジェクト配列

### 標準JSON配列

```json
[
  {
    "id": 1,
    "name": "アイテム1",
    "type": "weapon",
    "price": 100
  },
  {
    "id": 2,
    "name": "アイテム2",
    "type": "armor",
    "price": 200
  }
]
```

## JSONインポート

### 方法1：メニューインポート

ファイル → JSONインポート → JSONファイルを選択

video:Res/zh/videos/导入json.webm|JSONインポート

### 方法2：貼り付けインポート

コピーしたJSON内容は貼り付け時に自動認識されインポートされます
