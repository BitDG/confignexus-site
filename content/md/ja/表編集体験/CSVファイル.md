# CSV ファイルサポート

標準 CSV フォーマットのインポートと使用をサポートします。Web Worker による非同期処理で、大容量ファイルでもスムーズに読み込めます。

createtab:Res/zh/templates/CSV导入演示.cnx

## 主な特徴

| 機能 | 説明 |
|------|------|
| Web Worker 非同期処理 | バックグラウンドスレッドで解析を実行し、UI をブロックしない |
| エンコーディング自動検出 | UTF-8、Shift_JIS、GBK など主要な文字コードを自動判別 |
| 区切り文字自動検出 | カンマ・タブ・セミコロンなどの区切り文字を自動認識 |
| ドラッグ＆ドロップ | ファイルを画面にドロップするだけで即座にインポート |

## CSV インポート

2 つのインポート方法をサポートしています。

### 方法 1：メニューインポート

ファイル → CSV インポート → CSV ファイルを選択してインポート

video:Res/zh/videos/导入csv.webm|CSVインポート

### 方法 2：ドラッグ＆ドロップ

CSV ファイルを ConfigNexus の画面に直接ドラッグ＆ドロップしてインポート

video:Res/zh/videos/拖拽csv.webm|ドラッグ＆ドロップCSV

## CSV フォーマット説明

> [!NOTE]
> CSV フォーマットはデータ内容のみを含み、表示フォーマット（フォント、色などのスタイル情報）は含みません。

## 対応エンコーディング

- UTF-8（BOM 付き / BOM なし）
- Shift_JIS
- GBK / GB2312
- EUC-JP
- ISO-8859-1
