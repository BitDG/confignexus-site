# マルチタブ管理

A テーブルを編集している途中で B テーブルの数値を確認したくて B を開く——すると A テーブルでさっき選んでいた範囲やカーソル位置がすべて失われる。マルチタブはこれを解決します：メインウィンドウで**複数のテーブルを同時に開き**、各テーブルに 1 つのタブを割り当て、切り替えてもそれぞれが編集状態を保ち、互いに邪魔しません。

## タブの種類

| 種類 | アイコン | 意味 |
|------|------|------|
| 通常ワークシート | 📊 | xlsx / cnx ファイルのある sheet |
| ウェルカムページ | 🏠 | ホーム（このページのある場所） |
| 設定 | ⚙️ | 設定センター |
| 参照関係グラフ | 🔗 | 単一インスタンスで再利用、詳細は[[参照関係グラフ]] |

![マルチタブ管理-タブバー](Res/zh/images/多页签管理-页签栏.png)

## 新しいタブを開く

| 操作 | 説明 |
|------|------|
| ファイルブラウザでファイルをダブルクリック | 新しいタブで開く |
| メニュー ファイル → 開く | ファイルを選択 → 新しいタブ |
| メニュー ファイル → 新規 | 空白ワークシート → 新しいタブ |
| ファイルをメインウィンドウにドラッグ | 自動的に新しいタブで開く |
| タブバー右端の **+** をクリック | 空白ワークシートを新規作成 |
| ウェルカムページ → 設定 をクリック | 単一インスタンスの設定ページ |

## タブバーの右クリックメニュー

タブ上で右クリック：

- **閉じる** —— このタブだけ閉じる
- **他を閉じる** —— これを残して他をすべて閉じる
- **右側をすべて閉じる** —— このタブより右側をすべて閉じる
- **パスをコピー** —— ソースファイルのパスをクリップボードにコピー
- **ファイルマネージャーで表示** —— そのファイルのあるフォルダへジャンプ

## パフォーマンス最適化（重要）

ConfigNexus は開いた瞬間にすべてのタブを完全に描画するわけではありません——アクティブなタブだけが**実際に** Luckysheet インスタンスを描画します。別のタブに切り替えると：

- 現在のタブの Luckysheet インスタンスは**状態を保持**（カーソル位置、選択範囲、未保存の変更）
- 非表示にして CPU を消費しない
- 切り替えて戻すと瞬時に復元

効果：数十個のタブを開いてもメモリ使用は線形に増えるだけで、CPU が数十個の非表示タブに引きずられて遅くなることはありません。

## プリレンダリング機構

タブ切り替え時に「Luckysheet インスタンスを作成する」1〜2 秒を待たなくて済むよう、システムは非表示のインスタンスを**事前描画**します：

- 起動時にテーブルを 1 つも開いていなければ、バックグラウンドで空の Luckysheet を静かに描画
- ユーザーが **+** を押すと事前描画済みのインスタンスを即使用 → 即時表示
- 使い終わったらバックグラウンドで次を準備

これが「空白タブの新規作成」がほぼ瞬時に出てくる理由です。

## ドラッグで並べ替え

タブはドラッグして並べ替えられます——タブの頭を長押しして横方向に目標位置までドラッグします。

## 未保存の変更を閉じる

未保存の変更があるタブを閉じるときは確認ダイアログが出ます：

- **保存して閉じる**
- **保存せず閉じる**
- **キャンセル**

設定で既定の動作を変更できます（詳細は[[自動保存]]）。

## タブ数の上限

理論上は無制限ですが、**同時に 20 個まで**を推奨します。開きすぎるとタブバーが詰まり（横スクロールは可能ですが）、切り替えの体感も低下します。

## 注意事項

> [!TIP]
> タブ切り替えのショートカット：**Ctrl+Tab** で次へ / **Ctrl+Shift+Tab** で前へ。よく使う 2 つのテーブルをすばやく行き来できます。

> [!NOTE]
> ウェルカムページ / 設定ページ / 参照関係グラフ はすべて**単一インスタンス**——再度開くと既存のタブに切り替わり、2 つ目が増えることはありません。
