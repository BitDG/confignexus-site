# データ変換

マッピングテーブルの設定に基づいて、複雑なマルチデータセルの内容を自動計算・変換します。

createtab:Res/zh/templates/数据转换演示.cnx

> [!note]
> **開き方：** 多数データ列（`[{...},{...}]` 形式）の**列ヘッダー**（スプレッドシート上部の列記号行）を右クリック →「コンテンツを生成」→「データ変換」。事前に列を CT マルチデータ編集器に設定しておく必要があります（列ヘッダーを右クリック → CT プロパティ、詳細は[[マルチデータ編集モード]]）。

> [!note]
> 本節の翻訳・内容は現在更新中です。詳細な手順は中国語チュートリアルに合わせて今後追加されます。

## 機能一覧

| 機能 | 説明 |
|------|------|
| データ解析グループ化 | マルチデータセル内の `{}` ブロックを自動認識してグループに分割 |
| マッピングテーブル参照 | 外部テーブルから対応する値（価格・名称など）を自動検索 |
| 期待値計算 | 確率付きデータの期待値を自動算出 |
| 区切り検出 | カンマ・セミコロンなどの区切りパターンを自動認識 |

## 使用シーン

CT マルチデータエディタのデータに対応し、マッピングテーブルの設定に基づいて計算・変換を行います。

### 報酬配列の例

```
[{1001,30,0.75},{1002,50,0.85}]
```

データ構造：`{報酬ID, 数量, 獲得確率}`

### 計算要件

このセルの具体的な価値を計算するには：

1. マッピングテーブル `item` で報酬 ID に対応するゴールド価格を検索
2. ゴールド価格 × 数量 × 獲得確率 を計算
3. `{}` 内の各データグループの結果を合算して最終報酬価値を取得

### 計算式

```
総価値 = Σ (ゴールド価格 × 数量 × 獲得確率)
```

### 具体的な計算例

| 報酬ID | ゴールド価格 | 数量 | 確率 | 小計 |
|--------|-------------|------|------|------|
| 1001 | 10 | 30 | 0.75 | 225 |
| 1002 | 5 | 50 | 0.85 | 212.5 |
| **合計** | | | | **437.5** |

> [!TIP]
> マッピングテーブルは事前にプロジェクトに登録しておく必要があります。テーブル名と参照列の設定を確認してください。外部ファイルから取り込む場合は[[外部参照ソース]]を使います。
