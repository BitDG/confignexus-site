# 多言語文字抽出

ゲームに数千行のテキストがあり、最終的にはゲーム用のフォントに埋め込む——でもフォントファイルには数万の字形が含まれ、実際に使うのはそのうち 2〜3 千だけ。このツールはプロジェクト内の多言語フォーマット指定列をすべてスキャンし、出現した文字を重複除去してまとめた文字テーブルを作り、フォントサブセット化ツールに渡して、フォントを 10MB+ から数百 KB に圧縮します。

> [!tip]
> **ストア主力ツール**：プロジェクト内のすべての多言語テキストをスキャン → **重複しない文字集合**を抽出 → `charset.txt` を生成。[[フォントサブセット化]]と組み合わせれば、ゲームフォントを元の 5% 以下に圧縮できます。

## 用途

| シーン | 使い方 |
|------|--------|
| フォントサブセット化 | ここで生成した文字テーブルを使い、フォントサブセット化ツールでフォントを裁断 |
| 文字監査 | プロジェクトが実際に何種類の重複しない文字を使っているかを確認 |
| 文字互換性チェック | 文字テーブルをフォントツールに入れ、どのフォントが非対応かを確認 |

## 使い方

### ステップ 1：ツールを開く

メインウィンドウメニュー → **ツール → 多言語文字抽出**

### ステップ 2：スキャン範囲を設定

| オプション | 説明 |
|------|------|
| スキャン範囲 | 現在のワークシート / 現在のプロジェクトのすべてのテーブル / 自選 |
| スキャン列 | すべての列 / テキストタイプ列のみ / 自選 |
| 含める言語 | 簡体中文 / 繁体中文 / EN / JP / KR / 全選 |
| 文字フィルター | ASCII をスキップ / 数字をスキップ / 記号をスキップ（任意） |
| 出力パス | 既定 `<プロジェクト>/charset.txt` |

### ステップ 3：実行して結果を確認

![多言語文字抽出パネル](Res/zh/images/多语言字符提取面板.png)

「**抽出**」をクリックすると、完了後にステータスバーへ文字総数が表示されます。`charset.txt` の内容例：

```
攻撃力防御暴撃率天賦技能Hello World 你好こんにちは안녕하세요123456...
```

各文字が 1 つの位置を占め、重複除去され、Unicode コードポイント順に並びます。

> [!tip]
> ゲームフォントには通常 7000〜9000 個の漢字が含まれます。抽出して数千あれば十分で、サブセット化後の圧縮率は 95% を超えられます。

## よくある使い方

### 使い方 1：「フォントサブセット化」と組み合わせ

最もよくある使い方。文字集合を抽出したら、そのまま[[フォントサブセット化]]ツールへ送ってフォントを裁断します（詳細は対応チュートリアル）。

### 使い方 2：プロジェクトに「怪しい文字」がないか検出

プランナーがコピペで**全角スペース / 不可視文字 / 絵文字**を持ち込むことがあります——これらはゲームフォントで豆腐（□）表示になります。

文字抽出を一度走らせ、`charset.txt` に次のものがないか確認：
- 全角スペース `　`
- ゼロ幅スペース
- 制御文字
- 絵文字（絵文字を対応しない予定なら）

見つかったら「検索置換」で一括クリーニングします。

### 使い方 3：増分抽出

リリース前に毎回実行し、前バージョンの文字テーブルと diff すると、このバージョンで新しく追加された文字が分かります——フォントを再サブセット化するかどうかを判断できます。

## 高度な内容

出力される `charset.txt` は**文字ホワイトリスト**——フォントサブセット化ツール、ローカライズチェックスクリプト、アーティストのアート文字制作（この文字だけ描けばよい）に同時に渡せます。

> [!note]
> スキャンはセル内の**数式の結果**も対象に含めます——例えば `=CONCATENATE("プレイヤー", A1)` が算出した「プレイヤー田中」は「プレイヤー田中」の各文字を抽出します。

> [!note]
> 「除外」——例えば簡体字をすべて除外して繁体中文 / 英 / 日のみの文字を得る——をしたい場合、現状は非対応です。抽出後にスクリプトで charset.txt を後処理する必要があります。
