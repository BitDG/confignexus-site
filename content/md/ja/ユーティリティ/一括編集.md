# 一括編集

マルチデータ列のデータを効率的に一括で編集・管理する機能です。

createtab:Res/zh/templates/批量编辑演示.cnx

> [!TIP]
> 一括編集は **CT マルチデータ型**（`[{...},{...}]` のオブジェクト配列）の列に特化しています。通常のテキスト/数値列の一括変更は[[マルチデータ一括修正]]の「計算/接頭・接尾辞」モードの方が適しています。

## 機能一覧

| 機能 | 説明 |
|------|------|
| マルチデータ列識別 | CT マルチデータ型の列を自動認識して一括編集モードを有効化 |
| 一括編集テーブル | 専用のテーブル UI で複数行のマルチデータを同時に閲覧・編集 |
| コンテキストメニュー | 右クリックメニューから一括編集モードをすばやく起動 |
| 値収集 | 列内のすべてのユニーク値を自動収集し、選択肢として表示 |

## 使い方

### 一括編集の起動

1. マルチデータ型の列のセルを選択
2. 右クリックメニューから「一括編集」を選択
3. 一括編集テーブルが表示される

### 一括編集テーブルの操作

一括編集テーブルでは、マルチデータ列内のすべてのデータが展開されて表示されます。

- **行の追加**：新しいデータ行を追加
- **行の削除**：不要なデータ行を削除
- **値の編集**：各セルの値を直接編集
- **値収集**：列内の既存値を自動収集し、ドロップダウンから選択可能

## 使用ケース

### ゲーム報酬設定

報酬テーブルで複数のアイテム・数量・確率をまとめて編集する場合に便利です。

```
[{1001,30,0.75},{1002,50,0.85},{1003,10,0.50}]
```

一括編集テーブルを使うと、上記のような複雑なマルチデータを表形式でわかりやすく編集できます。

### ドロップテーブル設定

ドロップアイテムのリストを一覧で確認・編集し、値の重複チェックや一括変更を効率的に行えます。

> [!TIP]
> 値収集機能を使うと、既存データから入力候補を自動生成できるため、入力ミスを減らせます。
