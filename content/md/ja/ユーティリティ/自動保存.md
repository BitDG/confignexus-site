# 自動保存

編集中のデータを自動的に保存し、予期しないクラッシュやフリーズによるデータ損失を防止します。

## 機能一覧

| 機能 | 説明 |
|------|------|
| アイドル検出 | 最後の編集操作から 2 分間操作がない場合に自動保存を実行 |
| 最小間隔制御 | 連続保存を防ぐため、最小 1 分の間隔を設ける |
| 元のフォーマットで書き戻し | xlsx / xls / cnx など、開いたファイルの元の形式で上書き保存 |
| 失敗通知 | 保存に失敗した場合、トースト通知でユーザーに警告 |

## 動作の仕組み

### 保存トリガー

1. ユーザーが編集操作を行う
2. 最後の操作から **2 分間** アイドル状態が続く
3. 前回の自動保存から **1 分以上** 経過している
4. 上記の条件をすべて満たした場合に自動保存が実行される

### 保存フロー

```
編集操作 → アイドル検出タイマー開始 → 2分経過
→ 最小間隔チェック → 元のフォーマットで保存
→ 成功 / 失敗通知
```

## 対応ファイル形式

| 形式 | 説明 |
|------|------|
| `.cnx` | ConfigNexus ネイティブプロジェクト形式 |
| `.xlsx` | Excel 2007 以降の形式 |
| `.xls` | Excel 97-2003 形式 |

## 設定

自動保存はデフォルトで有効です。設定画面から以下を変更できます：

- 自動保存の有効 / 無効切り替え
- アイドル検出時間の調整
- 最小保存間隔の調整

> [!NOTE]
> 新規作成で未保存のファイル（ファイルパスが未設定）の場合、自動保存は実行されません。最初に「名前を付けて保存」でファイルを作成してください。

> [!TIP]
> 重要な変更を行った直後は、`Ctrl+S` で手動保存することを推奨します。自動保存はあくまでセーフティネットとしてご利用ください。
