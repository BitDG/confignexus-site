# カスタム数式

独自の数式を登録・管理し、スプレッドシート内で繰り返し使用できるカスタム数式機能です。

## 機能一覧

| 機能 | 説明 |
|------|------|
| 数式登録 | カスタム数式に名前・説明・計算ロジックを定義して登録 |
| CRUD 管理 | 登録済み数式の作成・参照・更新・削除が可能 |
| 永続化 | 数式定義はプロジェクトに保存され、次回起動時にも利用可能 |
| インポート / エクスポート | 数式定義を JSON ファイルとして書き出し・読み込み |

## 使い方

### 数式の登録

1. メニューまたはツールバーから「カスタム数式マネージャー」を開く
2. 「新規作成」をクリック
3. 数式名、説明、計算ロジックを入力
4. 「保存」をクリックして登録完了

### 数式の使用

1. セルを選択して数式入力モードに切り替え
2. 登録したカスタム数式名を入力
3. 引数を指定して Enter で確定

## インポート / エクスポート

- **エクスポート**：登録済みの数式を JSON ファイルとして書き出し、チームで共有可能
- **インポート**：他のプロジェクトからエクスポートした数式ファイルを読み込み

> [!TIP]
> チーム内で頻繁に使う計算ロジックは、エクスポート機能で共有すると効率的です。

## 注意事項

- 数式名は英数字とアンダースコアのみ使用可能
- 既存の Luckysheet 組み込み関数名との重複は不可
