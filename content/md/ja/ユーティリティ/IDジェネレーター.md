# ID ジェネレーター

ユニーク ID を自動生成し、手動入力による重複や欠落を防ぎます。

createtab:Res/zh/templates/ID生成器演示.cnx

## 機能一覧

| 機能 | 説明 |
|------|------|
| フォーマットテンプレート | プレフィックス・サフィックス・桁数などのカスタムフォーマットを定義 |
| 自動増分 | 連番 ID を自動的に生成（例：1001, 1002, 1003...） |
| ランダム生成 | ランダムな数値または文字列の ID を生成 |
| UUID 生成 | 標準 UUID v4 フォーマットのユニーク識別子を生成 |
| プリセット管理 | よく使うフォーマット設定をプリセットとして保存・呼び出し |
| 一括入力 | 選択した複数セルに一括で ID を自動入力 |

## 使い方

1. ID を生成したいセル範囲を選択
2. コンテキストメニューまたはツールバーから「ID ジェネレーター」を開く
3. 生成モード（自動増分 / ランダム / UUID）を選択
4. フォーマットテンプレートを設定（必要に応じてプリセットを利用）
5. 「生成」をクリックして選択範囲に一括入力

## フォーマット例

| モード | 例 |
|------|------|
| 自動増分 | `item_1001`, `item_1002`, `item_1003` |
| ランダム数値 | `78432`, `29185`, `56701` |
| UUID | `a1b2c3d4-e5f6-7890-abcd-ef1234567890` |

> [!TIP]
> プリセットに保存したフォーマットは、他のプロジェクトでも再利用できます。

## 注意事項

- ID の一意性はテーブル内で自動チェックされます
- 既存データがあるセルに生成する場合、上書き確認ダイアログが表示されます
- 大量のセル（1000 行以上）への一括生成にも対応しています
