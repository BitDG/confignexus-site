# スマートペースト

クリップボードの内容をスマートに解析し、Markdown テーブルや JSON 配列を自動的にスプレッドシートデータに変換して貼り付けます。

## 機能一覧

| 機能 | 説明 |
|------|------|
| Markdown テーブル変換 | Markdown 形式のテーブルを自動認識し、セルデータに変換して貼り付け |
| JSON 配列変換 | JSON 配列形式のデータを解析し、行・列に自動マッピング |
| 確認ダイアログ | 変換内容をプレビューし、確認してから貼り付けを実行 |

## 対応フォーマット

### Markdown テーブル

```markdown
| ID | 名前 | 価格 |
|----|------|------|
| 1001 | 回復薬 | 100 |
| 1002 | 魔力薬 | 200 |
```

上記のような Markdown テーブルをコピーして貼り付けると、自動的にスプレッドシートのセルデータに変換されます。

### JSON 配列

```json
[
  {"id": 1001, "name": "回復薬", "price": 100},
  {"id": 1002, "name": "魔力薬", "price": 200}
]
```

JSON 配列をコピーして貼り付けると、キーがヘッダー、値がセルデータとしてマッピングされます。

## 使い方

1. Markdown テーブルまたは JSON 配列をクリップボードにコピー
2. ConfigNexus のスプレッドシート上でターゲットセルを選択
3. `Ctrl+V` で貼り付け
4. スマートペーストが内容を検出し、確認ダイアログが表示される
5. プレビューを確認して「貼り付け」をクリック

> [!TIP]
> 通常のテキスト貼り付けの場合、スマートペーストは自動的にスキップされ、標準の貼り付け動作が実行されます。

## 注意事項

- Markdown テーブルはヘッダー行とセパレーター行（`|---|---|`）が必須です
- JSON は配列形式（`[...]`）のみ対応し、オブジェクト単体は非対応です
- 大量データの場合は変換に数秒かかることがあります
