# 🚀 はじめてのレッスン

ConfigNexus を初めて開いて、ボタンだらけでどこから手をつければいいか分からない？このページでは**最初の 1 枚の設定テーブルを最後まで通して作る**手順を案内します——ソフトを開くところから、ゲームエンジンがそのまま読める形式にエクスポートするところまで。コードは一切不要、クリックしていくだけです。

> [!tip]
> このページは「全体ロードマップ」です。各ステップで触れる機能には専用の詳しいチュートリアルがあります。深く知りたい場合は左側の目次から該当ページを開いてください（本文中ではリンクで示しています）。

---

## 何をするもの？

一言で：**ConfigNexus はゲーム設定データ向けの「スーパー Excel」**です。Excel のようにテーブルを埋め（数値・テキスト・アイテム・会話……）、データに入力ミスがないか検証し、最後に Unity / Unreal / Godot / 自社エンジンがそのまま読める形式（JSON、C#、Lua など）へワンクリックでエクスポートします。

プランナーがテーブルを埋め、プログラマーがデータを読み、アーティストがリソースを設定する——三者が 1 つのプロジェクトを共有し、「Excel を送り合って修正する」やり方から卒業できます。

---

## ステップ 1：画面を知る

開くと Excel に似たメインウィンドウが現れます。まず 4 か所を覚えましょう：

| 場所 | 何か |
|------|--------|
| 上部メニューバー | **ファイル / 表示 / ツール / ヘルプ** の 4 メニュー。すべての機能入口がここ |
| テーブル領域 | 中央の大きなテーブル。Excel と同じ操作（入力・フィルター・固定・数式） |
| タブバー | テーブルの上部。複数のテーブルを同時に開け、互いに影響しない（詳細は[[マルチタブ管理]]） |
| 右下のデスクトップペット | 動く小さなアシスタント。クリックすると AI 対話やよく使うツールが開く |

> [!note]
> 上部メニューの所属を覚えておきましょう：**新規/開く/インポート/エクスポート/保存**は「ファイル」、**ログ/ファイルブラウザ**は「表示」、**Python スクリプト/スクリプトライブラリ**は「ツール」、**チュートリアル/バージョン情報**は「ヘルプ」です。

---

## ステップ 2：最初のテーブルを作る

4 つの始め方があります。1 つ選んでください：

1. **ゼロから新規作成**：メニュー **ファイル → 新規プロジェクト**（またはタブバーの ➕）で空のテーブルを作り、自分で埋める。
2. **既存の Excel をインポート**：メニュー **ファイル → Excel インポート**で手元の `.xlsx` / `.xls` を選ぶと、データがそのまま入る（詳細は[[Xlsxファイル]]）。
3. **JSON / CSV をインポート**：メニュー **ファイル → JSON インポート** または **CSV インポート**（詳細は[[JSONファイル]][[CSVファイル]]）。
4. **テンプレートを利用**：メニュー **ファイル → テンプレート**でスタートテンプレートを選んでそのまま編集。

> [!tip]
> 初めての方は、まず「Excel インポート」で既存のテーブルを取り込むのが一番実感しやすいです。

---

## ステップ 3：データを編集する

テーブルに入ったら Excel のように直接入力します。ConfigNexus が Excel より優れているのは **CT 列タイプ**——ある列に「この列にはどんなデータが入るか」を指定すると、編集体験が一気に向上します：

- **列ヘッダーを右クリック → 列タイプを設定**で選べます：
  - **日付**：ダブルクリックで日付選択器が開き、手入力不要（詳細は[[日付エディタ]]）
  - **リソース**：ダブルクリックで画像/音声を選び、セル内にサムネイル表示（詳細は[[リソースエディタ]]）
  - **JSON**：複雑なネスト構造をコード＋ツリービューで編集、セル内で手打ちしない（詳細は[[JSONエディタ]]）
  - **マルチデータ**：`[{...},{...}]` のようなオブジェクト配列をビジュアルに一括編集（詳細は[[マルチデータ編集モード]]）
  - **リッチテキスト**：Notion のような WYSIWYG レイアウト（詳細は[[リッチテキスト編集]]）

> [!tip]
> 最初から CT を設定する必要はありません。テキスト/数値はそのまま入力で OK。「日付の形式をよく間違える」「画像パスを覚えられない」といった痛みに出会ってから、その列に対応する CT タイプを設定すればよいのです。

## ステップ 4：データに入力ミスがないか確認する

テーブルを埋めたら、エクスポート前に一度健康診断を。間違ったデータをゲームに持ち込まないように。

ConfigNexus は**検証ルール DSL** を使います：ヘッダー行に小さなルール（例えばある列に `required`（必須）、`unique`（重複不可）、`range(1,100)`（値が 1〜100 の範囲））を書くと、ソフトが**入力ミスのセルをリアルタイムで赤く表示**し、検証ログをクリックすればエラーのセルに直接ジャンプできます。

- 詳しい書き方は[[データ検証]]と[[検証ルールDSL]]の 2 編を参照。
- 初心者が覚えるべき最も有用なもの：「ID 列」に `unique` を付けると、重複 ID を即座に発見できます。

## ステップ 5：エンジン向けにエクスポートする

データに問題がなければ、ワンクリックでエクスポート：

1. メニュー **ファイル → データエクスポート**でエクスポートパネルを開く。
2. エンジンが必要とする形式にチェック（複数選択可）——全部で **10 種類**：
   - テキスト系：**JSON / YAML / CSV**
   - コード系（ローダー付属）：**C# / TypeScript / Lua / C++**
   - バイナリ系：**Bytes / MessagePack / Protobuf**
3. 各形式に出力フォルダを選び、エクスポートをクリック。
4. 「エクスポート前に検証」にチェックを入れると、エラーがあれば止めてくれます。

> [!tip]
> どれを選べばいい？ Unity なら **C# + JSON**、Unreal なら **C++ + JSON**、フロントエンド/ミニゲームなら **TypeScript** または **JSON** を選びましょう。詳細は[[データエクスポート]]。

## ステップ 6：プロジェクトを保存する

作業の保存を忘れずに：

- メニュー **ファイル → プロジェクトを保存**、またはショートカット `Ctrl+S`。
- **`.cnx`** 形式（ConfigNexus ネイティブプロジェクトファイル）での保存を推奨——CT 列タイプ、テーブル間参照、Python 数式といった Excel では保存できないものを**完全に保持**し、閉じて開き直してもそのまま残ります。

> [!warning]
> `.xlsx` で保存すると、CT タイプ・テーブル間参照・数式などの高度な情報は失われます。日常作業は `.cnx` で保存し、他人に渡すときやアーカイブするときに対応形式へエクスポートしてください。

## 通せたら、次は何を学ぶ？

ここまでで ConfigNexus を使って作業できるようになりました。さらに進みたいなら、必要に応じて選んでください：

- **大量のデータをまとめて修正** → [[一括編集]][[マルチデータ一括修正]]
- **スクリプトで自動的にテーブルを処理** → [[Pythonスクリプトエディタ]][[Python数式統合]]
- **複数のテーブルを相互参照**（A 表に ID、B 表に名前を表示）→ [[外部参照ソース]][[参照関係グラフ]]
- **多言語対応**（中英日韓のテキスト管理）→ [[多言語ワークフロー]]
- **機能を追加**（ワークショップのプラグインを購読）→ [[Steamワークショップ]]

> [!success]
> 設定こそゲーム——テーブルを 1 マス変えれば、ゲームの挙動が変わります。まずこのメインルートを通し、残りの機能は必要になったときに学んでいきましょう。
