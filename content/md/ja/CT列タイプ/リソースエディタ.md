# リソースエディタ

プロフェッショナルなゲームリソースの管理・編集機能を提供します。

createtab:Res/zh/templates/资源编辑演示.cnx

## 機能一覧

| 機能 | 説明 |
|------|------|
| 画像プレビュー | セル内でリソース画像のサムネイルをリアルタイム表示 |
| オーディオ再生 | サウンドファイルをエディタ内で直接プレビュー再生 |
| フォルダ管理 | リソースフォルダの登録・切り替えで素早くアクセス |
| 検索・リネーム | ファイル名で検索し、リソースパスの一括リネームが可能 |

## 開き方

1. セルを選択 → 右クリックメニュー → CT 属性 → リソースエディタとして設定
2. 該当列がリソースエディタ列として設定されます
3. セルをダブルクリックしてリソース選択画面を開く

## リソース管理

### フォルダ登録

プロジェクトのリソースフォルダを事前に登録しておくと、リソース選択時にフォルダツリーからすばやくファイルを見つけられます。

### 検索機能

リソース名やパスの一部を入力して、目的のリソースをすばやく絞り込めます。

### サポートフォーマット

| カテゴリ | 対応形式 |
|------|------|
| 画像 | PNG, JPG, JPEG, GIF, BMP, SVG, WebP |
| オーディオ | MP3, WAV, OGG |
| その他 | ファイルパスとして任意の形式を設定可能 |

> [!TIP]
> リソースフォルダはプロジェクト設定から管理できます。複数のフォルダを登録して用途ごとに整理すると便利です。

> [!NOTE]
> 「この列はリソースエディタ列」という設定は `.cnx` プロジェクトファイルに保存され、`.xlsx` で保存すると失われます（詳細は[[cnxプロジェクトファイル]]）。
