# 日付エディタ

専用の日付選択・編集インターフェースで、手動入力による日付フォーマットエラーを防止します。

createtab:Res/zh/templates/日期编辑演示.cnx

## 機能一覧

| 機能 | 説明 |
|------|------|
| カレンダー UI | ビジュアルなカレンダーから日付を直感的に選択 |
| 多数の日付フォーマット | `YYYY-MM-DD`、`YYYY/MM/DD`、タイムスタンプなど複数形式に対応 |
| ショートカット操作 | 「今日」「昨日」「明日」などのクイック選択ボタン |
| セル内編集 | ダブルクリックでカレンダーがポップアップし、その場で編集可能 |

## 開き方

1. セルを選択 → 右クリックメニュー → CT 属性 → 日付エディタとして設定
2. 該当列が日付エディタ列として設定されます
3. 最初の 3 行（ヘッダー行）を除き、セルをダブルクリックすると日付選択画面が開きます

## 対応フォーマット

| フォーマット | 例 |
|------|------|
| `YYYY-MM-DD` | 2026-04-17 |
| `YYYY/MM/DD` | 2026/04/17 |
| `YYYY-MM-DD HH:mm:ss` | 2026-04-17 14:30:00 |
| Unix タイムスタンプ | 1776614400 |
| `MM/DD/YYYY` | 04/17/2026 |

## 使い方のヒント

- CT 属性でフォーマットを設定すると、列全体に統一フォーマットが適用されます
- ショートカットボタンで頻繁に使う日付をすばやく入力できます
- 手動入力も可能ですが、カレンダー UI の利用を推奨します

> [!TIP]
> 日付フォーマットは列単位で設定されます。同じ列内では統一されたフォーマットで出力されます。

## 注意事項

- 最初の 3 行はヘッダー行として扱われ、日付エディタは起動しません
