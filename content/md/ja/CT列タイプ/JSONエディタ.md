# JSON エディタ

報酬設定をセルに詰め込むとこうなります：`{"items":[{"id":1001,"rate":0.5}],"gold":50}` ——セルが狭くて全体が見えず、手で括弧を 1 つ、引用符を 1 つ消すだけでプログラムが即クラッシュ、多層ネストではどの階層を変えているのか分からなくなります。JSON エディタはこれを解決します：ある列を JSON タイプに設定し、セルをダブルクリックすると Monaco コードビュー＋ツリービューの 2 ビューが開きます。左でコードを変えれば右のツリーが即同期、右でノードをクリックすれば左のカーソルが追従し、形式が不正なときは保存ボタンがグレーアウトして、壊れた JSON はセルに書き込めません。

> [!tip]
> JSON（JavaScript Object Notation、軽量データ交換フォーマット）はネスト構造の保存に向きます——報酬リスト、アイテム属性、ステージパラメータなど。シンプルな「オブジェクト配列で各レコードの構造が固定」なら**マルチデータ編集**の方が直感的です（詳細は[[マルチデータ編集モード]]）。

## 使い方

### ステップ 1：ある列を JSON エディタに設定

対象列の任意のセルを選択 → **右クリック** → **CT 属性 → JSON エディタとして設定**。列全体に一度で適用されます。

> [!note]
> CT 属性（Column Type、列タイプ）は「この列にどんなデータが入るか」のラベルで、一度設定すれば列全体に効きます。デモプロジェクトの `drops` 列（D 列）が JSON エディタを設定する対象です。D 列の任意のセルを右クリックして設定できます。

### ステップ 2：データセルをダブルクリックしてエディタを開く

JSON 列で**データ行のセルをダブルクリック**すると、Monaco ＋ツリービューのポップアップが現れます。

> [!warning]
> ダブルクリックで開くのは**データ行**だけ。ヘッダー領域（フィールド名/型/検証ルールの数行）はダブルクリックしても開きません——リッチテキストエディタと同じく、ヘッダーをデータと間違えて変更しないための意図的な仕様です。

### ステップ 3：2 ビューで編集する

左側は Monaco コードビュー（VS Code と同じエディタ）で JSON テキストを直接編集。右側のツリービューが自動同期し、階層ごとに展開、ノードをクリックするとカーソルが対応行へ飛びます。

![JSONエディタ-2ビュー](Res/zh/images/JSON编辑器双视图.png)

よく使うツリービュー操作：

| 操作 | 効果 |
|------|------|
| ノードをクリック | 左側エディタのカーソルがその行へ移動 |
| ノードをダブルクリック | その値だけを編集する小窓を表示（数値/文字列/真偽に対応コントロール） |
| ノードを右クリック | 子ノードの追加 / 削除 / **パスをコピー** / すべて折りたたみ |
| ノードをドラッグ | 配列要素の順序を調整 |

### ステップ 4：形式を確認して保存

下部のステータスバーが JSON が正しいかをリアルタイム表示——正しければノード数と最深階層数を、エラーがあればエラー行＋説明を表示します。**形式が不正なときは保存ボタンがグレーアウト**し、修正しないとセルに書き戻せません。

> [!tip]
> よくある小さなミス（末尾カンマ `[1,2,]`、シングルクォート `{'key':'val'}`）はエディタが**まず自動修復を試みて**から開きます。自動修復できない場合のみエラーを出して問題行を指し示します。デモプロジェクトの 7 行目（エリートゴブリン）には末尾カンマを仕込んであり、開くと自動修復の様子が見えます。8 行目（スケルトン兵）は不完全な JSON で、エラーの位置表示が見られます。

## 値タイプの色分け

ツリービューでは各値が型ごとに色分けされます：

| 型 | 色 | 例 |
|------|------|------|
| 文字列 | 紫 | `"装備ドロップ"` |
| 数値 | 青 | `100` |
| 真偽 | オレンジ | `true` |
| null | グレー | `null` |
| 配列 | 緑 | `[3]`（3 要素） |
| オブジェクト | 緑 | `{2}`（2 フィールド） |

双方向同期で型が意図せず変わることはありません——コード領域を手で変更しない限り。

## JSON エディタ vs マルチデータ編集

| シーン | どちらを使う |
|------|--------|
| セル内が 1 つの JSON オブジェクト / 任意のネスト構造 | JSON エディタ |
| セルがオブジェクト配列で各レコードの構造が固定（報酬リストなど） | マルチデータ編集（スキーマ駆動で列の整列が直感的） |
| 一時的な探索 / 構造が不確定 | JSON エディタ（より柔軟） |

## 注意事項

> [!tip]
> ツリーノードを右クリック → **パスをコピー** すると `rewards[0].count` のような JSONPath が取れ、Python 数式 `=json_get('rewards[0].count')` に直接使って値を自動取得できます。

> [!warning]
> セルに数 MB の大きな JSON を詰めるとエディタの読み込みが遅くなることがあります——こうした大きな構造は外部の `.json` ファイルに置き、**外部参照ソース**で取り込む方が向いています（詳細は[[外部参照ソース]]）。

> [!note]
> 「この列は JSON エディタ列」という設定（CT 属性）は列のメタデータで、`.cnx` に保存され、フィールドとしてエクスポートされません。`.cnx` で保存すれば列タイプを保持できますが、`.xlsx` では失われます（詳細は[[cnxプロジェクトファイル]]）。
