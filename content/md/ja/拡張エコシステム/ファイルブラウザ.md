# ファイルブラウザ

プロジェクトが大きくなると、設定テーブルが十数個のフォルダに散らばる——ファイル探しは記憶頼み、ファイル名を変えるとどこの参照が切れるか分からず、Git/SVN の状態はターミナルを開かないと見えない。ファイルブラウザはこれらを 1 つのサイドバーに集約します：独立ウィンドウがメインウィンドウの左側に貼り付き、ファイルツリー＋バージョン管理バッジ＋参照グラフ入口の三位一体で、ソフトを離れずにプロジェクト全体のディレクトリを管理できます。

独立ウィンドウ形式のファイルツリーがメインウィンドウの左側に常駐し、プロジェクト全体のディレクトリ下の設定ファイルを管理します——新規 / リネーム / 削除 / メインウィンドウへドラッグして開く、Git / SVN バッジ・参照関係グラフ・外部参照ソースなどの拡張機能を統合しています。

## 機能の全体像

| 機能 | 説明 |
|------|------|
| ファイルツリー | フォルダ階層で展開、フォルダは遅延読み込み（開いて初めてスキャン）、万単位のファイルでも重くならない |
| 複数ロケーション切替 | 上部のドロップダウンで「作業ロケーション」を切替（複数のプロジェクトルート） |
| 検索ボックス | キーワード入力でツリー内のファイル名をリアルタイムフィルター |
| 右クリックメニュー | ファイル / フォルダの新規作成、リネーム、削除、ファイルマネージャーで表示、外部参照ソースとして追加 |
| ダブルクリックでメインに開く | 対応ファイル（xlsx / json / cnx など）をダブルクリックでメインウィンドウに開く |
| バッジシステム | ファイル名の横に Git/SVN 状態（M/A/D/U/C）を表示、git-mod・svn-mod プラグインが提供 |
| 参照関係グラフ入口 | ファイル行内の 🔍 単一ファイルビュー、左下の 🔗 現在フォルダ全体ビュー |
| 拡張スロット | 左側の縦並びアイコンバー（Git / SVN / 設定 / 参照グラフ）をプラグインが動的に登録 |

## ファイルブラウザを開く

メインウィンドウメニューバー **表示 → ファイルブラウザ**。ウィンドウは既定でメインウィンドウの左側に貼り付き、幅はメインウィンドウの 31.25%、高さはメインウィンドウと同じで、メインウィンドウの移動に追従します。

> [!TIP]
> ファイルブラウザは**独立ウィンドウ**で、メインウィンドウとはプロセス間通信です。閉じてもメインウィンドウで開いているテーブルには影響せず、再度開くと前回の閲覧位置を保持します。

## 作業ロケーションの切替

上部のドロップダウンには **設定 → ファイルブラウザの位置** で設定したすべての作業ロケーション（各ロケーション = 1 つのプロジェクトルート）が並びます。切り替えるとツリー全体が再読み込みされます。

ロケーションを 1 つも設定していない場合、ファイルブラウザは「前回メインウィンドウで開いたプロジェクトディレクトリ」をルートとして使います。

## ファイルツリー操作

| 操作 | 説明 |
|------|------|
| ファイルをシングルクリック | 選択ハイライト（開かない） |
| ファイルをダブルクリック | メインウィンドウで開く（対応形式のみ：xlsx / xlsm / xls / json / csv / cnx） |
| フォルダをシングルクリック | 展開 / 折りたたみ |
| ファイル名横の 🔍 をクリック | そのファイルの参照関係グラフを開く（対応形式のみ） |
| 任意のノードを右クリック | メニュー表示：新規 / リネーム / 削除 / ファイルマネージャーで表示 / 外部参照ソースとして追加 |

> [!NOTE]
> 削除操作は**システムのゴミ箱**を経由し、復元可能です。リネーム / 移動時にファイルがメインウィンドウで既に開かれている場合は、先に「このファイルは編集中です」と提示されます。

## 検索

上部の検索ボックスにキーワードを入力すると、現在のツリーで見えているファイル名を**リアルタイムフィルター**します（パス断片マッチを含む）。ESC または右の ✕ でクリア。

検索は展開済みの部分のみをフィルターします。ツリー全体を検索したい場合は、先にフォルダをすべて展開してください。

## バッジ（Git / SVN 状態）

現在のロケーションが Git リポジトリや SVN 作業コピー内にある場合、ファイル名の右側に 1 文字バッジが表示されます：

| バッジ | 色 | 意味 |
|------|------|------|
| M | 黄 | 変更済み |
| A | 緑 | 新規追加 |
| D | 赤 | 削除済み |
| U / ? | グレー | 未追跡 |
| C | 赤 | 競合 |

バッジは 30 秒ごとに更新され、commit / 取り消し / ステージングなどの操作後は即座に更新されます。

> [!TIP]
> バッジ機能は **git-mod** / **svn-mod** プラグインが提供し、システム PATH に `git` / `svn.exe` が必要です。未インストールなら自動的に非表示になり、他の機能には影響しません。

## 参照関係グラフ入口

- **ファイル行内 🔍**：「このファイルは誰に参照されている / このファイルは何を参照している」の単一ファイルビューを開く
- **左下 🔗**：現在のルートディレクトリを範囲として、関連参照グラフ全体を表示

どちらの入口もタブをメインウィンドウに開き、単一インスタンスで再利用します（再度クリックすると既存タブに切り替わり、複数開きません）。

## 外部参照ソースとして追加

任意のファイルまたはフォルダを右クリックし、**🔗 外部参照ソースとして追加** を選択：

- 表示名を入力（ドロップダウンでソースを区別するため）
- フォルダの場合「再帰スキャンするか」を確認（「はい」=すべてのサブディレクトリをスキャン、「いいえ」=第 1 階層のみ）
- 追加成功後はエイリアス数が表示され、エイリアス競合があれば **設定 → 外部参照ソース** で解決

詳細はチュートリアル[[外部参照ソース]]。

## 拡張スロット：左側の縦並びアイコンバー

左側の幅 44px の縦並びアイコンバーはプラグインが動的に登録します：

| アイコン | 提供元 | 作用 |
|------|------|------|
| 🌿 | git-mod | Git ソース管理パネルを開く（commit / pull / push / stash / branch） |
| 🌐 | svn-mod | SVN ソース管理パネルを開く（commit / update / log） |
| 🔗 | 内蔵 | 現在フォルダの関連参照関係グラフ |
| ⚙️ | 内蔵 | ファイルブラウザ設定 |

アイコンの順序・表示は `plugins/<plugin>/manifest.json` の `contributesSettings.sidebar.order` で制御されます。

## 注意事項

> [!WARNING]
> ファイルブラウザの「更新」ボタンはルートディレクトリを**再スキャン**します——ファイルが多いと 1〜2 秒待ちます。日常利用では手動更新は不要で、ファイルの変更は watcher が監視して自動的に反映します。

> [!NOTE]
> ファイルブラウザは**メインウィンドウのメモリを占有しません**。独立した描画プロセスを持ち、メインウィンドウとは IPC で通信します。

## 次に学ぶこと
