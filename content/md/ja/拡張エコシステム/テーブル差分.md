# テーブル差分

「最終_最終_V3_修正済み.xlsx」を受け取ったときに一番つらいのが、手元の 1 枚との比較——どちらも数百行あり、目視で 1 行ずつ追うか、Excel の VLOOKUP で間に合わせるしかなく、半日かけても見落としが起こりがち。テーブル差分は 2 つのファイルを並べると、どのセルが変わって何になったかをセルごとに、文字レベルの精度で教えてくれます。5000 行でも重くなりません。

2 つの xlsx / cnx ファイル、または同一ファイルの 2 つのバージョンの間で、**セルごとに比較**——どのセルが変わったか、何に変わったか、誰が行を足し、誰が列を消したかが一目瞭然です。

> [!IMPORTANT]
> テーブル差分は**独立 DLC ツール**で、Steam で別途入手が必要です。DLC をインストールして初めて、以下で説明する入口が現れます。

## 機能の全体像

| 機能 | 説明 |
|------|------|
| 文字レベル diff | セル内の文字を文字単位で変化ハイライト（セル全体のハイライトではない） |
| トークンレベル diff | 数値 / JSON / 配列をトークンで分割し、誤判定を回避 |
| 3 ステップフロー | フォルダ選択 → 差分ファイル一覧 → 具体的なセル diff |
| モジュール A：ポップアップ | 単一ファイル比較、ポップアップ形式 |
| モジュール B：独立ウィンドウ | フォルダ横断比較、独立ウィンドウ |
| Git / SVN 統合 | 「作業領域版 vs HEAD 版」を直接比較 |

## 3 つの開き方

### 方法 1：メニュー → テーブル差分

メインウィンドウメニューバー **📊 テーブル差分** → 独立ウィンドウ（モジュール B）を開き、完全な 3 ステップフローを進む：

1. **Step 1 2 つのフォルダを選ぶ**：左が「現在のバージョン」、右が「参照バージョン」
2. **Step 2 差分ファイル一覧**：2 つのフォルダ下のファイルの 追加/削除/変更 を一覧、行をクリックで展開
3. **Step 3 セル diff グリッド**：sticky の 3 行ヘッダー＋上下分層で、セルごとに変化を見る

### 方法 2：Git / SVN ソース管理パネル

ソース管理パネルで変更リストの `.xlsx` / `.cnx` ファイルをクリック：

- テーブル差分 DLC をインストール済み → 「テーブルで diff するか、テキストで diff するか」を表示
- テーブル diff を選択 → 作業領域版 vs HEAD 版、セル単位でハイライト
- テキスト diff を選択 → 通常の unified diff

### 方法 3：ブランチ ↔ 作業領域の比較

Git パネルの「履歴」ビューで、ある commit を右クリック → **作業領域とテーブルで diff** → commit のバージョンを一時ファイルへ自動エクスポートし、作業領域版と比較。

## diff の配色

| 色 | 意味 |
|------|------|
| 緑の背景 | 追加（参照版になく、現在版にある） |
| 赤の背景 | 削除（参照版にあり、現在版にない） |
| 黄の背景 | 変更 |
| 文字レベルの赤 / 緑 | 同一セル内で置換された部分文字列 |

## 文字レベル diff とは

例を挙げます：

| 参照バージョン | 現在バージョン | ハイライト効果 |
|---|---|---|
| `攻撃力 100` | `攻撃力 120` | 「100」赤、「120」緑、「攻撃力 」は変化なし |
| `[1,2,3]` | `[1,2,4]` | 「3」赤、「4」緑、その他変化なし |
| `報酬：金貨` | `報酬：ダイヤ` | 「金貨」赤、「ダイヤ」緑 |

実装は LCS（最長共通部分列）＋トークン分割。アルゴリズムは `cell-diff-render.js` にあり、vitest でカバーしています。

## 3 ステップフローの画面

### Step 1 フォルダを選ぶ

左右に 1 つずつフォルダを選びます（「現在 / 参照」の意味は自由、入れ替えると結果も反転）。「サブディレクトリを再帰スキャン」にチェックできます。

### Step 2 差分ファイル一覧

すべての差分ファイルを一覧：

- 追加（緑 +）：参照版になく、現在にある
- 削除（赤 -）：参照版にあり、現在にない
- 変更（黄 ~）：両方にあるが内容が異なる
- 同名同 hash のファイルは表示されない

行をクリックで展開 / 収納、ファイル名をクリックで Step 3 へ。

### Step 3 セル diff グリッド

- 3 行 sticky ヘッダー（sheet 名 / 列名 / ヘッダー）
- 行の高さは内容に応じて自動調整
- 上下分層で「参照 / 現在」を表示
- 同じ行同じ列の両側の内容を並べて表示

## パフォーマンス

文字レベル diff は**セルを開いたときだけ**計算します（遅延計算）。テーブル全体が 5000+ 行でも重くなりません。

## 注意事項

> [!NOTE]
> テーブル差分 DLC は有料 DLC で、未購入時はメニューや Git / SVN の「テーブルで diff」入口は現れず、対応する IPC も反応しません——ただし**通常のテキスト diff** は影響を受けません（Git / SVN 自身の機能）。

> [!TIP]
> 「参照関係グラフ」とは別の機能です：参照グラフは「誰が誰を参照するか」を見るもの、テーブル差分は「どのセルが何に変わったか」を見るものです。
