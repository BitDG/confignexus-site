# 関連参照関係グラフ

あるテーブルの ID 列を変えたが、プロジェクト内のどのテーブルがそれを参照しているか分からない——1 つずつ開いて手で調べると数十分かかり、見落としも起こりがち。参照関係グラフは、プロジェクト内のすべてのテーブル間の依存関係を 1 枚の図に描きます：開けば「このテーブルは誰に参照され、何に依存しているか」が一目で分かり、変更する前に影響範囲を把握してから手を動かせます。

現在のプロジェクト内で「どのテーブルが誰に参照されている / 何を参照しているか」のグラフをビジュアルに表示します——「ID を変えたらどのテーブルが影響を受けるか」「この報酬設定は何枚のテーブルで使われているか」を調べるのに使います。

![参照関係グラフ：プロジェクト内の各テーブルの依存関係をノードグラフ化、線が参照を示す](Res/zh/images/引用关系图-整图.png)

## 機能の全体像

| 機能 | 説明 |
|------|------|
| 単一ファイルビュー | 1 つのファイルを中心に、直接 / 間接の参照関係を表示 |
| ディレクトリ全体ビュー | 現在のルートディレクトリを範囲に、関連グラフ全体を表示 |
| ノードジャンプ | ノードをクリックするとメインウィンドウで対応テーブルを開く |
| 単一インスタンスタブ | 別のフォルダに切り替えても同じタブを再利用、参照グラフが乱立しない |

## 開き方

### 方法 1：ファイル行内 🔍（単一ファイルビュー）

ファイルブラウザで、任意の対応ファイル（xlsx / json / cnx）にマウスを乗せると、右側に 🔍 アイコンが現れます。クリック → 「このファイルの参照関係グラフ」タブを開く。

### 方法 2：左下 🔗（ディレクトリ全体ビュー）

ファイルブラウザ左下の 🔗 アイコン → 現在のロケーション（rootPath）をルートとして、そのフォルダ下のすべてのファイル間の参照関係を一覧します。

## グラフの読み方

- **矢印の向き**：A → B は A が B を参照していることを示す
- **ノードの色**：
  - 青：現在のフォーカスファイル
  - 緑：フォーカスファイルに参照されている
  - オレンジ：フォーカスファイルを参照している
- **ノードの大きさ**：参照される回数が多いほどノードが大きい

## ノード操作

| 操作 | 効果 |
|------|------|
| ノードをシングルクリック | メインウィンドウのタブでそのファイルを開く |
| ノードをダブルクリック | グラフのフォーカスをそのノードへ切替（それを中心に再描画） |
| ノードをドラッグ | レイアウトを調整して構造を見やすく |
| ホイールでズーム | グラフ全体を拡大縮小 |
| 空白部分をドラッグ | ビューをパン |

## 単一インスタンスタブ

🔍 / 🔗 を何度クリックしても、メインウィンドウには「🔗 参照 · xxx」タブが**1 つだけ**できます。クリックのたびに内容が更新されて切り替わり、複数開くことはありません。

## データソース

参照関係グラフは以下のソースをスキャンします：

- **プロジェクト内**：開いたことのある / プロジェクトルート下の xlsx / json / cnx ファイル
- **外部参照ソース**：設定で取り込んだすべてのソース（詳細はチュートリアル[[外部参照ソース]]）

> [!TIP]
> データは**非同期スキャン**です——大きなプロジェクトでは関係グラフを初めて開くとき 1〜2 秒かかることがあります。結果は次の手動更新までキャッシュされます。

## 注意事項

> [!WARNING]
> 参照関係は**明示的な lookup / 外部キー設定**から算出されます。参照を Python スクリプト内に書いていたり、リッチテキスト内にばらばらに書いていたりすると、関係グラフは検出できません。

## 次に学ぶこと

- ファイルブラウザで参照関係グラフを開く入口 → [[ファイルブラウザ]]
- 他プロジェクトのテーブルを取り込み、グラフでプロジェクト横断の参照も見る → [[外部参照ソース]]
- 2 つのバージョンの差分をセルごとに比較 → [[テーブル差分]]

> [!NOTE]
> 🔍 / 🔗 をクリックしても**反応がない**場合、まずファイルが対応形式（xlsx / json / cnx）か、ファイルブラウザで作業ロケーションを選択済みかを確認してください。それでも反応しないときは、ファイルブラウザを閉じて開き直すと復旧します。
