# Steam ワークショップ

新しいプロジェクトを始めるたびにテンプレートをゼロから組む——アイテム表、会話表、タスク表を 1 マスずつ再構築。Python スクリプトも同じで、前のプロジェクトで作った便利なエクスポートスクリプトを、別プロジェクトでまた書き直す。ワークショップは、こうした再利用できる「テンプレート / スクリプト / プリセット」をパッケージ化して共有します：ConfigNexus 内蔵ストアでコミュニティの成熟したコンポーネントをワンクリック購読したり、自作のものを他人に使ってもらうためにアップロードしたりできます。

> [!IMPORTANT]
> ワークショップは **Steam 正規ルートのみ**利用可能です。非 Steam ルート（クラック版 / グリーン版 / ネットディスク版）では入口がグレーアウトし、上部に「Steam 版のみ利用可」と表示されます。

## 機能の全体像

| 機能 | 説明 |
|------|------|
| コミュニティコンポーネント閲覧 | ConfigNexus 内蔵のコンポーネントストアで検索 / 並べ替え / プレビュー |
| ワンクリック購読 | 購読後、Steam が自動でダウンロードしローカルにインストール |
| 自動更新 | ワークショップでコンポーネントが更新されると、購読者は次回起動時に通知される |
| コンポーネントのアップロード | 自作コンポーネントをパッケージ化してアップロード、プレビュー画像・バージョン番号・依存説明を付与 |
| 規約署名 | アップロード前に Steam ワークショップ法的規約への署名が必要（1 回限り） |

## コンポーネントストアを開く

メインウィンドウメニューバー **ツール → コンポーネントストア**、またはウェルカムページ / 設定ページの入口から。

![ワークショップ-コンポーネントストア](Res/zh/images/创意工坊-组件商店.png)

ストアには 2 つのタブがあります：

- **インストール済み**：ローカルコンポーネント＋購読済みのワークショップコンポーネント
- **ストア**：現在 Steam で検索できるすべての公開コンポーネント（既定は人気順）

## コンポーネントを購読

ストアタブで：

1. 欲しいコンポーネントを検索 / 閲覧
2. **購読** をクリック
3. Steam がバックグラウンドでダウンロード（メイン画面をブロックしない）
4. ダウンロード完了後、自動的に「インストール済み」タブに現れ、状態が緑になる

## 購読を解除

「インストール済み」タブでそのコンポーネントを見つける → **購読解除** → ローカルファイルも同時に削除するか選択。

> [!NOTE]
> 購読解除は既定でローカルコピーを**削除します**。ローカルコピーを残したい場合は、先に ConfigNexus 外でコンポーネントディレクトリを手動バックアップしてください。

## コンポーネントをアップロード

### 前提条件

1. **Steam クライアントが起動中**で、**ログイン中のアカウントが ConfigNexus を所有**していること
2. **初回アップロード**：Steam ワークショップ法的規約への署名が必要（ポップアップでチェック確認）
3. **Pro 版機能**（無料版はダウンロード購読可、アップロードは不可）

### アップロードフロー

1. **ツール → コンポーネントストア → インストール済み** タブで、アップロードするローカルコンポーネントを選択
2. **ワークショップにアップロード** をクリック
3. アップロードメタデータを入力：タイトル / 概要 / タグ / 公開範囲（公開 / フレンドのみ / 非公開）/ プレビュー画像
4. 検証：システムがコンポーネント構造＋メタデータの妥当性を検証
5. パッケージ化：コンポーネントディレクトリを zip にしてアップロード
6. 規約署名：初回は規約がポップアップ（Steam クライアントで承認）
7. アップロード完了を待つ

### 以降の更新

同じコンポーネントを再アップロードすると（ディレクトリ内の `metadata.json` を変えずに）、システムが自動的に「新規」ではなく「更新」と認識します。規約の再署名は不要です。

## 作者本人確認

- 1 つのコンポーネントは原作者だけが更新できる
- アップロード時、システムは `metadata.authorSteamId` と現在ログイン中の Steam ID を比較する
- 一致しない場合はアップロードを拒否し「自分が作成したコンポーネントのみアップロードできます」と提示

> [!TIP]
> 初回アップロード時、システムは自動的に `metadata.authorSteamId` を現在のユーザーに設定します。そのため**初回アップロードは必ず作者本人**が行ってください。さもないと以降は更新できなくなります。

## エラー対照表

| エラーコード | 意味 | 解決 |
|--------|------|------|
| E_STEAM_UNINITIALIZED | Steam が未起動または未ログイン | Steam クライアントを起動してログイン |
| E_STEAM_AGREEMENT_REQUIRED | 先にワークショップ規約への署名が必要 | Steam クライアントで規約を承認 |
| E_AUTHOR_MISMATCH | 現在のアカウントが原作者でない | 原作者のアカウントでアップロード |
| E_COMPONENT_INVALID | コンポーネント構造が規約に合わない | `metadata.json` が揃っているか、プレビュー画像があるか確認 |
| E_UPLOAD_FAILED | ネットワーク / Steam サーバーの問題 | 後ほど再試行 |

## 注意事項

> [!WARNING]
> ワークショップにアップロードしたコンポーネントは**誰でも見られます**（「フレンドのみ」「非公開」を選んだ場合を除く）。商業秘密 / 顧客データを含む設定を公開ワークショップにアップロードしないでください。

> [!IMPORTANT]
> Steam ワークショップ法的規約への違反（他人の作品の盗用、違法コンテンツなど）は Steam アカウント凍結につながる可能性があります。アップロード前に、そのコンテンツの合法的な権利を保有しているか確認してください。
