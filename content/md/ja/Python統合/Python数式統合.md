# Python 数式統合

キャラクターの経験値計算式を変えたら、数千個のセルを手で更新し直す？攻撃力アルゴリズムを調整すると、芋づる式に全部直す羽目になる？ Python 数式統合は、複雑な計算ロジックを Python 関数として書き、セルに紐づけられます——Excel 数式のように、依存するセルが変われば下流のセルが**すべて自動再計算**されます。複雑な数値ルールも 1 行で済みます。

「Python スクリプトエディタ」（手書きスクリプトでバッチ処理）とは別の機能です：

| 項目 | Python スクリプトエディタ | Python 数式統合（本編） |
|------|------------------|----------------------|
| トリガー方法 | 手動で「実行」をクリック | セルに数式を書くと自動計算 |
| 用途 | 一度きりのバッチ処理 | 継続的に効く計算ロジック |
| キャッシュ | なし | SmartCache が自動キャッシュ |
| バッチ最適化 | なし | BatchExecutor が自動マージ |

## クイックスタート

1. Python スクリプトエディタを開き、関数を 1 つ書く：

   ```python
   def calc_exp(level):
       return level ** 2 * 100
   ```

2. 数式システムに登録（エディタ上部のボタン **数式として登録**）

3. 任意のセルに書く：

   ```
   =calc_exp(A2)
   ```

   A2 = 5 のとき、このセルは自動的に 2500 を算出します。A2 を変えると → このセルが自動再計算されます。

## 数式として登録

スクリプトエディタ上部の **数式として登録** ボタン → 登録する関数を選択 → 数式名を付ける（既定は関数名そのまま）。

登録後、関数は数式システムに永久に残り、プロジェクトをまたいで利用可能（既定スコープ）です。「現在のプロジェクト専用」に指定することもできます。

## SmartCache スマートキャッシュ

同じ入力 → 同じ出力 → 計算を繰り返さない：

- キャッシュキー：`関数名(パラメータのシリアライズ)`
- LRU 方式：直近に使った 1000 件の結果をメモリにキャッシュ
- TTL：既定 5 分、依存データが変わったら手動でクリア

効果：1 枚のテーブルで 10000 個のセルが同じ関数を呼び、パラメータの大部分が重複 → 実際は数十回しか計算しません。

## BatchExecutor バッチ実行

同じ関数が一群のセルから呼ばれると、システムが自動的にリクエストをマージします：

- 10ms 以内に同じ関数呼び出しが N 個あると検知 → 1 回の Python プロセス呼び出しにマージ
- Python 関数が受け取るのはパラメータ配列 → 結果配列を返す → 各セルへ振り分け

効果：セルを 1 個ずつ呼ぶと本来 N 回の Python プロセス往復 → 実際は 1 回の往復に。大きなテーブルの一括再計算が分単位から秒単位へ。

> [!TIP]
> あなたが書く Python 関数はバッチ最適化を**気にする必要はありません**。システムが「この関数はバッチ化できるか」を自動判断します——副作用のない純関数は自動でバッチ化、I/O がある関数は自動で単発呼び出しになります。

## セルに何を書けるか

- 基本呼び出し：`=my_func(A1)`
- ネスト：`=my_func(other_func(A1, B1))`
- 組み込み数式との併用：`=SUM(my_func(A1:A10))`（注意：range を渡すときは関数が配列パラメータに対応している必要あり）
- 文字列リテラル：`=lookup('item', 'id', A1)`

## 関数シグネチャの約束

数式として登録する関数は以下を満たす必要があります：

1. **副作用なし**（ファイルを書かない、グローバル状態を変えない）
2. **基本型を返す**（int / float / str / bool / list / dict）—— オブジェクト / クラスインスタンスは返さない
3. **パラメータ順が固定**（数式呼び出しは位置で渡す、キーワード引数は非対応）

満たさない関数は登録時に警告され、実行時にエラーになります。

## エラー処理

数式内で Python が例外を投げると → セルに `#ERR!` が表示され、マウスを乗せると例外の詳細が見えます：

```
#ERR! ZeroDivisionError: division by zero
  at calc_exp(level=0)
```

## 永続スクリプトライブラリ

登録した数式関数は自動的に**スクリプトライブラリ**に保存されます：

- メインウィンドウメニュー → **ツール → スクリプトライブラリ**
- 登録済み関数の一覧を見る
- 有効化 / 無効化 / 削除
- プロジェクトをまたいで再利用（既定スコープの関数はすべてのプロジェクトで使える）

詳細はチュートリアル[[永続スクリプトライブラリ]]。

## パフォーマンスベンチマーク

| シーン | キャッシュ/バッチなし | SmartCache + BatchExecutor |
|------|---------------|---------------------------|
| 5000 セル呼び出し、パラメータ全同一 | 5000 回の Python 呼び出し | 1 回（キャッシュヒット 4999 回） |
| 5000 セル呼び出し、パラメータ全異なる | 5000 回の Python 呼び出し | 5 回（各バッチ 1000） |
| 5000 セル呼び出し、80% 重複 | 5000 回 | ~1 回（重複分はすべてキャッシュ） |

> [!WARNING]
> 関数内で `time.sleep` / ネットワーク IO / ファイル IO を**書かないでください**——テーブル全体の再計算が遅くなります。こうした操作は「スクリプトエディタ」で手動実行してください。
