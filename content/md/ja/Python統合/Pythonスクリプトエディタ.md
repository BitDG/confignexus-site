# Python スクリプトエディタ

> [!IMPORTANT]
> この機能は ConfigNexus Pro 版の機能です。Steam で購入後にご利用いただけます。

ConfigNexus には強力な Python スクリプト実行環境が内蔵されており、開発者はワークベンチ内で直接データ処理ロジックを記述・実行できます。

> [!TIP]
> Python スクリプトエディタは「一度きりの一括処理」向け——実行したら終わり、です。ある列を Excel 数式のように**継続的に自動計算**させたい場合は[[Python数式統合]]を参照してください。

## 機能一覧

| 機能 | 説明 |
|------|------|
| Python API | テーブルデータの読み書き、セル操作などの専用 API を提供 |
| カスタム関数 | スクリプト内で関数を定義してテーブルの数式システムに登録、VBA のような体験を提供（[[Python数式統合]]） |
| スクリプトライブラリ | よく使うスクリプトを保存・管理し、ワンクリックで再利用（[[永続スクリプトライブラリ]]） |
| import 対応 | 標準ライブラリおよび許可されたサードパーティモジュールのインポートが可能 |
| セキュリティ制限 | サンドボックス環境で実行され、ファイルシステムやネットワークへのアクセスを制限 |

## PY エディタ

ワークベンチ内で直接 Python コードを記述・実行できます。

video:Res/zh/videos/脚本编辑器-操作.webm|スクリプトエディタを開く → スクリプトを書く → 実行 → 出力を確認

## PY 関数

カスタム関数を定義し、VBA のような体験、またはそれ以上の体験を提供します。スクリプト内の関数を数式として登録すると、セル内から直接呼び出せます（詳細は[[Python数式統合]]）。

## セキュリティについて

> [!NOTE]
> スクリプトはサンドボックス環境で実行されます。システムファイルへの直接アクセスやネットワーク通信は制限されており、安全にご利用いただけます。

## 使い方のヒント

- スクリプトライブラリに頻繁に使うコードを保存して効率化（詳細は[[永続スクリプトライブラリ]]）
- エラーが発生した場合はコンソールログで詳細を確認可能
- 複雑な処理は関数に分割して管理すると保守性が向上します
