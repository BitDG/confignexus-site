# AIのインストールとモデル設定

## 解決できること

ConfigNexus の AI 機能は、実行時プラグインを通じてモデルに接続します。初めて使用するときは、プラグインをインストールし、サービスへ接続してモデルを選択します。

## 対応する接続方法

| 接続方法 | 適した用途 | データの送信先 |
|---|---|---|
| Ollama | オープンソースモデルをローカルで実行したい場合 | 通常はローカルに残ります |
| LM Studio | LM Studio ですでにモデルをダウンロードして読み込んでいる場合 | 通常はローカルに残ります |
| リモート API | OpenAI 互換プロトコルのオンラインサービスを使う場合 | 対応するサービス事業者へ送信されます |

## 操作手順

1. ワークショップを開き、必要な AI 実行時プラグインをインストールします。
2. プラグインの案内に従って Ollama または LM Studio を起動するか、リモート API を設定します。
3. ConfigNexus を再起動します。
4. デスクトップペットを右クリックし、**アシスタントハブ設定**を開きます。
5. **接続設定**を開き、**プラグインを更新**と**すべてのモデルを更新**を実行します。
6. 既定のモデルを選び、必要に応じて翻訳、文章改善、ワークシート操作、フィールド生成、数式生成、チャット用モデルを選びます。
7. メイン画面に戻り、スマートアシスタントが接続済みと表示されることを確認します。

## プライバシー

ローカル実行を選んでも、すべての接続がオフラインになるとは限りません。Ollama と LM Studio は通常ローカルで処理しますが、リモート API はリクエストに必要な内容をサービス事業者へ送信します。機密データをリモートモデルで扱う前に、事業者のデータポリシーを確認してください。

## よくある問題

> [!warning]
> AI 実行時プラグインが未インストールの場合、チャット、全体翻訳、ワークシート操作、右クリックの AI メニューは表示されません。

- モデルが見つからない：サービスが起動し、モデルが読み込まれていることを確認してから一覧を更新します。
- 接続できない：サービスのアドレス、ポート、ファイアウォール、API キーを確認します。
- 違うモデルが使われる：そのタスクに個別のモデルが指定されていないか確認します。
