# 外部AIからConfigNexusを操作

## 解決できること

ConfigNexus は MCP（外部 AI からアプリの機能を呼び出すための標準インターフェース）に対応しています。接続すると、Claude Code や Codex などのツールから ConfigNexus に実際のデータ操作を依頼できます。

## 呼び出せる操作

- 設定データのエクスポート。
- データ検証の実行。
- Excel のインポート、Excel への変換。
- ディレクトリ、ファイル、セルの差分比較。
- データ書き戻しのプレビューと確定。
- 外部参照の読み取り。
- 実行環境の確認。

## 接続手順

1. デスクトップペットを右クリックし、**アシスタントハブ設定**を開きます。
2. **接続設定**を開きます。
3. **AI ツール接続（MCP）**を探します。
4. **AI 接続設定をコピー**を選びます。
5. 外部 AI ツールの MCP 設定へ貼り付けます。
6. 外部 AI ツールを再起動または更新します。
7. 最初に環境確認を実行し、小さなプロジェクトで検証またはエクスポートを試します。

## 推奨する安全な順序

1. 最初に環境を読み取り、確認します。
2. 次に検証、エクスポート、差分比較を実行します。
3. 書き戻しを伴う場合は先にプレビューします。
4. プレビュー結果を確認してから書き込みを確定します。

> [!warning]
> MCP により外部 AI は実際の操作権限を持ちます。書き戻しのプレビューを省略せず、対象パスを確認せずに一括変更を承認しないでください。

> [!note]
> Claude Code と Codex は MCP クライアントの例です。各社のモデル API が ConfigNexus に直接内蔵されているという意味ではありません。
