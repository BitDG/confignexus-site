# AIでPythonスクリプトを生成

## 解決できること

Python を一から書けない場合でも、処理の目的を説明して AI にスクリプトや数式コードを作成させ、エディタで確認してから実行できます。

## 操作手順

1. Python スクリプトエディタまたは数式エディタを開きます。
2. 処理するデータ、期待する結果、制約を入力します。
3. コードを生成します。
4. すぐには実行せず、生成結果を確認します。
5. まず小さなデータ範囲でテストします。
6. 出力が正しいことを確認してから正式なテーブルで使います。

## 指示の例

> 現在のワークシートの `price` 列と `count` 列を読み、`total=price*count` を計算してください。空の値は 0 として扱い、ほかの列は変更しないでください。

## 実行前の確認

- 入力と出力のフィールドが実際に存在するか。
- 空の値、文字列、不正なデータを処理できるか。
- 変更範囲が想定どおりか。
- 不要なファイル、ネットワーク、システム操作が含まれていないか。
- 元のデータを意図せず上書きしないか。

> [!warning]
> AI が生成したコードも通常のコードです。実行前に必ず読み、内容を確認してください。一括変更の前にはプロジェクトを保存するか、復元できるコピーを用意してください。
