# Process Rich Text with AI

## What This Solves

When editing story text, skill descriptions, or quest text, you can ask AI to rewrite, translate, refine, or continue a selected rich-text passage.

## Steps

1. Open a rich-text cell.
2. Select the text you want to process.
3. Select **Ask Assistant**.
4. Describe how to rewrite, translate, refine, or continue the text.
5. Preview the response.
6. Replace the original only after checking the result, then save.

## Example Instructions

> Keep all skill values and placeholders. Make this description more concise without changing its meaning.

> Translate this into English. Preserve HTML tags, line breaks, and the `{damage}` placeholder.

## What To Check

- Numbers, variable names, and placeholders have not changed.
- Bold text, colors, lists, and line breaks are still intact.
- Continued text matches the setting and the character's voice.

> [!tip]
> Select a specific passage before asking. It is easier to review and undo than rewriting the entire document.
