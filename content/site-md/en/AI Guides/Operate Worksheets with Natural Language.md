# Operate Worksheets with Natural Language

## What This Solves

**Worksheet Operations** converts natural-language instructions into real table changes. It is useful when you are not familiar with bulk-editing tools.

## Supported Operations

- Append, insert, or delete rows.
- Insert or delete columns.
- Change cells or fill a range in bulk.
- Clear cells or ranges.
- Format cells or ranges.

## Steps

1. Select the desktop companion, then choose **Worksheet Operations**.
2. Enter an instruction with a clear location, range, and result.
3. Wait for AI to analyze and perform the operation.
4. Check the modified range and data pattern.
5. Undo immediately if the result is wrong.

## Example Instructions

> Insert a row at row 3 and fill its ID by following the neighboring pattern.

> Clear the description column from row 5 through row 10.

> Set cells in the price column above 1000 to a light red background.

## Three Rules for Better Instructions

1. Name the worksheet, rows, columns, or selection.
2. Say whether to add, overwrite, clear, or format.
3. State what must not change, such as IDs, formulas, or headers.

> [!warning]
> Delete and overwrite operations can affect a large amount of data. Save the project first and review the result before continuing to edit.
