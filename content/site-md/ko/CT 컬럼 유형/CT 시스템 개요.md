# CT 시스템 개요

CT(Configuration Type, 설정 열 유형)는 해당 열이 일반 텍스트가 아니라 전용 편집기로 처리해야 하는 내용임을 ConfigNexus에 알려 줍니다.

## 해결하는 문제

설정 테이블에는 보상 목록, 리치 텍스트 설명, 리소스 경로, 날짜, JSON 매개변수처럼 한 셀에 복잡한 내용을 저장하는 경우가 많습니다. 문자열을 직접 입력하면 괄호를 빠뜨리거나 형식이 달라지기 쉽습니다. CT 시스템은 이런 내용을 전용 편집기로 바꾸어 테이블 안에서 시각적으로 편집하게 합니다.

## 사용 시점

- 셀에 서식이 있는 설명문을 저장할 때.
- 셀에 JSON 객체나 중첩 구조를 저장할 때.
- 보상, 드롭, 조건처럼 고정 필드 목록을 저장할 때.
- 열의 날짜 형식을 통일해야 할 때.
- 이미지, 오디오, 모델 등의 리소스 경로를 저장할 때.

## 활성화 방법

1. 메인 테이블에서 대상 열의 셀을 선택합니다.
2. 우클릭 메뉴를 엽니다.
3. **CT 속성**으로 이동합니다.
4. 알맞은 열 유형을 선택합니다.
5. 열 유형 설정을 유지하려면 `.cnx` 프로젝트로 저장합니다.

## 작업 단계

### 1단계: 열에 저장할 데이터 결정

열의 실제 용도를 먼저 확인합니다. 일반 숫자와 짧은 텍스트에는 CT가 필요하지 않습니다. 구조화된 내용, 긴 텍스트, 리소스, 날짜에 사용합니다.

### 2단계: 열 전체에 CT 유형 설정

CT는 셀별 설정이 아니라 열 설정입니다. 설정 후 해당 열의 모든 데이터 셀이 같은 편집기를 사용합니다.

### 3단계: 데이터 셀 더블 클릭

CT 편집기는 데이터 행에서만 열립니다. 헤더 영역은 필드명, 유형, 설명, 검증 규칙에 사용되므로 더블 클릭해도 CT 편집기가 열리지 않습니다.

### 4단계: 전용 편집기에서 셀로 저장

편집기 결과가 현재 셀에 기록됩니다. 내보낼 때 셀에 저장된 내용도 함께 내보냅니다.

## 자주 발생하는 문제

> [!warning]
> `.xlsx`로 저장하면 CT 열 유형 설정이 사라집니다. CT, 외부 참조, Python 수식 같은 프로젝트 정보를 유지하려면 `.cnx`로 저장하세요.

> [!tip]
> 더블 클릭해도 편집기가 열리지 않으면 해당 열에 CT 유형이 설정되었는지, 데이터 행을 클릭했는지, Luckysheet 로딩이 끝났는지 확인하세요.
