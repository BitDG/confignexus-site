# AI 번역 및 텍스트 처리

## 해결하는 문제

AI로 다국어 열을 일괄 번역할 수 있습니다. 선택 영역 번역, 영어 필드명 생성, 문장 다듬기에도 사용할 수 있습니다.

## 전체 번역

1. 데스크톱 펫을 클릭하고 **스마트 전체 번역**을 선택합니다.
2. 원본 열과 번역 범위를 선택합니다.
3. 출력 열을 하나 이상 추가합니다.
4. 각 출력 열의 대상 언어를 선택합니다.
5. 번역을 시작하고 결과가 기록될 때까지 기다립니다.
6. 고유명사, 숫자, 경로, 자리표시자를 일부 추출해 확인합니다.

전체 번역은 여러 언어 열을 한 번에 만들 때 적합합니다. 큰 작업은 진행 상황을 확인하거나 완료되지 않은 부분을 취소할 수 있습니다.

## 선택 영역 우클릭 작업

셀을 선택하면 우클릭 메뉴에서 다음 기능을 사용할 수 있습니다.

- **AI 번역**: 기존 행과 열 구조를 유지하면서 선택 영역을 번역합니다.
- **영어 필드명 생성**: 중국어 필드에서 코드용 영어 이름을 생성합니다.
- **AI 문장 다듬기**: 선택한 말투에 맞게 텍스트를 다시 씁니다.

## 출력 규칙 사용자 지정

**어시스턴트 허브 설정 → 기존 내용**에서 번역 프롬프트, 전체 번역 규칙, 영어 필드명 규칙, 필드 생성 프롬프트, 문장 다듬기 말투를 설정할 수 있습니다.

프롬프트에 다음 규칙을 추가하는 것이 좋습니다.

> `{name}`, `{0}`, `%s`, 숫자, HTML 태그, 리소스 경로를 유지하고 프로그램 식별자는 번역하지 마세요.

> [!warning]
> 일괄 번역은 테이블에 결과를 다시 씁니다. 시작 전에 프로젝트를 저장하고 완료 후 자리표시자와 고유명사를 확인하세요.
