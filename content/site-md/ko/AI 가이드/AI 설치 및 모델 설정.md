# AI 설치 및 모델 설정

## 해결하는 문제

ConfigNexus의 AI 기능은 런타임 플러그인을 통해 모델에 연결됩니다. 처음 사용할 때는 플러그인을 설치하고 서비스에 연결한 뒤 모델을 선택해야 합니다.

## 지원하는 연결 방식

| 연결 방식 | 적합한 상황 | 데이터 전송 위치 |
|---|---|---|
| Ollama | 오픈 소스 모델을 내 컴퓨터에서 실행할 때 | 기본적으로 내 컴퓨터에 유지 |
| LM Studio | LM Studio에서 모델을 이미 내려받아 로드했을 때 | 기본적으로 내 컴퓨터에 유지 |
| 원격 API | OpenAI 호환 프로토콜의 온라인 서비스를 사용할 때 | 해당 서비스 제공자에게 전송 |

## 작업 단계

1. 워크샵을 열고 필요한 AI 런타임 플러그인을 설치합니다.
2. 플러그인 안내에 따라 Ollama나 LM Studio를 실행하거나 원격 API를 설정합니다.
3. ConfigNexus를 다시 시작합니다.
4. 데스크톱 펫을 우클릭하고 **어시스턴트 허브 설정**을 엽니다.
5. **연결 설정**으로 이동해 **플러그인 새로 고침**과 **모든 모델 새로 고침**을 실행합니다.
6. 기본 모델을 먼저 선택하고, 필요에 따라 번역, 문장 다듬기, 워크시트 작업, 필드 생성, 수식 생성, 채팅 모델을 선택합니다.
7. 메인 화면으로 돌아가 스마트 어시스턴트가 연결됨으로 표시되는지 확인합니다.

## 개인정보 안내

로컬 실행을 선택해도 모든 연결이 오프라인인 것은 아닙니다. Ollama와 LM Studio는 일반적으로 내 컴퓨터에서 내용을 처리합니다. 원격 API는 요청 처리에 필요한 내용을 해당 서비스 제공자에게 보냅니다. 민감한 데이터를 원격 모델로 처리하기 전에 제공자의 데이터 정책을 확인하세요.

## 자주 발생하는 문제

> [!warning]
> AI 런타임 플러그인을 설치하지 않으면 채팅, 전체 번역, 워크시트 작업, 우클릭 AI 메뉴가 표시되지 않습니다.

- 모델을 찾을 수 없음: 서비스가 실행 중이고 모델이 로드되었는지 확인한 다음 모델 목록을 새로 고칩니다.
- 연결할 수 없음: 서비스 주소, 포트, 방화벽, API 키를 확인합니다.
- 작업에서 잘못된 모델 사용: 해당 작업에 별도 모델이 지정되어 있는지 확인합니다.
