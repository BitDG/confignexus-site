# AI 채팅 및 테이블 생성

## 해결하는 문제

스마트 어시스턴트는 설정 관련 질문에 답하고 구조화된 내용을 생성할 수 있습니다. 답변에 포함된 테이블로 새 워크시트를 만들 수도 있습니다.

## 여는 방법

1. 먼저 [[AI 설치 및 모델 설정]]을 완료합니다.
2. 데스크톱 펫을 클릭해 스마트 어시스턴트를 엽니다.
3. 입력 상자 아래에서 채팅 모델을 선택합니다.

## 작업 단계

### 1단계: 필요한 결과 설명

테이블의 용도, 필드, 데이터 수, 제한 조건을 명확히 적습니다. 예:

> ID, 이름, 유형, 등급, 가격, 설명을 포함하는 게임 아이템 설정 테이블을 만들어 주세요. 테스트 데이터는 10개이며 ID는 1001부터 시작하고 중복되면 안 됩니다.

### 2단계: 답변 확인

필드명, ID, 숫자 범위, 열거값, 참조 관계를 확인합니다. AI가 생성한 내용은 초안이므로 최종 데이터로 바로 사용하지 마세요.

### 3단계: 워크시트 생성

답변에 테이블이 있으면 옆의 생성 버튼을 사용해 새 워크시트를 만들고 테이블 편집기에서 계속 조정합니다.

## 채팅 관리

- 이전 채팅을 새로 만들고, 이름을 바꾸고, 고정하거나 삭제할 수 있습니다.
- 반복해서 쓰는 요구 사항을 **자주 쓰는 프롬프트**에 저장할 수 있습니다.
- 프롬프트에 호출어를 설정해 입력 상자의 바로가기 메뉴에서 빠르게 사용할 수 있습니다.

> [!tip]
> 프롬프트가 구체적일수록 결과가 안정적입니다. “테이블을 채워 줘” 대신 열, 행 수, 지켜야 할 규칙을 정확히 적으세요.
