# AI로 워크샵 컴포넌트 개발

## 해결하는 문제

ConfigNexus는 컴포넌트 개발용 스킬 패키지를 제공합니다. 스킬 기능을 지원하는 AI 도구에 설치하면 기존 프로젝트 규칙에 맞춰 워크샵 컴포넌트를 만들거나 수정할 수 있습니다.

## 스킬 패키지 내용

- 프로젝트 구조와 기술 스택.
- 의존성과 리소스 로딩 규칙.
- IPC 통신과 데이터 형식.
- 필드 매핑과 UI 규칙.
- 다국어 지원.
- 개발, 테스트, 전달 절차.

## 사용 단계

1. 공식 사이트 저장소에서 `skills/confignexus-component-dev`를 찾습니다.
2. 스킬 설치 스크립트를 실행하거나 스킬 디렉터리를 AI 도구의 스킬 검색 디렉터리에 복사합니다.
3. AI 세션을 다시 열어 도구가 새 스킬을 로드하게 합니다.
4. “ConfigNexus 워크샵 컴포넌트를 개발해 줘”라고 요청하고 용도, 입력, 출력, 화면을 설명합니다.
5. 기존 예제 컴포넌트를 먼저 수정하도록 합니다.
6. 컴포넌트 설명에 따라 실행하고 검증한 뒤 게시 여부를 결정합니다.

## 권장 요청문

> 현재 선택 영역을 읽고 빈 셀 수를 세어 대화 상자에 표시하는 ConfigNexus 컴포넌트를 개발해 주세요. 기존 컴포넌트 템플릿을 재사용하고 중국어와 영어를 지원하며 새 의존성은 추가하지 마세요.

> [!warning]
> AI가 생성한 컴포넌트에도 오류나 안전하지 않은 작업이 포함될 수 있습니다. 설치 전에 의존성, 파일 접근, 네트워크 요청, IPC 권한을 확인하세요.

> [!tip]
> 빈 프로젝트에서 다시 만들게 하지 말고 워크샵의 기존 예제를 재사용하세요. 코드가 줄어들고 실제 환경에서 검증하기도 쉽습니다.
