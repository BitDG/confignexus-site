# AI로 Python 스크립트 생성

## 해결하는 문제

Python을 처음부터 작성하기 어렵다면 처리 목표를 설명하고 AI가 스크립트나 수식 코드를 만들게 한 뒤, 편집기에서 확인하고 실행할 수 있습니다.

## 작업 단계

1. Python 스크립트 편집기나 수식 편집기를 엽니다.
2. 처리할 데이터, 원하는 결과, 제한 조건을 입력합니다.
3. 코드를 생성합니다.
4. 바로 실행하지 말고 생성 결과를 확인합니다.
5. 먼저 작은 데이터 범위에서 테스트합니다.
6. 출력이 올바른지 확인한 뒤 실제 테이블에 사용합니다.

## 설명 예시

> 현재 워크시트의 `price`와 `count` 열을 읽어 `total=price*count`를 계산해 주세요. 빈 값은 0으로 처리하고 다른 열은 변경하지 마세요.

## 실행 전 확인

- 입력과 출력 필드가 실제로 존재하는지 확인합니다.
- 빈 값, 텍스트, 잘못된 데이터를 처리하는지 확인합니다.
- 수정 범위가 예상과 같은지 확인합니다.
- 불필요한 파일, 네트워크, 시스템 작업이 포함되어 있지 않은지 확인합니다.
- 원본 데이터를 의도치 않게 덮어쓰지 않는지 확인합니다.

> [!warning]
> AI가 생성한 코드도 일반 코드입니다. 실행 전에 반드시 읽고 확인하세요. 일괄 수정 전에는 프로젝트를 저장하거나 복원 가능한 복사본을 준비하세요.
