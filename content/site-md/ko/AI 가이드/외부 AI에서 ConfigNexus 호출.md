# 외부 AI에서 ConfigNexus 호출

## 해결하는 문제

ConfigNexus는 MCP(외부 AI가 앱 기능을 호출하는 표준 인터페이스)를 지원합니다. 연결하면 Claude Code, Codex 같은 도구가 ConfigNexus에 실제 데이터 작업을 요청할 수 있습니다.

## 호출할 수 있는 작업

- 설정 데이터 내보내기.
- 데이터 검증 실행.
- Excel 가져오기 또는 Excel로 변환.
- 디렉터리, 파일, 셀 차이 비교.
- 데이터 되쓰기 미리보기 및 확인.
- 외부 참조 읽기.
- 실행 환경 확인.

## 연결 단계

1. 데스크톱 펫을 우클릭하고 **어시스턴트 허브 설정**을 엽니다.
2. **연결 설정**으로 이동합니다.
3. **AI 도구 연결(MCP)**을 찾습니다.
4. **AI 연결 설정 복사**를 선택합니다.
5. 설정을 외부 AI 도구의 MCP 설정에 붙여넣습니다.
6. 외부 AI 도구를 다시 시작하거나 새로 고칩니다.
7. 먼저 환경 확인을 실행한 다음 작은 프로젝트를 검증하거나 내보냅니다.

## 권장 안전 순서

1. 먼저 환경을 읽거나 확인합니다.
2. 다음으로 검증, 내보내기, 차이 비교를 실행합니다.
3. 되쓰기가 필요한 작업은 먼저 미리 봅니다.
4. 미리보기 결과를 확인한 뒤 쓰기를 승인합니다.

> [!warning]
> MCP를 연결하면 외부 AI가 실제 작업 권한을 갖습니다. 되쓰기 미리보기를 건너뛰지 말고 대상 경로를 확인하지 않은 상태에서 일괄 수정을 승인하지 마세요.

> [!note]
> Claude Code와 Codex는 MCP 클라이언트의 예입니다. 해당 회사의 모델 API가 ConfigNexus에 직접 내장되어 있다는 뜻은 아닙니다.
