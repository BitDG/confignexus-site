# AI生成Python脚本

## 解决什么问题

不会从零编写 Python 时，可以先描述处理目标，让 AI 生成脚本或公式代码，再在编辑器中检查和运行。

## 操作步骤

1. 打开 Python 脚本编辑器或公式编辑入口。
2. 输入需要处理的数据、目标结果和限制条件。
3. 选择生成代码。
4. 检查生成结果，不要立即运行。
5. 先用小范围数据测试。
6. 确认输出正确后再用于正式表格。

## 描述示例

> 读取当前工作表的 price 和 count 两列，计算 total=price*count。空值按 0 处理，不修改其他列。

## 运行前检查

- 输入和输出字段是否真实存在。
- 是否处理空值、文本和异常数据。
- 修改范围是否符合预期。
- 是否包含文件、网络或系统操作。
- 是否会覆盖原始数据。

> [!warning]
> AI 生成的代码仍然是代码。运行前必须阅读并确认；批量修改前先保存工程或准备可回退副本。
