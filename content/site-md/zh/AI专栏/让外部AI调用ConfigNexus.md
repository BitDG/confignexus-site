# 让外部AI调用ConfigNexus

## 解决什么问题

ConfigNexus 支持 MCP（让外部 AI 调用软件能力的标准接口）。连接后，Claude Code、Codex 等工具可以直接请求 ConfigNexus 完成数据操作。

## 可以调用什么

- 导出配置数据。
- 运行数据验证。
- 导入 Excel 或转回 Excel。
- 比较目录、文件和单元格差异。
- 预演并确认数据反写。
- 读取外部引用。
- 检查运行环境。

## 接入步骤

1. 右键桌宠，打开“助手中台设置”。
2. 进入“接入配置”。
3. 找到“AI 工具接入（MCP）”。
4. 点击“复制 AI 接入配置”。
5. 把配置粘贴到外部 AI 工具的 MCP 配置中。
6. 重启或刷新外部 AI 工具。
7. 先执行环境检查，再尝试验证或导出一个小项目。

## 推荐的安全顺序

1. 先读取或检查环境。
2. 再运行验证、导出或差异比较。
3. 涉及反写时先执行预演。
4. 人工检查预演结果后再确认写入。

> [!warning]
> MCP 会让外部 AI 获得实际操作能力。不要跳过反写预演，也不要在未检查目标路径时批准批量修改。

> [!note]
> Claude Code 和 Codex 是 MCP 客户端示例，不代表 ConfigNexus 直接内置了对应厂商的模型接口。
