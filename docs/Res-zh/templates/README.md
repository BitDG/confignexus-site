# 模板文件夹

存放中文版的 ConfigNexus 模板文件。

## 文件类型

- **ConfigNexus 项目文件（.cnx）** - 推荐使用，完整保留所有配置和样式

## 使用方法

在 MD 文件中添加创建按钮：

```markdown
createtab:Res/zh/templates/示例道具表.cnx
```

用户点击按钮后会自动导入该模板文件到应用中。

## 创建模板

1. 在 ConfigNexus 中创建并编辑好表格
2. 文件 -> 保存项目 -> 选择保存位置
3. 将 .cnx 文件复制到此文件夹
4. 在 MD 文件中引用该模板

## 注意事项

- 模板文件必须是 .cnx 格式
- 文件名建议使用中文，方便用户识别
- 模板应该包含示例数据，帮助用户理解功能
