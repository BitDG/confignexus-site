# 官网聚光画布背景设计

## 目标

把首页后半段从“格子上叠浅白色带”改成连续、安静的聚光画布，让真实产品画面成为视觉焦点，同时保留 ConfigNexus 克制、可信的工程工具气质。

## 已确认方向

采用 C「聚光画布」：

- 首屏和工作流证明条继续保留现有格子背景。
- 从“核心工作流”开始进入连续的浅暖灰绿色画布。
- 画布使用大面积低对比柔光和极轻点状颗粒，不使用明显格子、玻璃色带或 3D 动态背景。
- 深色只用于产品视频和产品截图容器，不把整段页面改成深色。

## 页面结构

在首页中用一个 `.atmosphere-canvas` 容器包住以下现有段落：

1. 核心工作流
2. 进阶能力
3. AI 扩展能力
4. 工程与生态
5. 底部下载入口

容器只承担连续背景，不改变段落顺序、文案、链接或媒体内容。

## 视觉规则

- 基础色：接近 `#f5f7f1` 的暖灰绿色。
- 柔光：右上淡绿色、左下浅灰绿色，透明度保持低于内容卡片。
- 颗粒：使用 CSS 小圆点形成极轻纹理，并在上下边缘渐隐。
- 段落分隔：依靠留白和柔光变化，不再使用当前的横向边框与浅白渐变色带。
- 媒体：工作流和 AI 演示沿用现有深色影院容器；工程生态的两张产品图也进入同一深色媒体样式。
- 卡片：维持现有白色玻璃卡，不新增发光边框、浮动球或持续动画。

## 动效与可访问性

继续使用现有滚动进入效果，不新增背景动画。减少动效模式、触屏设备规则和视频按可见性播放逻辑保持不变。

## 改动边界

- 修改 `index.html`：增加一个背景容器，不改变内容顺序。
- 修改 `site.css`：新增聚光画布与工程生态媒体样式，删除当前后半段浅白色带规则。
- 修改五个页面的 CSS 版本号，避免浏览器继续使用旧样式。
- 修改 `scripts/check-site.mjs`：检查聚光画布结构和新 CSS 版本。
- 不安装依赖，不引入 Lenis、GSAP、Vanta.js 或 React Bits。

## 验收标准

- 桌面端从核心工作流到下载入口呈现为一块连续背景，没有色带接缝。
- 首屏格子仍然可见，进入后半段后格子被聚光画布遮住。
- 工程生态的产品图与现有视频使用一致的深色媒体舞台。
- 手机端无横向溢出，文字和按钮对比度不降低。
- `node scripts/check-site.mjs`、JavaScript 语法检查和 `git diff --check` 全部通过。
