# Video Resources Folder

This folder is used to store demonstration video files in WebM format for the English version.

## Usage

Use the following syntax in Markdown files to reference videos:

```markdown
video:Res/en/videos/demo.webm
```

Or use syntax with a title:

```markdown
video:Res/en/videos/demo.webm|This is video title
```

## File Naming Convention

- Use lowercase letters and hyphens
- Examples: `excel-import-demo.webm`, `ai-translation.webm`

## Notes

- Video format must be WebM (VP8/VP9 codec)
- Recommended video resolution: up to 1920x1080
- Recommended video size: up to 50MB
- Video controls will be automatically added
- WebM format offers better compression and open-source advantages compared to MP4
